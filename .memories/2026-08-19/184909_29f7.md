## CT dogfood — four fixes implemented (TDD), fast suite green

**WHAT:** Implemented and tested four fixes from the CT dogfood findings:

1. `ContinuousTestProjectInventory.TryIdentify`: dropped the name-contains-"Test" heuristic; a bare `.csproj` now needs a real test signal (xunit/nunit/mstest reference, `Microsoft.NET.Test.Sdk`, `Microsoft.NET.Sdk.Test`, or `Microsoft.Testing.Platform`). Fixes misclassification of `src/Miller.Testing` (class library) and `Miller.SharedBrokerTestHost` (helper host).
2. New `ParseDefaultFilterExclusions`: enable now seeds `exclude_traits` from the project's `VSTestTestCaseFilter` (pure `Name!=Value` conjunctions only; anything else seeds nothing). On this repo that maps `Category!=Scale` → exclude trait `Category=Scale`, so CT stops running the Scale suite by default.
3. `ContinuousTestStoreApplier.ApplyDiscovery` now wraps prune+insert in one `store.Transaction` — was one commit per row (~35 rows/s, minutes of write-lock hold for 6k cases, blocked readers).
4. `ContinuousTestDaemonHost`: new `PulseHeartbeatAsync` background task + `HeartbeatInterval` option (default 15s) keeps `daemon.heartbeat.json` fresh; it was written once at lease acquisition and never again. Also `TestsCore.CompactFreshness` renders the compact `selected:` line bounded (rev + 24-char identity prefix) instead of a 300-char store cursor.

**Tests:** new RED-first tests in `ContinuousTestProjectInventoryTests` (6), `ContinuousTestStoreApplierTests.Apply_discovery_stores_all_cases_or_none`, `ContinuousTestDaemonHostHeartbeatTests`, `TestsToolTests.Compact_status_renders_a_bounded_selected_line_for_a_long_index_identity`. Fast suite: 7368 passed, 0 failed, 29s.

**Still open (reported, not fixed — design decisions):**
- xunit run argv passes one `-method` per selected case (>128KB observed; exceeds the Windows 32K limit).
- During a long drain the host loop processes no stop commands and freezes `daemon.status.json`.
- Enable does not prune stored rows that discovery no longer returns (stale misclassified rows survive; provenance is not recorded so auto-prune could remove explicit `--project` enables).
