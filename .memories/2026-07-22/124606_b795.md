## Semantic maturity decision foundations implemented

The first execution phase now measures semantic value instead of relying on retrieval impressions.

- **What:** Added the v3 decision canary runtime profile, a pure paired task-completion scorer, and frozen per-query retrieval search modes.
- **Why:** The prior canary was underpowered for identifiers and the visible evaluator accidentally sent docs-like rows through auto symbol search, so it could not answer whether semantic search improves completed tasks.
- **How:** `MILLER_SEMANTIC_CANARY=decision` keeps hybrid assignment unchanged while sampling every identifier unit in shadow; the evaluator uses a 30-pair Wilson lift gate with identifier/path safety and routes four markdown rows through `mode=content`.
- **Impact:** Export/aggregation and sealed CLI wiring can now build on stable contracts, and the final day-30 decision can honestly promote or remove semantic retrieval.
