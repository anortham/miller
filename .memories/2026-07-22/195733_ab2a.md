## Separated clean source identity from prepared benchmark roots

- **WHAT:** Added `SnapshotIdentity.verify_prepared_root` and switched the Codex runner preflight to it.
- **WHY:** A real paired run needs prebuilt Miller and Julie indexes without weakening the clean snapshot identity contract.
- **HOW:** Prepared roots still verify repository top-level, commit, and committed-content hash. They require only top-level `.miller` and `.julie`, exclude exactly those trees from Git dirty status, and reject missing trees, arbitrary dirt, other artifact directories, symlinks, and nested Git markers.
- **IMPACT:** Timed runs can start from prebuilt indexes while remaining isolated from active workspaces and failing closed on source contamination.
