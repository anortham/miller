## WHAT

Completed and accepted Task 6, the Maven continuous-testing backend. The backend now preserves project/user Maven configuration, enforces class-level selection identity for every run mode, bounds Surefire report reads to the generation-owned report root, and requires both `java` and `javac` before JVM Scale smoke runs.

## WHY

Lead review found that setting `-DargLine` and `MAVEN_OPTS` would overwrite project JaCoCo/Surefire or user JVM options. A live Maven probe also showed that a runtime-only Java installation could pass the old Scale prerequisite and then fail compilation misleadingly.

## HOW

Removed the configuration-clobbering arguments, retained generation-local temporary paths, validated the Maven class sentinel before the whole-suite branch, tightened report containment, and added focused regressions. Added a compiler-aware Java locator test. Maven 3.9.16 was downloaded only to `/tmp`; the exact Scale smoke now skips because this host has `/usr/bin/java` but no `javac`.

## IMPACT

Maven CT is registered and covered without risking source-tree output or overwriting build configuration. Task 7 (sbt) can now extend the shared JVM seam. Release remains held until every provider task and branch gate completes.
