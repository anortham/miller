## Preserved trace recovery context

### WHAT

Extended trace path recovery actions to retain invocation context for ambiguous sources and destinations, including mode, destination, path kind, depth, and the original source scope where the action still targets that source. Swapped no-path retries intentionally omit the original source scope.

### WHY

The release-candidate trace fixes still dropped replay arguments at ambiguity and no-path diagnostic boundaries. JSON path output also carried structured root actions that differed from diagnostic.next_actions.

### HOW

Added a private TraceArgs helper, threaded path context through ResolveSymbol, ambiguity, destination, and no-path action builders, and copied structured JSON root next_actions into the path diagnostic envelope. Existing one-traversal no-path behavior remains unchanged.

### IMPACT

Agents receive replayable path calls with consistent root and diagnostic recovery ordering. No new MCP arguments or tools were added.
