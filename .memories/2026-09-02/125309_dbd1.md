## WHAT

Accepted the user-provided Claude review of the sbt shadow design after verifying it against Miller's inventory, janitor, coordinator, path-budget, and JVM seams. Resolved the remaining product decision in favor of mirroring the sbt build-root subtree.

## WHY

`ContinuousTestProjectInventory` treats each `build.sbt` as a separate project and materializes a project-specific `BuildOutputRoot`. Copying the whole workspace for each project would duplicate unrelated monorepo data, consume each 2 GB cache budget, and lengthen Windows paths.

## HOW

Kept Claude's corrected report matching (`*.xml` validated by root element), nested `.git` exclusion, plain batch output, multi-project parse shape, global-plugin/symlink limitations, and janitor evidence. Strengthened janitor handling by always splitting `cache/sbt-workspace` from `cache/sbt-deps`, with independent last-used markers and a source-copy budget refusal. Replaced manual `\\?\\` path handling with preflight enforcement of Miller's existing 260-character path budget. Documented `../`/absolute/external build references outside the selected build root as v1 limits and marked the design approved.

## IMPACT

The brainstorming gate is cleared. Task 7 can now be rewritten into TDD implementation packets, committed, and dispatched in the existing feature worktree.
