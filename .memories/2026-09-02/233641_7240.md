## Windows residual test-contract corrections

### WHAT

Updated three focused test assumptions for Windows: mirror diagnostics now compare the native separator, JVM inventory keys are normalized before comparison, and `GutTooling` asserts the OS-specific environment. Reworked the GUT case-collision fixture to use two explicit resource IDs while creating only one case-insensitive Windows file, preserving the real collision behavior.

### WHY

The residual failures were not product defects. `CtWorkspaceMirror` and `ContinuousTestProjectInventory` carry filesystem-native paths; `GutTooling.BuildEnvironment` intentionally omits XDG variables on Windows; and NTFS collapses two case-only directory entries, so the original GUT fixture could never expose `GutConfiguration`'s collision detector there. The isolated `IndexerCore` test passes on Windows and Linux; its broad-run failure was a one-off five-second scheduling race under the 9,681-test load, so no timeout or product change was made.

The prior Windows broad log supplied the RED evidence for the three corrected cases, and the exact IndexerCore Windows rerun passed 1/1.

### IMPACT
