## WHAT
Implemented the Maven continuous-testing backend in the JVM provider seam. Added class-level Surefire discovery, class-filtered Maven runs with bounded chunking, generation-owned build/output/report/repository/temp paths, wrapper resolution, aggregate JUnit result mapping, and Maven registration. Added focused tests, a two-class Scale smoke, Maven toolchain discovery, and a convention guard.

## WHY
Task 6 is the release-blocking Maven provider slice in the approved CT provider plan. Maven has no dry-run listing, so discovery must compile then inspect generation-local test-classes using Surefire's default class naming patterns. Per-class identity uses the stable internal sentinel while public selectors and argv remain class-only.

## HOW
Followed Miller-first exploration and strict TDD. The backend invokes test-compile, scans only generation roots, redirects Maven and Surefire paths, parses the shared secure JUnit parser, aggregates method rows per class, and fails closed on malformed/duplicate/mismatched or partial-attribution results. Wrapper order is module, workspace, PATH. The live Maven smoke is capability-gated and skipped because Maven is not installed on this host.

## IMPACT
Task 6 is ready for lead inline review and commit reconciliation. Focused JVM/Maven/factory/convention tests pass; the Maven Scale smoke skipped for the absent executable; Release build passes with zero warnings/errors.
