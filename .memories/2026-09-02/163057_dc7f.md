## WHAT

Wrote and adversarially reviewed the Task 8 Godot/GUT project-shadow design. The shared mirror boundary survived, and the design now includes a bounded Godot import phase, isolated global data/config/cache/temp paths, exact derived-config selection, Godot/GUT version gates, deterministic warm-path metrics, `.gdignore`, and an over-budget refusal marker.

## WHY

Godot has no import-suppression flag, so the original in-place Task 8 plan would violate CT source isolation. Claude's one-pass doubt review also found home-directory writes, warm full-file hashing, command-line overflow, discovery-flow contradiction, and incomplete runtime evidence.

## HOW

The hardened sbt reconciler becomes an internal `CtWorkspaceMirror` with closed sbt and Godot policies. sbt retains strict hashing and its existing result contract. Godot uses metadata-fast reconciliation, a persistent `.godot` cache, a separate `godot-home` candidate, a conditional `--import` phase, and derived `.gutconfig.json` script arrays for both focused and whole-suite runs. Every medium-or-higher review finding was verified and incorporated; no second reviewer call is permitted.

## IMPACT

Task 8 now has a safe, performance-aware design ready for user spec approval. Implementation remains gated. Release verification must execute the real Godot 4/GUT 9 Scale smoke; an honest missing-tool skip is insufficient for release.
