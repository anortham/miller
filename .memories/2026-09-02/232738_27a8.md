## Windows mirror metadata regression test

### WHAT

Added `CtWorkspaceMirrorTests.Sync_preserves_empty_directory_timestamp_and_permissions`, covering an empty directory's timestamp and Unix permissions after mirroring.

### WHY

The Windows gate showed directory entries fail in `CtWorkspaceMirror.ApplyMetadata` before metadata can be applied. The test exercises the real mirror contract and provides the smallest reproducible directory-metadata case.

### HOW

The fixture sets a hand-derived timestamp and, on Unix, a restrictive executable directory mode, then syncs through `CtWorkspaceMirror` and asserts the mirrored directory metadata. The focused shared mirror class currently passes on Linux (19/19); the Windows-specific RED remains to be observed after syncing this test-only commit.

### IMPACT

This test isolates the 38 Windows failures to directory metadata application without touching the other Windows failure groups. Next, sync this commit to the guest for the focused RED, then change only `ApplyMetadata` to use the directory timestamp API for directory entries.
