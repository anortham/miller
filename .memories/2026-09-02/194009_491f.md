## WHAT

Fixed five Task 1 review findings in the shared mirror, Godot shadow, and sbt adapter. Added direct shared-interface safety coverage and targeted regressions.

## WHY

Metadata mode could adopt unowned destination content, empty directory additions were invisible to source-change reporting, post-import budget enforcement was private and unavailable to Task 2, normal Godot sync traversed source metadata twice, and sbt dependency-cache creation could follow a reparse-point candidate outside CT storage.

## HOW

`CtWorkspaceMirror.SyncCore` now requires prior manifest ownership before reuse and marks any newly materialized source entry as changed. `GodotProjectShadow.EnforcePostProcessBudget` measures both candidates without following reparse points, owns marker serialization, rejects marker/candidate reparse paths, and atomically writes the durable over-budget marker. Normal Godot marker checks compute a pre-sync source digest only when a marker exists; the normal path gets the digest from the one shared sync traversal. `SbtWorkspaceShadow` guards `sbt-deps` before creation. Added direct shared coverage for changes/deletes, empty directories, collisions, traversal, escaping/cyclic links, special files, source budget, path length, metadata, recovery, cancellation, concurrency, and both integrity modes.

## IMPACT

Task 2 can enforce post-process budget through one internal operation without duplicating marker logic. The shared mirror remains closed-policy and internal, sbt behavior remains compatible, and the full Task 1 focused scope is green.
