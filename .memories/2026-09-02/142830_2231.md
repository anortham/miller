## Fixed round-2 sbt workspace shadow review findings

- **WHAT:** Hardened the provider-local sbt shadow against nested build-owned `.git` cleanup, ancestor-directory symbolic-link cycles, recursive/double candidate-byte measurement, and non-portable Unix special-file classification.
- **WHY:** Review found stale reconciliation recognized only `target`, directory links to containing ancestors could be accepted, `DirectoryBytes` followed accepted links, and a raw libc `stat` buffer offset was not portable.
- **HOW:** Treat `target` and `.git` as build-owned at any depth; thread the original source root through enumeration, reject resolved ancestor targets, and use an explicit reparse-point-skipping byte walk. Replace the raw `lstat` buffer with Linux `statx`'s fixed ABI plus an explicit Darwin LP64 layout for x64/arm64; expose only provider-local internal classification helpers for branch tests. Unsafe-manifest validation is unchanged.
- **IMPACT:** The internal `SbtWorkspaceShadow.Sync`/result contract and shared APIs remain unchanged. The complete focused class passes 31/31 tests, including all prior Task 1 behavior and the three remaining review regressions. No broad, Release, Scale, Windows, or performance gate was run.
