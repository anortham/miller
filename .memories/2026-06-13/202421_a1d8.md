## Clarified empty inspect recovery for agents

Claude's wording was not a literal Miller error string; local search found the closest Miller behavior is `inspect <file>` returning `No indexed symbols in <path>` when a file has no cached symbols. The embedded server instructions told agents to refresh stale indexes generally, but did not explicitly cover the empty-file-symbol case.

- **What:** Added a concise rule to `src/Miller.Server/MILLER_AGENT_INSTRUCTIONS.md`: when `inspect <file>` shows no indexed symbols for an expected code file, refresh and retry before raw reads.
- **Why:** Prevents agents from treating a transient or stale index miss as permission to bypass Miller with broad direct file reads.
- **How:** Pinned the behavior in `AgentInstructionsTests.Load_PinsBehavioralAdoptionLanguage` with an assertion for the new phrase.
- **Impact:** Future MCP server instructions nudge Claude/Codex toward `workspace refresh` + retry when just-changed files are missing from symbol inspect.
