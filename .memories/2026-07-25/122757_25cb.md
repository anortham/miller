## Closed the critical rename and qualified-target review findings

### WHAT

- Restricted exact rename sites to identifier-derived evidence whose span equals the old identifier's UTF-8 byte length.
- Kept the first highest-scoring definition token instead of replacing a later equal-score body occurrence.
- Allowed fully qualified member resolution when extraction provides the type/member chain but omits outer namespace parent rows.
- Documented the applied JSON `post_apply_hint` and exact rename safety contract.

### WHY

Relationship evidence could carry whole-construct spans and be spliced as if it were an identifier, equal-score matching could rename a right-hand-side use instead of the declaration, and missing namespace rows made otherwise resolvable qualified names fail.

### HOW

Added failing regressions for a broad relationship span, an expression-bodied property with a repeated name, and parentless fully qualified type/member fixtures, then made the narrow production fixes.

### IMPACT

The critical corruption path now fails closed, declaration targeting is deterministic, and agents can resolve qualified names on real extractor artifacts that omit namespace parents.
