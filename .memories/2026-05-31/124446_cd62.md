## First dogfood: fixed MCP connect failure + shipped 4 TODO hardening items

The miller MCP server failed to connect (`-32000`) on its first real dogfood. Diagnosed two stacked startup crashes, then worked the user's `TODO.md` review list (all 4 items).

### MCP connection fix (two root causes)
- **Host lifecycle crash.** `FreshnessService` injected `IndexHolder` in its ctor; the .NET Generic Host constructs ALL hosted services before any `StartAsync`, so the holder factory hit `IndexBootstrapService.Holder` before bootstrap ran → "Holder requested before bootstrap completed". Fix: drop the eager param, read `_bootstrap.Holder` lazily (the `IndexerService` pattern). Extracted the host graph into testable `MillerServiceRegistration.AddMillerServices`; added `HostStartupRegistrationTests` resolving the hosted-service set pre-bootstrap.
- **Packaging gap (masked by the crash).** Production locates julie-server at `AppContext.BaseDirectory/.tools`, but nothing copied it there. Fix: csproj `Content` copy of `.tools/julie-server` next to the binary + a chmod target (MSBuild Copy drops the exec bit).

### TODO items (order 2→3→1→4)
- **Item 2 — sensitive-root guard.** New `WorkspaceRootSafety` ported from julie `root_safety.rs`; refuses home/`/`/system dirs. Runs at the TOP of `Program.cs` (before any fs touch) + in `workspace open`. Verified cwd=$HOME refuses and writes nothing.
- **Item 3 — server instructions.** Authored `MILLER_AGENT_INSTRUCTIONS.md`, embedded as resource, set `McpServerOptions.ServerInstructions`. Tool descriptions were already good (left as-is, honestly reported).
- **Item 1 — log consolidation.** Per-PID files → ONE shared daily pair (`shared:true`); deleted `LogFileReaper` + reaper tests. pid/role/cid stay as line properties. m8-design D1/D6 marked superseded.
- **Item 4 — AGENTS.md.** Byte-identical mirror of CLAUDE.md + `scripts/sync-agents.sh` + `.githooks/pre-commit` + `scripts/install-hooks.sh` (core.hooksPath). Refreshed CLAUDE.md with the lifecycle gotcha.
