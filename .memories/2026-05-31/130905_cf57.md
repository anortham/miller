## Dogfood session: fixed `edit`/add_doc + centralized telemetry DB

Found via live MCP dogfooding after TODO.md items shipped; fixed two issues with TDD.

### 1. `add_doc` edit operation (two defects)
- **Indentation**: `EditPlanner.AddDoc` now aligns the inserted doc block to the symbol's own indentation (dedent caller block to common leading whitespace, re-indent to the member's indent). Previously inserted at column 0 against an indented member. Language-agnostic, no comment prefix synthesized. Backward compatible (column-0 symbols + the pre-indented EditService test unchanged).
- **Duplicate doc**: `EditService` now refuses `add_doc` when julie already extracted a `DocComment` for the symbol (via `ExtractReader.ReadDetail`), with guidance to use replace_text/insert_before. Consumes julie's cross-language doc_comment signal — no per-language comment-syntax re-derivation. Fires before disk access.

### 2. Telemetry DB centralized (was per-workspace)
- **Was**: `<root>/.miller/telemetry.db` (per-repo, alongside the symbols index).
- **Now**: `<home>/.miller/telemetry.db` — one machine-global ledger collecting from all workspaces. `symbols.db` stays per-repo (it's that repo's index).
- `WorkspaceContext.Create` gained optional `homeDirectory` param (null → UserProfile; tests inject temp).
- Schema: added `workspace_root TEXT` column (+ idx on workspace_id) so the shared DB is human-readable in aggregate. New central DB created fresh → no migration.
- **Critical ripple**: `Summarize`/`ComputeP95`/totals now scope by `workspace_id IS $ws` — otherwise per-workspace `workspace status` would report machine-wide totals. `InsertRawForTest` + the summary test helper now stamp workspace_id to match production (`TelemetryScope` stamps `_ledger.WorkspaceId`).
- Bootstrap ensures `~/.miller` exists before opening; `OpenAndPrune` now takes workspaceRoot.

### Parity note
Julie has NO separate tool-usage telemetry ledger — its `metrics_db_path_for_workspace` resolves the per-workspace symbols index. So Miller's `tool_telemetry` centralization was Miller's own design call, not a julie-parity constraint.
