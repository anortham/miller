## Fixed v1.5.1 Windows CI test portability failures

- **WHAT:** Added a shared-access SQLite body corruption helper in `MetricHistoryStoreTests` and normalized trailing `\r` after splitting compact metric-history output lines in `MetricsToolTests`.
- **WHY:** The v1.5.1 docs follow-up CI exposed two Windows-only test failures: `File.ReadAllBytes` could not open `history.db` while SQLite held a write-capable handle, and a compact-output assertion compared a CRLF-split line with a trailing carriage return.
- **HOW:** Kept the WAL-resident corruption scenario intact by opening the DB file with `FileShare.ReadWrite | FileShare.Delete` before mutating bytes, matching existing shared-file read patterns in the repo. Trimmed only trailing `\r` from split compact lines.
- **IMPACT:** The release branch/main follow-up can get CI green without changing product code or release artifacts.
