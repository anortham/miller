## Fixed Miller SQLite performance review findings

- **WHAT:** Added missing path/source/symbol/telemetry indexes, bumped affected sidecar schema versions, split hot dashboard telemetry queries away from `$all OR workspace_id` predicates, and added streaming JSONL writer APIs for bulk exports.
- **WHY:** Review found SQLite scans/temp sorts in incremental search-sidecar deletes, content corpus window/symbol reads, dashboard telemetry feeds/P95 queries, plus full-string materialization in CLI JSONL export paths.
- **HOW:** Added regression tests using `EXPLAIN QUERY PLAN`; added `search_symbols(path, symbol_id)`, `search_regions(path, region_id)`, `content_chunks(source_id,line_start,chunk_id)`, content symbol indexes, and telemetry composite indexes for recent, scoped, error, latest, and duration queries. Rewrote content context symbol lookup into indexed id/name arms and made CLI artifact/telemetry exports stream to `TextWriter`.
- **IMPACT:** Hot SQLite paths now use targeted indexes instead of table scans/temp B-trees, stale sidecar artifacts rebuild via schema bumps, and CLI JSONL exports no longer require one aggregate string before writing output.
