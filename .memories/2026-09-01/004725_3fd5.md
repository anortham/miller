## MCP workspace remove backgrounds producer retirement

### WHAT
MCP and dashboard `workspace remove`/`prune` now unregister immediately. They write the owed reclaim record and enqueue `StoreViewRetirementDrainService`. CLI still waits on `julie-extract retire-view`.

### WHY
MCP `workspace remove` blocked up to 2 minutes on producer retirement and timed out at 30s.

### HOW
- `awaitProducerRetirement` + `onRetirementOwed` on `WorkspaceRemoval` and `WorkspaceRegistryPrune`
- `WorkspaceRemoval.FinishProducerRetirement` runs preview+apply then sidecar reclaim
- Hosted `StoreViewRetirementDrainService` (no bootstrap getters)
- Deferred prune skips `SweepFamilies` so it does not spawn store maintain or reclaim on the caller thread

### IMPACT
MCP remove returns as soon as the registry row is gone. If the serve process dies, `.reclaim-owed` still names the view.
