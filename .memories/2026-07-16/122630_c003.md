## Agent→Miller interaction audit — telemetry + ponytail/context-mode comparison

Six-topic investigation (harness support, adoption, output efficiency, telemetry mix, hooks stance, search zero-results). Telemetry window 2026-06-16→07-16, 30,067 calls, 10 workspaces.

### Telemetry findings
- **Tool mix unchanged: inspect 54% + search 27% = ~80%.** edit 0.7% with **26% error rate** (replace_text, reasons unlabeled pre-1.9.0; 1.9.0 adds `edit_failure_reason`). content 13.8% errors — all contract friction (invalid `content_kind` enum ×29, path-vs-`source_id` confusion ×23, >200-line window ×17). trace 29% empty, patterns 25%, impact 12%. inspect full:summary = 3.4:1; ~950 inspect `not_found` empties.
- **Search zero-results NOT improving**: weekly 27→16→43→33→32%. Symbol/auto solved (<1% empty); text modes stuck (source 45.6%, file 43.9%, content 35.6%). `empty_diagnosis` (shipped Jul 6): **87.5% true_no_hit**, dominated by natural-language queries into lexical source/content; 68 file-mode path-like query_shape failures (fixable); only 53 mode_mismatch (routing hints work).
- **search computes `empty_diagnosis`/`query_shape` but ships them to telemetry ONLY** (SearchTool.cs:489) — agent gets a static generic hint. Highest-leverage actionability fix.

### Cross-project lessons
- **Both ponytail and context-mode skip MCP ServerInstructions entirely** and deliver guidance via SessionStart hook `additionalContext` (~4.6–5.2KB, not subject to the ~2KB cap). Ponytail: ALL hooks are prompt-injecting, zero blocking, fail-open, one shared instruction builder + thin per-host adapters (4 output schemas; Windows stdin-hang issue #443 solved with 1s timeout fallback). SubagentStart re-injection exists because SessionStart context never reaches subagents (ponytail #252) — subagents are the biggest grep population.
- **Ponytail's instruction-tier**: AGENTS.md + copied rule files (.cursor/rules/*.mdc alwaysApply, .windsurf, .clinerules, .kiro/steering, copilot-instructions.md) wins 8+ harnesses with zero code; drift-guarded by CI byte-compare + canary phrases.
- **context-mode measured vocabulary effects** (ADR-0003): "blocked"→"redirected" flipped Opus capitulation 6/6→0/6; bare-NOT negations regressed Haiku (ironic priming). Miller's rule 6 ("do NOT re-verify with grep/find") uses the measured-bad construct. Their unenforced description caps rotted 2–3× over; Miller's AgentInstructionsTests gate is the thing that keeps budgets honest. Their #856 do-nothing loop: auto-captured directives re-injected as standing orders froze the agent. context-mode is Elastic-2.0 — ideas only, no code.
- Miller output weak spots: impact compact has no impacted-row cap (tests capped 20); content search repeats source_id hashes per hit; edit 8-line Match proof fixed block; SignatureMaxLength=110 triplicated.

### Recommended priority order (not yet approved/implemented)

3. Fix content contract friction (accept display_path alias, clamp window, tolerant content_kind).
4. Reword bare-NOT constructs in instructions/descriptions to affirmative redirects.
5. file-mode path-like query handling; impact row cap; content source_id dedup.
6. Watch 1.9.0 edit_failure_reason telemetry for the 26% edit error rate.
