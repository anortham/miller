## Dashboard deep-dive review (usability/styling/functionality) — findings only, no fixes applied

Reviewed the live dashboard (v1.10.0, port 4977) via full-page light/dark/mobile screenshots plus a read of every `src/Miller.Dashboard` component, endpoints, CSS, and JS.

### Confirmed bugs
- **"common misss" typo**: `DashboardFormat.FormatCount` naive `+s` pluralization × "common miss" singular (`WorkspaceOnboardingPanel.razor:36`) renders "10 common misss".
- **Home hero metric wrap**: `.hero-metrics` is `repeat(3, 1fr)` (dashboard.css ~302) but home passes 4 metrics → 4th ("symbols") wraps to a ragged second row. Workspace page has 3, fits.
- **Mobile (≤390px) clipping**: right-edge clipping on both pages — detail-action buttons, language pills, JSON links, right-aligned numbers all cut; home rows show large blank gaps. Breakpoints at 900/760/640 exist but don't fully contain content.
- **Remove-confirm collapses under the user**: `WorkspaceRemoveConfirm` details sits inside `#workspace-index`, which polls/outerHTML-swaps every 30s; open state is NOT in the persistence store (only stale-collapse + issue-details are), so an open confirm silently closes mid-decision.
- **Bare 404s**: `/workspace?workspace_id=bogus` returns text/plain with no styled page/back link.

### Presentation issues
- Onboarding "Hot targets" renders raw `unresolved_hash` as both name and detail for half the rows (TargetName falls back to Confidence).
- Pattern inventory: 33 rows each with a redundant "1 pattern; languages: X; captures: X" line.
- REMOVE… button repeated on all 77 home rows in the primary position under the name.
- READY rows with "—" files/symbols (facts missing) look contradictory; `.hermes` row shows 0/0 READY.
- Sort affordance invisible until first click (caret only on aria-sort); aria-sort applied to button not columnheader role; ws-index is div-soup (no table roles).
- Recent-errors rows wrap inconsistently (duration sometimes below-left, sometimes right).

### Opportunities
- Refresh index POST is fully synchronous (`TryRefreshWorkspace` in request) — long converge = spinner with no progress/timeout.
- Whole row not clickable despite "click to inspect" hint; no last-activity column; telemetry table not sortable; JSON links navigate away in same tab; Cancel in remove-confirm reloads page (loses in-memory filter store); notices auto-cleared by next 30s poll.
- Hardening: `open-folder`/`refresh` POSTs lack antiforgery (cross-origin form POST can trigger); no Host-header validation (DNS-rebinding could read JSON endpoints).

### What's solid
light-dark() CSS token system, state persistence across htmx swaps, visibility-paused polling, toasts, antiforgery on remove/prune, XSS-escaped notices, loopback-only binding, SVG favicon endpoint, degrade-not-500 discipline.
