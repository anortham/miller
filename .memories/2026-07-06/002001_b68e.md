## Text-search miss diagnosis telemetry split

- **WHAT:** Added privacy-safe empty-result telemetry classification for `search` and `content search`, plus targeted compact hints for obvious wrong-mode or too-short text searches.
- **WHY:** The next Miller priority is diagnosing high empty-result rates in text search without widening default symbol ranking or storing raw queries.
- **HOW:** Empty telemetry rows now keep the existing `empty_reason` and add enum-style `query_shape` plus `empty_diagnosis` labels. `search` classifies empty source/content/symbol routes, and `content search` uses the same helper for imported and workspace corpus misses. Text empty hints now point at `mode=content`, `mode=source`, `mode=file`, or a longer query only when the query shape supports that handoff.
- **IMPACT:** Aggregation can separate likely mode mismatches, weak query shape, and true no-hit buckets while preserving query privacy and existing result JSON shapes.
