## v1.27.0 post-release audit found a live CT retry loop

- **WHAT:** Exercised all Miller MCP tools across four real repositories and a disposable edit/content lifecycle fixture. Ran the committed seven-workload performance replay on a quiet machine.
- **WHY:** Validate the published v1.27.0 runtime after release and detect regressions missed by package gates.
- **HOW:** Used the live `1.27.0+700c42cb312c` server, fixed warm workloads with three measured runs, telemetry error review, and read-only CT database/log analysis. Stopped the malfunctioning CT daemon after it repeatedly retried the full 9,368-case suite.
- **IMPACT:** Core tools and cross-language behavior are healthy. Performance matches the pre-release baseline, though known absolute 2 s budgets remain exceeded for context, impact, trace, and leader startup. A real CT SQLite FK failure remains under diagnosis; the isolated importer path alone does not reproduce it.
