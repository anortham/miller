## Task 5: Not-found near-miss candidates + scope-mask fallback (resolver UX)

**WHAT:** `SmartTargetResolver` now never returns a bare not-found for a resolvable name, and offers up to 3 near-miss suggestions when a name truly does not resolve.

- `TargetResolution.NotFound` gained additive optional fields `Suggestions` (`IReadOnlyList<IndexedSymbol>?`) and `ScopeMissed` (`string?`) plus a shared `RenderMessage()` used by inspect/impact/trace (EditService untouched — it keeps its own message and compiles unchanged because the extension is additive).
- Scope matching normalizes separators (`\` → `/`, mirroring `ToolSearchFilters.NormalizePath`) and compares OrdinalIgnoreCase, so a Windows backslash scope narrows instead of zeroing out matches.
- When a scope still filters all matches to zero but the name resolves unscoped (exact-name or qualified-member), the resolver returns `NotFound` with the out-of-scope matches as suggestions + the missed scope.
- True not-found: near-miss candidates come from `ISymbolLookupIndex.Search` (BM25/FTS recall), filtered to genuinely close names (case-insensitive exact first, then containment of the target or its last dot segment), capped at 3 (`MaxSuggestions`).

**WHY:** Windows dogfood showed agents could not self-correct in one turn: a backslash `scope` silently reported "not found" for an existing symbol, and misspelled targets got zero candidates.

**HOW (key decisions):**
- Extended `NotFound` rather than adding a new resolution case — lighter and keeps EditService's `case TargetResolution.NotFound:` source-compatible.
- Near-miss recall via existing `Search()` (all three `ISymbolLookupIndex` implementers already provide it) instead of a new interface member — no FTS/projection/table changes needed. Tokenizer emits the full lowercased identifier, so wrong-case exact and component-overlap typos both recall.
- Inspect JSON shape is additive: `closest` array + `scope_missed` only when present.

**IMPACT:** inspect/impact/trace not-found messages become `'{target}' not found. Closest: A (path:line)…` or `'{target}' not found in scope 'X'. Found in: …`. Fast suite green (1916 passed, 15s).
