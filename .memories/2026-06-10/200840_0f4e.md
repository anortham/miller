## Central missing-required-param catch for all MCP tools (Task 2)

**WHAT:** `TelemetryCallToolFilter.Create` now catches the Microsoft.Extensions.AI marshaller's missing-required-parameter shape (`ArgumentException` with `ParamName == "arguments"` and message "missing a value for the required parameter '<name>'") at the single tools/call choke point and returns a friendly `CallToolResult { IsError = true }` naming the missing parameter, with a one-line usage example for inspect/search/context/trace/edit (generic hint for unmapped tools). Telemetry still records `outcome=error`, `error_kind=ArgumentException`. All other exceptions keep the record-then-rethrow-for-SDK-redaction path.

**WHY:** Windows dogfood session showed agents retry-looping on the opaque protocol-level "An error occurred invoking 'inspect'." when calling `inspect`/`trace`/`edit` without `target` or `search`/`context` without `query`. The v0.3.2 operation-defaults fix didn't cover tools whose required param has no sensible default.

**HOW:** New `catch (ArgumentException ex) when (TryGetMissingRequiredParameter(...))` ahead of the existing catch-all in the filter; parameter name parsed from the message between the marker quote pair; static `ToolUsageExamples` map for the five mapped tools. No new seams — error shaping stays at the same choke point as telemetry, covering every current and future tool.

**Verification (TDD, in isolated worktree because parallel task workers had the shared tree's test project temporarily uncompilable):**
- RED: new in-process MCP round-trip test (real `InspectTool` via `WithTools<InspectTool>()`, `{}` args) failed with the opaque redacted message — exact dogfood symptom reproduced.
- GREEN: `dotnet test --filter FullyQualifiedName~CallToolFilterTelemetryTests` → 5/5 passed.
- Fast suite `scripts/test.sh` at HEAD + exactly these two files: 1894 passed, 0 failed, 19s.

**IMPACT:** Agents now get an actionable one-line hint (e.g. `inspect requires 'target'. Example: inspect(target="WorkspaceTool.ResolveTarget")`) instead of an opaque error, ending the retry loop for all five affected tools and any future tool with required params.
