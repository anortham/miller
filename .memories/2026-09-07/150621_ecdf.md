## Agent usefulness review of Miller 1.28.1 written

**WHAT:** `docs/findings/2026-09-07-agent-usefulness-review.md` plus a pointer in `docs/README.md`. Answers six questions from an AI coding agent's standpoint: server instructions and tool descriptions, session hooks, CT awareness and adoption, per-tool accuracy/speed/token cost, reasons to stop using Miller, and gaps.

**WHY:** The user asked for a thorough agent-standpoint evaluation of the last month of work, documented as findings.

**HOW:** Three workflow batches (5 static reviewers; 9 live tool trials plus a Miller-only vs raw A/B on 5 tasks; 12 adversarial verifiers plus 3 critics), a live CT trial, 30 days of telemetry, disk and registry inspection. Every headline claim was verified by a refuter; corrected numbers are in the doc's "Corrected claims" section. No repo edits were applied (all `edit` calls were previews).

**Key discoveries:**
- Every default MCP read prints `freshness: refresh_pending` on a fresh index from the plugin reader and never clears (`WorkspaceIndexProvider.cs:1044`, `WorkspaceFreshnessView.cs:28`); rule 6 then triggers a 2 s lock_busy refusal.
- CT first contact after a 282-file gap: run request unacked, loop silent 11 min 7 s inside `SelectAtRevision` (3 selections, all discarded as Unknown), status calls it wedged and hints `stop`, which would have discarded the work. Bare fast suite: 65 s wall. Warm explicit run: 52 s.
- Impact compact renders tests last and cuts at 6,000 chars; `via=` hashes are 50% of bytes. The A/B 6x token gap was mostly this one shape defect; without it 1.56x.
- Overloaded methods return 0 refs everywhere (QueryTimeResolver single-candidate rule).
- `ContentCorpusWriter.IsTestPath` misflags 114 sources (e.g. `InspectTool.cs` via "spec"), hiding production hits in `mode=source`.
- Edit floor 2.3 to 2.7 s per call on this index from a transient `WorkspaceIndexProvider` reloading the full projection.
- Disk: `~/.miller` 55 GB; family store retains 1.81 M symbols for 224,700 live.
- Only 3 of 227 applied edits in 30 days were followed by a `tests run` call.

**IMPACT:** Ranked recommendations (12) in the doc; the CT daemon for this workspace is now running and idle (it was stopped before the review). Product decisions flagged for the owner: tests rule placement, impact compact paging, razorback table overlap, store retention.
