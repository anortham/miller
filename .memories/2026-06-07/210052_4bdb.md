## Completed content corpus Phase 4 web workflow

- **WHAT:** Added Miller web research support on top of the content corpus: web markdown imports, URL metadata, kind-scoped web search/list, bounded reads, CLI support, MCP tool support, and a new mirrored `miller-web-research` skill.
- **WHY:** Phase 4 needed browser-fetched web pages to become searchable/readable through Miller without writing page artifacts into the repo or dumping full markdown into agent context.
- **HOW:** Kept network fetching outside Miller in the skill layer via `browser39`; added `ContentCorpusExternalStore.ImportMarkdown()` with `content_kind=web`, stable `web:` source ids, URL persistence, and `content search/list --kind web`; extended tests across store/tool/CLI/plugin/instructions.
- **IMPACT:** Agents can fetch pages to temp markdown, import them into `.miller/content.db`, search concise snippets scoped to web content, and read bounded line windows. This also preserves the same content corpus path Eros can later consume for semantic search.
