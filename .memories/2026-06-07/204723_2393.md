## Completed Phase 3 large external file workflow

- **WHAT:** Added a Miller `content` workflow for importing, searching, reading, listing, and removing external text files such as logs, CI output, generated reports, and large JSON/text dumps.
- **WHY:** Agents need a token-efficient way to inspect large text files without reading the whole file into context, and the workflow should feed the same `content.db` corpus model used by source/docs/config search.
- **HOW:** Implemented `ContentCorpusExternalStore`, unversioned FTS corpus opening for external-only content, MCP `ContentTool`, CLI `miller content <import|search|read|list|remove>`, DI/tool registration, server instructions, and mirrored `miller-large-file` skills under `.agents/skills` and `skills`.
- **IMPACT:** Phase 3 acceptance criteria are complete: external imports do not print full content, search returns snippets, read returns bounded line windows, remove deletes source/chunk/FTS rows, list shows source metadata, caps require explicit `max_bytes` overrides, and plugin skill mirrors pass.
