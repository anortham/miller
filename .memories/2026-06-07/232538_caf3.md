## Fixed Windows CI failure after v0.2.0 push

- **WHAT:** Diagnosed and fixed the `windows-fast` CI failure in `CliDispatchTests.Content_Export_SupportsKindAndContentWorkspaceFilters`.
- **WHY:** The test failed on Windows because `content export` JSONL already ended with `\n`, and `CliDispatch.Content` wrote it through `TextWriter.WriteLine`, appending the platform newline `\r\n`. Splitting on `\n` left a standalone `\r` item, so `Assert.Single()` saw two items.
- **HOW:** Added a CLI output helper that writes newline-terminated output as-is and only uses `WriteLine` for non-newline-terminated output. Added regression assertions that JSONL export ends with one newline and not an extra blank platform newline.
- **IMPACT:** Fixes the Windows-only CI failure without changing content corpus data or indexing behavior.
