## Implemented scoped search fallback hints

Filtered search misses now recover without making successful search output larger.

- **WHAT:** Added compact out-of-scope fallback hints for symbol, content, and source-region searches when `file_pattern` or `language` filters remove every otherwise matching hit.
- **WHY:** Token-efficient defaults only work if agents can recover from scoped misses without guessing or issuing several follow-up searches.
- **HOW:** `SearchTool.Run`, `RunContent`, and `RunRegions` keep strict scope semantics (`renderedCount` remains 0 and JSON remains `[]`) while compact output shows up to 3 outside-scope candidates using the existing result shapes.
- **IMPACT:** Closes the scoped-miss UX part of the post-beta search-quality TODO; remaining search-quality decisions are stale copied Julie cases and possible JSON file-level result objects.
