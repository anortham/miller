## Added Miller search-quality comparison runner

- **WHAT:** Added `tools/Miller.SearchQuality`, a local cross-tool runner that compares Miller, Julie, and Eros against hand-labeled search cases and writes generated cases/results under `.miller/eval/search-quality/`.
- **WHY:** Post-beta search quality needs repeatable scoring against multiple local repos without committing benchmark corpora or run artifacts.
- **HOW:** Implemented provider adapters for `miller`, `julie`, and `eros[:backend]`, normalized each provider's output into common hits, scored first matching rank with top1/top3/top5/MRR, added local `init` and `run` CLI commands with repo/case/tag filters, and documented usage in `docs/search-quality-runner.md`.
- **IMPACT:** We can now run focused Julie/Miller/Eros search comparisons over `hermes-agent`, `openclaw`, and `MyraNext`; local starter cases and JSON artifacts remain ignored under `.miller/`.
