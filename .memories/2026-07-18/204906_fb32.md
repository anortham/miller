## Windows review + CI smoke coverage for live bridge tests

**WHAT:** Windows-focused review of the 2.16.0 adoption found no blockers; added `LiveBridgeTraceTests` to the `windows-scale-smoke` CI filter.

**WHY:** The v1.11.0 release shipped a Windows crash (extended-length `\\?\` root paths URI-parsed by XmlReader) and needed a next-day patch — user asked for a Windows sweep before pushing. Review confirmed the adoption touches none of that class (pin data, test code, read-only SQL, docs), the Windows zip digest/layout match the pin template, and forward-slash path assertions are Windows-proven via the v1.11.1 `test.ps1 scale` verification. The one gap: bridge Scale tests had zero automatic Windows CI coverage (windows-fast excludes Scale; smoke filter covered only leadership/WAL/rebuild).

**HOW:** Appended `|FullyQualifiedName~LiveBridgeTraceTests` to the windows-scale-smoke dotnet test filter (schedule/dispatch-only job); verified locally the filter selects 27 tests including `BackendHttpV2160Group`.

**IMPACT:** Windows bridge-path regressions (path separators, CRLF fixtures, extractor path emission) now surface in scheduled CI instead of only the manual pre-release Windows run.
