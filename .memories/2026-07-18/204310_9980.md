## Strengthened v2.16.0 bridge test per Codex review

**WHAT:** Reworked `BackendHttpV2160Group_DeferredHttpClients_LiveBridges` so every deferred client is proven to bridge individually.

**WHY:** Codex review of the adoption commit found a P2: labels and per-server-file hits were asserted independently, so one client failing to bridge could hide behind a sibling hitting the same server file (and Finch's absolute-URL fixture provably never bridged).

**HOW:** Each of the 12 clients now lives in its own fixture file (own import gate, own containing symbol — edges dedupe by symbol pair, so per-file isolation is load-bearing); a new `HitsFrom` helper mirrors `HitsInto` over `Edge.SourceRef.FilePath`; the test asserts a High verb-known edge FROM each client file. Discovery: Finch DOES emit `url_kind=path` facts for path literals (`Finch.build(:get, "/ex/users")`), so it joins the bridge proof instead of staying label-only.

**IMPACT:** A regression in any single deferred client's emission or bridging now fails the test by name. Fast suite 3598 + scale 54 green.
