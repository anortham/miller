## Codex pre-release review of v1.10.0..main — findings triaged, 3 accepted fixes applied

**WHAT**: Ran the pre-release gate for the dashboard release: full suite (fast 3589 + scale 52, green), then a Codex CLI read-only review of the whole v1.10.0..HEAD range (15 commits, 53 files). Codex verdict was BLOCKED with 3 major + 2 minor; triage accepted 3, rejected 2 as documented deliberate design.

**Accepted & fixed:**
- **Remove-popover clipping** (major, real): `.panel { overflow: hidden }` clips the absolutely-positioned confirm form below the last/only workspace row. Fix: `.ws-index-panel:has(.ws-row-actions details[open]) { overflow: visible; }` + source-assertion test `WorkspacePanel_StopsClippingWhileARemovePopoverIsOpen`.
- **Empty-registry 404 miss** (minor, real, root cause deeper than Codex said): `SelectWorkspace` (DashboardData.cs:1384) *echoed* the requested id back when the registry was empty, so `/workspace?workspace_id=bogus` rendered a 200 shell. Fixed the echo (return null on empty registry), removed the now-redundant `Workspaces.Count > 0` guard in DashboardEndpoints, added `WorkspaceGet_WithUnregisteredIdAndEmptyRegistry_ReturnsStyledHtml404` (written first, confirmed failing against the endpoint-only fix — that's how the echo was found).
- **Release packaging gate gap** (major, found independently before Codex confirmed): release.yml verified alpine/theme-init/dashboard-site assets but NOT `lib/htmx/htmx.min.js` or the T1-added `lib/idiomorph/idiomorph-ext.min.js` — a package missing idiomorph would pass smoke and silently break every morph swap. Added both to bash + pwsh verification blocks and pinned in `ReleaseWorkflow_VerifiesVendoredDashboardScriptAssets`.

**Rejected (documented deliberate design, not blockers):**
- "Unowned Task.Run refresh job" — DashboardRefreshJobs doc comment states the contract: local scope, no persistence, restart forgets in-flight jobs; underlying converge machinery is crash-tolerant by design (indexer lock liveness, WAL, atomic promote).
- "Peek consumes terminal result" — single-observation is the designed render-once/stop-polling mechanism; two-tabs-same-workspace is an accepted local-dashboard edge.

**Verification**: fast suite 3591/3591 (26s, under 30s ceiling; earlier 40s trip was build contention — slowest tests all pre-existing), scale 52/52, build 0 warnings.

**IMPACT**: Release changeset is code-ready pending: fast suite tripwire is healthy, packaging gate now covers the new vendored JS. Still required before release: merge this follow-up commit to main, version bump 1.10.0 → 1.11.0 (props + 5 manifests + 2 version-pinned test files), push + publish in same session (marketplace rule), all user-approval-gated.
