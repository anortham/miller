## Removed HOL plugin scanner from CI

- **WHAT:** Removed the `HOL plugin-scanner (lint)` third-party action step from `.github/workflows/ci.yml`.
- **WHY:** The scanner was configured with `min_score: 0` and `fail_on_severity: none`, so it was not acting as a meaningful gate and was consuming GitHub Actions time after `scripts/test-plugin.sh` already validated plugin manifests and launcher behavior.
- **HOW:** Deleted only the `hashgraph-online/ai-plugin-scanner-action@v1` step. Kept `scripts/test-plugin.sh`, Node setup, and the rest of the CI workflow unchanged.
- **IMPACT:** Push/PR CI should be shorter and have one fewer third-party dependency while retaining deterministic plugin validation.
