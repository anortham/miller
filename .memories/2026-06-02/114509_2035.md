## Added Miller release workflow

- **WHAT:** Added a GitHub release workflow that builds non-AOT self-contained Miller packages for the four pinned julie-extractors platforms and includes exactly the matching `julie-extract` binary for each platform.
- **WHY:** Miller release binaries need to follow julie-extractors' platform matrix without bloating artifacts by bundling unrelated extractor binaries.
- **HOW:** Added `.github/workflows/release.yml` with native runner/RID mappings, per-platform restore, publish, packaging, upload, and GitHub release creation. Added a contract guard in `MillerExtractContractTests` that checks the workflow matrix matches `scripts/julie-pins.json`.
- **IMPACT:** Release packaging now has a durable CI path and a regression guard against platform-matrix drift.
