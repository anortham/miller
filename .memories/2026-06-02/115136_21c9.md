## Fixed Linux julie-extract archive restore

- **WHAT:** Patched `scripts/restore-julie-extract.sh` to stage release archives and locate `dist/<triple>/julie-extract` with a leading-path-tolerant `find` instead of asking tar for an exact member path.
- **WHY:** The Linux julie-extractors v2.0.0 archive lists entries with a leading `./`, so GNU tar rejected the previous exact `dist/x86_64-unknown-linux-gnu/julie-extract` member path in GitHub Actions.
- **HOW:** Replaced direct member extraction with a temporary staging directory, exact path lookup under `*/dist/${TRIPLE}/julie-extract`, binary move, and cleanup trap. Added a fast regression test that creates a local fake Linux archive with `./dist/...` and runs the restore script with fake `curl`/`uname`.
- **IMPACT:** The release workflow can restore the Linux extractor the same way macOS already did, while the fast suite now guards the archive-prefix edge case.
