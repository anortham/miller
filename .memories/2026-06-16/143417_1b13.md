## Added release-ready telemetry dimensions for future audits

- **WHAT:** Added schema-compatible telemetry enrichment before the next Miller release. Tool rows now populate `op` more consistently and add query-safe metadata in `metadata_json` for mode/operation, route, format, buckets, input-shape flags, `empty_reason`, and `error_category`.
- **WHY:** The initial telemetry audit showed that future improvements need better dimensions than tool/outcome/exception type. This captures useful aggregate facts without storing raw queries, targets, paths, snippets, or source text.
- **HOW:** Added structured metadata helpers on `TelemetryScope`, central error categorization in `SetError`, tool-level op/shape enrichment for `search`, `content`, `patterns`, `inspect`, `trace`, `impact`, `context`, and `edit`, and updated the findings doc with the next-pass query contract.
- **IMPACT:** The next telemetry review can group empty results/errors by `op`, route, safe input-shape flags, `empty_reason`, and `error_category` directly in SQLite instead of reconstructing causes from logs.
