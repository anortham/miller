## Prepared Miller v0.3.5 release candidate

- **WHAT:** Added watcher-side ignore policy handling for built-in ignored segments, `.gitignore`, `.julieignore`, nested git roots, ancestor `.gitignore` watchers, and ignore-file-triggered delta scans. Bumped Miller package/plugin metadata to `0.3.5` and added `docs/release-notes/v0.3.5.md`.
- **WHY:** Windows Visual Studio workspaces were producing repeated recoverable `file_outside_root` delete retries for gitignored `.vs` cache files. The live watcher needed to respect the same ignored paths before handing per-file operations to `julie-extract`.
- **HOW:** Introduced `WorkspaceIgnorePolicy`, routed `WatchPathFilter` through that policy, taught `IndexerService` to force rescans for ignore-policy changes and watch ancestor `.gitignore` files, and updated focused watcher/indexer tests plus version assertions.
- **IMPACT:** The release candidate now suppresses `.vs` watcher churn, keeps ignored/unignored file state convergent after ignore-file edits, and has aligned v0.3.5 plugin manifests for release packaging.
