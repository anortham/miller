## Added indexed-source stale hint for edit

`edit replace_text` now has a focused diagnostic path for the case where `old_text` is missing from the current disk file but still appears in Miller's indexed source corpus.

- **What:** Added an advisory `IndexedSourceTextReader` over `content.db` source chunks and wired `EditService` to use it only for `replace_text` text-not-found failures.
- **Why:** Agents previously saw only `old_text not found`, which did not distinguish a bad target string from a stale index/corpus situation.
- **How:** Disk remains authoritative for edit planning and applying. The new reader is read-only, fail-closed, and returns only a line hint from indexed source chunks; it never supplies write content.
- **Impact:** The edit tool can now tell agents to wait for the watcher or run `workspace refresh` when indexed source still contains the requested text, without weakening freshness or TOCTOU guards.
