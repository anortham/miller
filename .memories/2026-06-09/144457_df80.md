## Implemented Miller workspace health first slice

- **WHAT:** Added `workspace health` for MCP and CLI with compact and JSON output, plus `workspace health --json` in capabilities.
- **WHY:** The data opportunities plan identified workspace health as the best first Miller-owned feature because it turns existing index, sidecar, extraction-quality, and telemetry facts into a trust/readiness verdict for agents and future Eros consumption.
- **HOW:** Added a cheap `WorkspaceHealthReader` over grouped SQLite counts, a server-level health fact model with warning/state calculation, pure `WorkspaceRender.Health` output, MCP and CLI dispatch wiring, telemetry outcome aggregation, and a `docs/contracts/workspace-health-v1.md` contract. Kept the registered-workspace health path off full graph hydration and added tests that drop `relationships` to guard that.
- **IMPACT:** Agents can now call `workspace(operation="health")` or `miller workspace health --json` to see readiness, parse diagnostics, capability gaps, sidecar states, and telemetry outcomes without private SQLite reads or Eros-specific behavior.
