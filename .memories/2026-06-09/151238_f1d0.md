## Implemented Miller trace JSON contract

### WHAT

Added stable structured JSON output for Miller trace results across `auto`, `path`, and `bridge` modes.

- `trace(format="json")` now works for MCP callers.
- `miller trace <target> --json` now works for CLI callers.
- `capabilities --json` advertises `trace --json` and a versioned `trace` JSON contract entry.
- Added `docs/contracts/trace-json-v1.md` and updated Eros/public docs.

### WHY

Eros and other local integrations need machine-readable trace nodes, links, bridge provider status, confidence, and diagnostics without parsing compact human text.

### HOW

Kept the existing performance split intact:

- auto/path CLI JSON still use the lightweight `ISymbolLookupIndex` + `SqliteSymbolGraphIndex` path.
- bridge JSON still uses the full repository bridge graph because provider-scoped bridge evidence lives there.
- Compact output remains unchanged; JSON is opt-in through `format=json` / `--json`.

### IMPACT

This completes the data-opportunities plan's stable JSON trace contract slice and gives Eros a documented route/entity/change-risk feed to consume through public Miller contracts.
