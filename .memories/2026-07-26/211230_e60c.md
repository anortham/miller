## Completed Miller request, paging, diagnostics, and source-hygiene repair

Miller tool contracts now reject invalid enum-like inputs, page losslessly within relevant populations, and preserve typed diagnostics across render and telemetry paths.

- **What:** Added discriminated population continuations to Inspect file listings, Patterns list/summary/search, and Trace refs; Trace JSON is schema 2 without the duplicate `references` union and stays under 12 KiB.
- **Why:** Global-revision cursors, silent enum fallbacks, duplicate JSON payloads, and untyped Edit/Content failures made agent results stale, ambiguous, or wasteful.
- **How:** Canonical row ordering and fingerprints bind tokens only to the relevant population and exact request. Trace advances by the rows actually emitted after budget shrinking. Patterns free-text fan-out uses fair round-robin family selection. Edit/Content attach `ToolDiagnostic` to compact/JSON output and stamp outcome/class/error-channel telemetry.
- **Source hygiene:** Replaced raw NUL and `0x01` bytes with C# escapes that preserve runtime values, and expanded the convention gate to all tracked text files.
- **Impact:** Inspect, Patterns, Trace, Edit, and Content now expose strict, replayable, token-efficient contracts to MCP and CLI callers.
