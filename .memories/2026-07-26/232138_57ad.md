## Removed legacy reference evidence adapters

- **WHAT:** Deleted the `ContextTool.RunReferenceAware` overload that accepted `SymbolRef` readers, deleted `LegacyInboundEvidence` and `LegacyOutgoingEvidence`, deleted the analogous `TraceTool.Run` overload and `LegacyReferenceEvidence`, and migrated all affected tests to typed `ReferenceEvidence` and `OutgoingReferenceEvidence` fixtures.
- **WHY:** The adapters fabricated `legacy:*` site identifiers and `legacy_name_projection` provenance, hiding producer-owned evidence and weakening the schema-5 reference contract.
- **HOW:** Added explicit fixture builders with stable non-empty producer site IDs, real spans, `IsExact`, and `SiteProvenance`; retained fallback resolution semantics where the tests exercise name fallback; added a convention test forbidding the legacy adapter signatures and fabricated markers in Context and Trace.
- **IMPACT:** Context and Trace now consume the typed evidence contract directly end to end. Future regressions that reintroduce the legacy projection fail the fast suite.
