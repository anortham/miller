## Made patterns paging lossless

- **WHAT:** Exact-id and free-text pattern searches now page across the full matching population instead of a limit-sized sample. CLI and MCP continuations preserve every row, canonical identity, and fair family ordering.
- **WHY:** The reader applied `limit` before continuation construction, so rows beyond the first sample were permanently unreachable even though output reported them as omitted.
- **HOW:** `PatternFactsReader` streams the complete filtered population inside one read transaction, incrementally hashes canonical row identities, and retains only the requested offset window. Query search uses a SQLite `ROW_NUMBER()` family rank and stable interleaving order. `PatternsTool` advances continuation offsets by rows actually emitted after the 12 KiB budget, while cursor peeking validates token integrity before loading the requested page and full identity validation rejects stale or wrong-kind tokens.
- **IMPACT:** A 38,060-row live exact search now emits a continuation at limit 1 and replay returns the distinct second row. Agents can exhaust exact and free-text pattern results without duplicates, loss, or unbounded materialization.
