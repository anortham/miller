## Fixed silent lexical scoring in the live semantic evaluator

`run-live-arm.py --arm production` omitted forced-arm dispatch by design, so a missing vector artifact or semantic runtime could return a successful lexical result and be scored as production semantic evidence.

- **Root cause:** The runner treated any zero-exit production search as valid semantic evidence even though normal product routing may fall back to lexical.
- **Fix:** Preflight every mapped corpus for production, semantic, and hybrid runs with a fixed public forced-hybrid query before reading the query set; lexical runs skip the preflight.
- **Evidence contract:** Live result and latency rows now emit explicit integer `policy_version: 2`; the generic retrieval scorer remains unchanged and ignores the extra producer metadata.
- **Privacy:** The preflight is independent of query rows and runs before `read_queries`, so missing semantics fails before sealed query text is loaded or sent to a subprocess.
- **Docs:** Retrieval and fusion-arm README parity/status text now describes the fail-loud policy and lead-owned final rank-parity gate.
- **Impact:** Production evaluation can no longer silently generate believable lexical-only semantic reports.
