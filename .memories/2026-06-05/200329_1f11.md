## Improved Miller file-mode search shape

### WHAT

Completed the next Julie-vs-Miller search-quality matrix row for path and basename queries.

- Compact `mode=file` now renders `File match: <path>` for exact/single-file hits.
- Ambiguous path/basename queries now render `File matches:` grouped by file.
- `FindByFilePathFragment` now returns one representative symbol per matched file before extra symbols from earlier files.
- JSON file mode remains symbol-row based for compatibility.
- Updated `TODO.md` and `docs/findings/2026-06-05-julie-vs-miller-search-quality-matrix.md`.

### WHY

The previous file mode found the right file but presented only symbol rows, which was less direct than Julie. Broad basename queries like `mod.rs` also spent the page on one file's symbols instead of showing multiple matching files.

### HOW

- Added red tests for compact file-mode headers/grouping and JSON compatibility.
- Added a lookup-level red test proving representative-per-file ordering for ambiguous file fragments.
- Implemented a compact file-mode renderer separate from symbol search compact rendering.
- Changed shared file-path lookup ordering so all backends benefit.

### IMPACT

Miller file/path search is now more useful to agents for file discovery without widening symbol ranking or changing structured JSON contracts.
