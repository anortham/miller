## Recorded Miller search/content beta dogfood decision

### WHAT

Dogfooded the restarted Miller server and patched one additional search-quality issue.

- Added `docs/findings/2026-06-05-search-content-dogfood.md` with representative symbol and `mode=content` queries.
- Updated the beta checklist to mark local Miller search/content dogfood complete and record the projection decision.
- Patched file-mode/path-like search so `import`/`module` rows are hidden, matching the natural-language low-signal filter.
- Updated `TODO.md` and the symbol-search design doc so they no longer imply symbol projection widening is required before beta.

### WHY

Dogfood showed the correct beta split: symbol search works for code symbols and file/path intent; `mode=content` works for prose/docs/env-var/source-text snippets; `regions=` remains the scoped source-region path. The only immediate quality failure was path-like file search returning imports before real symbols.

### HOW

Used MCP dogfood queries against the restarted server, then added a focused failing unit test for file-mode import/module noise and patched `SearchTool.Run` so `fileMode` enables low-signal kind filtering and 500-row overfetch.

### IMPACT

The beta checklist can move past the symbol-projection-widening question. Next beta work should shift to large-repo first-read dogfood, CLI/README docs, CLI smoke coverage, restore/package clarity, and final gates.
