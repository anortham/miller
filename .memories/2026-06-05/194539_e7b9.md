## Added grouped compact output for context bundles

### WHAT

Extended the beta compact-output cleanup beyond `search` and file-level `inspect` into `context`.

- `ContextTool` compact text now groups selected bundle candidates by file.
- Candidate rows omit repeated file paths and use `:line name kind hop=N` plus signature.
- JSON output still carries per-candidate `file`, `line`, `hop`, `signature`, and `symbol_id` fields.
- `TODO.md` and `docs/findings/2026-06-05-tool-output-token-savings.md` now record the `context` follow-up slice.

### WHY

Dogfood showed the same token waste pattern across multiple tools: repeated query names, repeated signatures, and repeated file paths make compact output harder for coding agents to scan.

### HOW

- Added regression coverage for grouped compact `context` output and unchanged JSON file fields.
- Kept context packing conservative by costing each candidate with a file-path-inclusive line even though compact rendering prints the path once per group.
- Verified the Release CLI sample for `context "SearchTool InspectTool compact output renderers tests token savings" --budget 3500` renders grouped-by-file output at 7,642 bytes.

### IMPACT

This continues the Julie-style compact-output methodology across Miller's high-use read tools while preserving complete JSON contracts for programmatic callers.
