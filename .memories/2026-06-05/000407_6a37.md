## Refocus + source_regions/pillar-3 designed then DEFERRED on an upstream gap

Session refocused Miller's direction, then took the `source_regions` / pillar-3 scope-aware lexical search track through brainstorming → design → two Codex reviews → **deferral** when a live-data check proved it's blocked upstream.

### What happened
- **Refocused & reconciled the brief** to match `main`: FTS5 sidecar shipped default-on, projection split shipped, CLI open/remove + version shipped. Removed the stale "keep FTS5 parked" guardrail (now self-contradictory). Fixed the stale `project_search_collapsed_trigram` auto-memory + index hook (was a plan; it shipped).
- **Brainstormed source_regions** (capability = **Both**: region-scoped content search + symbol doc-comment; build = **Approach C staged**). Wrote `docs/plans/2026-06-04-source-regions-pillar3-design.md`.
- **Codex review #1** killed the "lean overlay on content search" premise: `mode=content` is **docs-only** (`ContentFileClassifier`), so it can't search source comments. Rewrote the design around a **region-text index in `search.db`** (slice file bytes at build time).
- **Codex review #2** + a live `symbols.db` query found the decider: julie-extract 2.1.0 emits `source_regions` only for **JavaScript** (187 JS rows, **0 C#**, **0 doc_comments**); `symbols.doc_comment` has 3,840 rows. A region-text index would be empty on C#/.NET.

### Decision
**Defer the Miller consumer until julie-extract 2.1.1** (user is adding all-language `source_regions` emission). Design is review-clean and marked DEFERRED with resume conditions baked into the doc (has_doc from `symbols.doc_comment`; CodeTokenizer token stream as FTS body; separate `MILLER_REGION_INDEX` flag + literal caps; `EnsureBuilt` needs workspaceRoot; fail-CLOSED region reads; per-language coverage warnings).

### New durable rule
Added **"Language parity (load-bearing product rule)"** to `CLAUDE.md` (synced to `AGENTS.md`): a julie-extract-backed feature isn't done until it works for ALL supported languages; verify per-language coverage before shipping.

### Impact
Two adversarial Codex passes + a data check caught an upstream block BEFORE any code was written — the reviews paid for themselves.
