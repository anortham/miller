## Capped compact impact likely-test output

Completed TODO item 9's first beta pass on tool-output token savings.

- **WHY:** Broad `impact` calls printed dozens of likely tests and consumed about 11 KB in compact mode, which is too expensive for routine agent context.
- **HOW:** Added a failing `ImpactToolTests` regression with 25 synthetic likely tests, implemented a private compact-rendering cap in `ImpactTool`, preserved full counts and complete JSON output, and recorded evidence in `docs/findings/2026-06-05-tool-output-token-savings.md` plus `TODO.md`.
- **IMPACT:** Broad compact impact outputs now measure about 3.7 KB while retaining the complete machine-readable JSON contract.
