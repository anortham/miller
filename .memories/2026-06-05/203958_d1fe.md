## Added scoped search filters for Julie parity

- **WHAT:** Added `file_pattern=<glob>` and `language=<lang>` filters to Miller search across symbol/file, content, and region result kinds. Content and region hits now carry language metadata so filters apply uniformly.
- **WHY:** Julie's scoped search was the remaining high-value token-efficiency gap: agents need small, correct result sets without raising `limit` or doing follow-up queries.
- **HOW:** Kept ranking narrow and deterministic by filtering after search ranking and before rendering. Added glob path matching in the tool layer, CLI/MCP parameters, CLI help, embedded Miller instructions, and project-local search-debug guidance. Updated TODO and the Julie-vs-Miller matrix to mark scoped filtering closed for the first beta pass.
- **IMPACT:** Miller can now narrow searches to known areas/languages without embeddings or broader symbol scoring, improving first-query precision for coding agents.
