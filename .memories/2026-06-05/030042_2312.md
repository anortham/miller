## Audited and repaired Miller search-sidecar trust gaps

### WHAT

Completed a full audit cleanup pass after suspected partially-completed search/source-region work. Patched concrete correctness and trust issues in the default-on symbol search sidecar and search rendering path.

- Bumped `SearchIndexWriter.SchemaVersion` to 4 and populated `symbols_trigram.qual_collapsed` with parent-chain qualified names.
- Changed `FtsSymbolSearchIndex` trigram lookup to search both collapsed short names and collapsed qualified names.
- Made `WorkspaceIndexProvider` repair a same-revision fallback cache entry when `search.db` appears after a first read.
- Added FTS smoke validation during `FtsSymbolSearchIndex.Open` so damaged FTS tables self-heal to in-memory search instead of failing at query time.
- Filtered low-signal `import`/`module` rows for natural-language symbol search while keeping them for single-identifier queries, with capped 500-row overfetch so useful rows can survive noisy top slices.
- Updated beta/source-region/search docs to reflect current code and remaining caveats.
- Made `SymbolSearchEvalScaleTests` build a fresh temp Miller corpus with the pinned extractor when the local `.miller/symbols.db` is missing or unreadable.

### WHY

The audit found several ways the repo could appear green while search behavior was still untrustworthy: empty qualified-name trigram data, stale docs, fallback cache pinning, route-to-disk despite damaged FTS tables, eval coverage that skipped too easily, and production phrase search polluted by import/module rows.

### HOW

Used test-first patches for the key bugs:

- Added failing writer/reader tests for qualified-name trigram recall, then populated/query `qual_collapsed`.
- Added failing provider tests for same-revision sidecar repair on both current and registered workspaces, then changed symbol-search cache entries to distinguish sidecar vs fallback.
- Added failing sidecar test for damaged FTS tables, then added open-time MATCH smoke queries.
- Added failing search renderer tests for natural-language import/module noise and noisy top-slice overfetch, then added post-fetch low-signal filtering with a 500-row cap.

### IMPACT

Miller's default search sidecar is safer and the beta checklist is more honest. Source-region indexing remains opt-in for beta. Remaining search beta work is measured real-workflow dogfood, deciding whether to widen symbol projection, content-search quality tuning, CLI/docs polish, and final beta candidate gates.
