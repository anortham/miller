## Applied compact-output lessons to file-level inspect

- **WHAT:** `inspect <file>` compact output now hides low-signal `import`/`module` rows by default, groups visible children by kind, and omits repeated file paths in each child row. Explicit `kind=import` / `kind=module` still shows those rows, and JSON still returns the complete child list.
- **WHY:** Dogfood showed file-level inspect could spend the first page on import rows and repeated `file:line` prefixes, which wastes agent context before surfacing real declarations.
- **HOW:** Added failing `InspectToolTests` for grouped compact output, explicit low-signal kind filters, and JSON completeness. Updated `InspectTool.RenderFile` compact branch only; JSON branch and symbol/full inspect paths remain unchanged.
- **IMPACT:** File inspection is now more useful as an agent orientation step: default compact output starts with classes/enums/methods/constants/fields and reports hidden low-signal counts instead of burying declarations behind imports.
