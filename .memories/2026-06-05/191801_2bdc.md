## Reduced compact search output noise

- **WHAT:** Changed compact search rendering for low-signal `import`/`module` rows to show `low_signal` instead of the full import/module signature. JSON output is unchanged and still carries full signatures.
- **WHY:** Exact-symbol ranking was fixed, but compact output for queries like `FastSearchTool` still repeated the queried symbol in every import signature, making agent-facing output noisy.
- **HOW:** Added a failing SearchTool renderer test, then updated `RenderCompact` to abbreviate low-signal rows while preserving normal signatures for concrete symbols and full data in JSON.
- **IMPACT:** Compact result shape is now easier to scan: definition row remains detailed, import/module rows remain visible but no longer echo repeated `use ... FastSearchTool` text.
