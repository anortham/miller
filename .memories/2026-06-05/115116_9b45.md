## Miller Beta Checklist: Dashboard Boundary And Cross-Platform Work

### WHAT

Advanced Miller beta readiness beyond search/CLI smoke coverage.

- Documented the dashboard split in `docs/plans/2026-06-05-beta-readiness-checklist.md`: Miller keeps a narrow local ops/status dashboard; Eros owns richer product intelligence UI.
- Added cross-platform compatibility as a beta checklist section.
- Added PowerShell mirrors for beta-critical scripts: `scripts/test.ps1`, `scripts/sync-agents.ps1`, and `scripts/install-hooks.ps1`.
- Added `ScriptPlatformConventionTests` so beta-critical shell scripts must have PowerShell mirrors and fail fast.
- Added a Windows fast-suite CI job using `scripts/test.ps1`.
- Updated `README.md` with CLI examples, text/JSON output expectations, Windows script commands, known beta limits, and troubleshooting.
- Updated `CLAUDE.md` and regenerated `AGENTS.md` so future agents use the PowerShell mirrors too.
- Closed checklist items for CLI examples, output expectations, MCP config/CLI install docs, README setup/troubleshooting, known beta limits, MCP restart non-blocking decision, pin sync, Unix restore evidence, and source-checkout beta package shape.

### WHY

Miller cannot be beta-ready as a .NET local code-intelligence core if normal setup/test commands are bash-only or if the Miller/Eros dashboard boundary is ambiguous. The beta should support real dogfood from source checkout on Unix/macOS and Windows PowerShell, while keeping richer Eros UI decisions outside Miller.

### HOW

Used a red/green convention test cycle: first added `ScriptPlatformConventionTests`, saw it fail on missing `test.ps1`, `sync-agents.ps1`, and `install-hooks.ps1`, then added the wrappers and reran green. Kept beta package shape as source checkout with platform restore scripts, leaving archives as release-readiness work.

### IMPACT

The beta checklist is down to Windows execution evidence only: run/verify `scripts/restore-julie-extract.ps1`, `dotnet build`, and `scripts/test.ps1` on Windows x64 or CI. Local Mac verification is clean.
