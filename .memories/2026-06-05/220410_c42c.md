## Tuned content search for beta dogfood

Completed TODO #4 content-search quality dogfood across Miller, julie-head-to-head, OpenClaw, and MyraNext.

- **WHAT:** Made `mode=content` more conservative for agent workflows: weak term-overlap misses now return `No results`, selected snippet lines must carry meaningful query-term coverage, token-phrase lines are boosted/preferred, and env-var/path/code-like content queries require the exact token phrase.
- **WHY:** Live dogfood showed large-app/source-comment/literal probes could return plausible-looking but wrong docs/config snippets, which hurts token efficiency because agents may trust a weak first hit.
- **HOW:** Kept the docs-like in-memory content projection narrow; changed scoring/filtering inside `ContentSearchIndex` without widening symbol search, merging result kinds, or adding a persisted content sidecar.
- **IMPACT:** Beta routing stays clean: symbols in `search`, docs/prose in `mode=content`, source comments/literals/env vars in explicit `regions=`. TODO #4 is closed; source-region default-on remains the separate follow-up.
