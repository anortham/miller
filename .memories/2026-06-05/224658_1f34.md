## Implemented beta-minimum dashboard

- **WHAT:** Replaced the hand-built dashboard HTML with static SSR Razor components and htmx fragments, added copied local assets, and made the dashboard show registered workspaces plus scoped per-tool telemetry in the page.
- **WHY:** Beta testers need to see captured Miller telemetry without opening JSON endpoints, and the dashboard was an open beta-readiness gate.
- **HOW:** Added `DashboardShell`, `DashboardContent`, `WorkspacesPanel`, and `TelemetryPanel`; moved workspace selection to a combined htmx fragment; served `dashboard.css` and vendored `htmx.min.js` from Release output; kept `/workspaces.json` and `/telemetry.json` stable; switched dashboard startup to a bare Kestrel `HostBuilder` to avoid default file-watch startup hangs.
- **IMPACT:** The dashboard now launches on loopback with `MILLER_DASHBOARD_PORT`, reads only registry/telemetry DBs for the main view, renders per-tool calls/avg/p95/max/errors/token estimates, and has dogfood evidence recorded in the beta candidate findings note. Also fixed fast-suite startup-scan tests by adding a test-only `IndexerService` watcher bypass so unit tests no longer depend on macOS `FileSystemWatcher` startup.
