## Tightened trace bridge target ergonomics

- **WHAT:** Added bridge-specific target resolution for route strings, table names, and file paths with exactly one bridge-connected symbol.
- **WHY:** MyraNext dogfood showed route-like targets such as `/api/messages/{messageId}/dismiss` were classified as files and returned a misleading message, even when a matching bridge route edge existed.
- **HOW:** `BridgeGraph` now exposes its admitted unique scored edges in deterministic order. `TraceTool` checks synthetic bridge nodes, route matches across `Hits` edge displays, and bridge-connected symbols in file targets before falling back to normal smart symbol resolution.
- **IMPACT:** Agents can now start `trace bridge` from a frontend route string, a table node, a single-symbol bridge file, or the usual symbol name/id without manual ID hunting.
