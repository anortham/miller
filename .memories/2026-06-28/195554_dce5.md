## Julie vs Miller edit adoption investigation

### WHAT
Created `docs/findings/2026-06-28-julie-miller-edit-adoption.md` with evidence comparing Julie edit-family adoption to Miller `edit` usage.

### WHY
The user wanted to understand why Julie's edit tools got real use while Miller's single `edit` tool is almost never called, without turning Miller into a Julie clone.

### HOW
Reviewed Julie 90-day usage, Julie `.julie/logs` edit-family calls, Miller `~/.miller/telemetry.db`, Julie edit skill/server instructions/tests, and Miller edit instructions/tool/service/tests. Key finding: Julie adoption was dominated by `edit_file`, not symbol rewrite or rename. Julie won because it made arbitrary text edits cheaper than Read/Edit via strong default-path guidance plus exact/trimmed-line/DMP fuzzy matching. Miller is safer but requires exact `old_text`, making `edit replace_text` no easier than `apply_patch` after the agent has already inspected enough text.

### IMPACT
Next implementation slice should keep Miller's MCP surface unchanged and improve existing `edit replace_text` with bounded normalized/fuzzy matching, preview metadata, better operation guidance, docs/skill updates, and edit-specific matrix rows.
