## Made context next-inspect footer copyable

Context output now reinforces the overview-first workflow at the point agents choose the next tool call.

- **What:** Changed `ContextTool` compact output so `## next inspect` emits copyable `inspect(target="...", scope="...", depth="overview")` calls instead of bare `file:line` targets.
- **Why:** Bare `file:line` targets were less directive and were not actually valid `inspect` targets in the live tool surface.
- **How:** Kept seed selection and context packing unchanged; added a small formatter that uses the seed symbol name plus file `scope` and escapes quotes/backslashes.
- **Impact:** Agents can now follow context output directly into overview-first inspect without guessing the correct `inspect` parameters.
