## Implemented trace graph recovery guidance

Trace now gives agents bounded recovery actions for graph diagnostic states without adding MCP tools or changing graph truth semantics.

- **WHAT:** Implemented compact `Next:` guidance and additive JSON `next_actions` for trace ambiguity, no-path, bridge not-on-bridge, and no-bridge-links states.
- **WHY:** The Miller/Julie foundation matrix showed graph workflow rows ending in `needs-search`, `no-path`, and unsupported bridge outcomes with weak recovery guidance.
- **HOW:** Updated `TraceTool`, reused `CandidateOutput` with a command override for trace rerun examples, documented the behavior in server instructions, tool description, README, GitHub Pages, and `trace-json-v1`, and promoted focused foundation rows to hard gates.
- **IMPACT:** Agents can recover from honest graph misses through refs/source/path fallbacks while Miller stays deterministic and does not clone Julie or add a tool surface.
