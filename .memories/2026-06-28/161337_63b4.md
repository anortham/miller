## Implemented overview-first Miller guidance slice

Miller now guides agents toward cheaper, higher-signal deterministic workflows before full-body reads.

- **What:** Updated server instructions, inspect tool description, Miller skills, onboarding hints, public docs/site copy, and foundation matrix evidence for `inspect depth=overview` as the normal first symbol read.
- **Why:** The Miller-vs-Julie matrix showed agents were under-discovering existing Miller strengths (`overview`, `trace`, `impact`) and overusing expensive or less directed paths.
- **How:** Kept the MCP surface unchanged and preserved inspect's omitted-depth default as `summary`; added prompt/docs guidance and aggregate-only onboarding hints that steer agents from `search` to `inspect depth=overview`, then to `trace`, `impact`, or `inspect depth=full` only when needed.
- **Impact:** Improves agent discoverability without adding tools, changing telemetry privacy boundaries, or moving semantic/vector work into Miller.
