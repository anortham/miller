## Completed Miller Ph3 family-store consumer wiring

Miller now reads one validated family/view/generation snapshot across production consumers while keeping legacy mode byte-compatible.

- **Read boundary:** Workspace facts, dashboard facts, search/content/vector sidecars, and primary index counts use the store read session instead of raw legacy paths.
- **Provenance:** Status, health, and dashboard expose family, view, generation, manifest, store-log sequence, level, resolution, migration, rollback, and typed failure state.
- **Safety:** Store mode never falls back to a stale legacy artifact; dashboard store reads bypass the legacy timestamp cache; disabling store mode exports the active view first.
- **Guidance:** CLAUDE.md and AGENTS.md state producer ownership and explicit `MILLER_INDEX_STORE=1`; default-on remains a Ph5 decision.
