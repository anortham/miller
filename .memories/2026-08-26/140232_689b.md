## Fixed: first edit after CT enable never triggered a run

### WHAT
`ContinuousTestDaemonQueue.TryEnqueueInventorySeed` — a bounded exception to the Unknown-executes-nothing rule. An Unknown selection on a project whose ct.db holds NO test cases (never discovered) now enqueues a discovery-owed pending (`RefreshInventory=true`, empty id list) instead of silence. The drain's existing `RefreshInventoryIfNeededAsync` runs provider discovery, rebuilds the selection, and executes the owed backlog as the project's first baseline. Once per project per daemon lifetime (`_inventorySeedAttempts` keyed by PendingKey).

### WHY
User field evidence (Windows, Tycho repo): every save logged `ct enqueue no-run outcome=Unknown stale=0` across all four tracked projects. Root cause was a deadlock: discovery only runs inside a drain, a drain only follows an enqueued pending, and an empty case store makes every selection return Unknown (`SelectAtRevision`: `testCases.Length == 0 → Unknown`), which never enqueues. Only an explicit `tests run` (workspace-scope → RefreshInventory) escaped.

### HOW
- Seed gated on: outcome==Unknown AND `!HasProviderInventory` (zero stored cases) AND first attempt for that project this daemon session.
- No execution ids at enqueue; the drain skips cleanly if discovery finds nothing (`TestCaseIds.Count == 0 → continue`), and a failed discovery records its failure row. The once-guard prevents provider respawn per save.
- Contract docs updated: `docs/contracts/tests-cli-v1.md` fail-closed clause + CLAUDE.md CT section (AGENTS.md re-synced).
- Tests: two new cases in `ForbiddenEnqueueTests` (seed→discovery→baseline run; once-per-project). Existing fail-closed contract tests unchanged (they all seed cases, so the gate leaves them alone).

### IMPACT
enable → start → edit now produces the first baseline run without a manual `tests run`. Fast suite 8768 passed / 0 failed, Release build 0/0. Combined with the earlier slice (dashboard version lifecycle, CT nudges, dashboard tests buttons, hover fix) — all uncommitted on main.
