## Added git-aware impact CLI

- **WHAT:** Added `impact --git` support to the Miller CLI, with `--base REF` and `--staged` routing.
- **WHY:** Agents needed a one-shot pre-commit blast-radius check that reads the current git diff and reuses Miller's existing diff-to-impact mapping.
- **HOW:** Introduced an injectable `IGitDiffReader` boundary for CLI dispatch. Production shells out to `git --no-pager diff --no-ext-diff`; tests use a recording fake to keep the fast suite subprocess-free. Empty git diffs return a clean no-impact message and git failures return exit 3 with stderr detail.
- **IMPACT:** `miller impact --git` can now answer what the current branch/index diff affects without requiring the caller to manually pass a unified diff.
