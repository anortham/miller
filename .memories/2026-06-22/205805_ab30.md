## Added MCP git-aware impact

- **WHAT:** Extended the `impact` MCP tool with git diff inputs: `git`, `base`, and `staged`.
- **WHY:** The previous slice made git-aware blast-radius checks available to the CLI only. Agents using MCP still had to manually supply a unified diff.
- **HOW:** Moved the git diff reader into a shared `Miller.Server.Git` service namespace, registered `IGitDiffReader` in server DI, injected it into `ImpactTool`, and added MCP wrapper logic that reads the selected workspace's git diff before calling the existing diff-to-impact core. Added tests for working-tree git diff, base+staged routing, empty diffs, git failures, and conflicts with other impact inputs.
- **IMPACT:** Agents can now call `impact(git=true)`, `impact(base="origin/main")`, or `impact(staged=true)` directly through MCP to get downstream symbols and likely tests for the current diff.
