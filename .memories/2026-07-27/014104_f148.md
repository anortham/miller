## Repaired stale Miller test-contract ownership

### WHAT

Moved all Miller SQLite test fixtures onto one current-schema builder, renamed the large fixture contract test from v1 to current schema, emitted schema-5 reference sites for scale relationships, and made the source-text convention audit the actual working tree.

### WHY

Scale tests were exercising a fake legacy artifact and failing the strict production schema-5 gate. The text guard then crashed on the old path of an unstaged rename.

### HOW

- Added `JulieDbFixture.EnsureCurrentSchema` as the single DDL construction path.
- Reused it from both small reader fixtures and `LargeDbWriter`.
- Updated large relationship rows to carry canonical spanless `reference_site_id`, `file_id`, and path.
- Seeded the full current metadata key set.
- Renamed `LargeDbWriterV1SchemaTests` to `LargeDbWriterCurrentSchemaTests` and removed stale v1 documentation.
- Changed the source-text guard to enumerate cached plus untracked, nonignored files and skip deleted paths.

### IMPACT

The strict schema-5 gate remains intact. Full fast and Scale suites now test the same current artifact shape without requiring pre-staging.
