## Fixed Miller review findings in marker, paging, and diagnostic paths

Claude's focused Miller contract review exposed correctness and scaling defects in the new schema-5 consumer work.

- **Marker search:** `MarkerFactReader.Read` now applies caller predicates before its row limit, so late marker/path/language matches cannot be hidden by an earlier 500-row prefix.
- **Marker history:** `marker_total` and its TODO/FIXME/HACK/XXX detail now come from an exact grouped SQL aggregate; unknown marker kinds are excluded so the total reconciles with the breakdown.
- **Patterns paging:** population fingerprints scan only identity columns, while metadata payloads are hydrated with `LIMIT/OFFSET` for the requested page. A 1,000-row 32 KiB-payload regression dropped page allocations below the 8 MiB gate from 99.7 MiB.
- **Content diagnostics:** failure rendering now falls back to a bounded minimal diagnostic instead of throwing from inside the catch path.
- **Diagnostic ownership:** the generic compact renderer always appends its own code/class without scanning result text; ContentTool no longer pre-renders the compact code field.
- **Contract decision:** retained strict refusal for unknown `language_capability_gaps.status`; schema 5 owns exact `open|exception` values, so accepting unknown values would weaken the intentional breaking contract.

**Impact:** removes silent wrong-empty marker answers, exacts history metrics above 500 facts, makes pattern page cost proportional to the returned payload, and preserves typed MCP failures under byte pressure.
