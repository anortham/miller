### What landed
- **`SymbolSearchSidecar`** (`src/Miller.Indexing/SymbolSearchSidecar.cs`, new) — the routing gate: `Enabled` flag (`Disabled` singleton default), `SearchDbPathFor` (sibling `search.db`), `IsEnabledValue` (env parse), and `TryOpen(symbolsDbPath, expectedRevision)` → disk `FtsSymbolSearchIndex` only when enabled + present + `meta.revision == expectedRevision`, else `null`. **Contract: never throws** (path derivation inside the guard; catch covers Sqlite/InvalidOperation/IO/UnauthorizedAccess/**Argument/NotSupported**).
- **`WorkspaceIndexProvider`** — both the registered (`_loadSymbolSearch`) and holder-backed current paths route through `TryOpen(...) ?? in-memory`, unified into ONE revision-keyed single-flight evicting cache (`GetOrLoadSymbolSearch(key, dbPath, fallback)`). Registered fallback = lean `SymbolSearchProjection`; current fallback = holder's full `MillerRepositoryIndex`. Flag OFF → current path returns holder index directly, no cache entry — byte-identical to pre-Phase-3.
- **Flag** = env `MILLER_SEARCH_SIDECAR`, default OFF, read once in `MillerServiceRegistration` (no bootstrap-getter read → host lifecycle contract preserved).
- Backend observable via concrete type of `context.Index` (no `WorkspaceSymbolSearchContext` schema change).

### Revision contract
Freshness key = julie `extraction_revisions` cursor: `IndexHolder.BuiltRevision` / registry `row.LastRevision` must equal the `meta.revision` Phase-1/4 writers stamp. Strict equality (stale OR ahead → reject → fallback).
