## Miller MCP "failed to connect" → bootstrap now auto-heals an incompatible index DB

**Symptom:** `/mcp` reported miller failed to connect after the `chore/extract-2.1.0` bump.

**Root cause:** The 2.1.0 commit raised `MillerExtractContract` expected schema/contract to **2** and the server binary was rebuilt, but the on-disk `.miller/symbols.db` was still the **schema-1** artifact written by julie-extract 2.0.3. `IndexBootstrapService.DecideBootstrapScan` only force-rescans on a `root_path` mismatch — it never checked schema/contract — so it reused the stale DB, which then failed `JulieSchemaGate.Verify` → `IncompatibleExtractException` → "Hosting failed to start" → stdio process exits → client sees "failed to connect." Compounding it: `workspace full` is MCP-only (no CLI in `Program.cs`), so the error's suggested recovery was unreachable while the server was down.

**Immediate fix:** Moved the stale DB aside; the real bootstrap rescanned with the bundled 2.1.0 tool → schema-2 DB → reconnected (verified: "Bootstrap ready: 5208 symbols").

**Durable fix (user chose "auto-rebuild on mismatch"):** New seam `IndexBootstrapService.LoadIndexWithAutoRebuild<T>` — on `IncompatibleExtractException`, force-rescan once with the bundled julie-extract and retry the load exactly once; a second incompatibility propagates loudly (no loop). Wired into `Run()`; an auto-rebuild now counts as a scan for holder seed-revision + registry `scanned-at` bookkeeping (`didScan = ShouldScan || Rebuilt`).

- **Files:** `src/Miller.Server/Hosting/IndexBootstrapService.cs`, `tests/Miller.Tests/Server/IndexBootstrapServiceTests.cs` (3 unit tests), new `tests/Miller.Tests/Server/LiveBootstrapAutoRebuildTests.cs` (Scale).
- **Note:** A newer-than-expected DB also force-rebuilds down via the bundled tool — acceptable since the bundled tool is the source of truth, but worth keeping in mind.

**Still open:** Freshness/IndexerService rebuild path does NOT auto-heal (only bootstrap does); and TODO.md item 6 (user-added) tracks adding a Miller CLI for non-MCP recovery + integration tests.
