## Phase 4 done — external search.db build in CrossWorkspaceRefreshService (TDD, default OFF, reviewed)

Wired the on-disk `search.db` WRITE side for external (cross-workspace) repos: the one path that holds the workspace single-writer lock before scanning now builds the sidecar. All untracked (per workflow), on top of untracked Phases 0–3.

### What landed
- **`SymbolSearchSidecar.EnsureBuilt(symbolsDbPath, revision)`** — the writer entry point. Cheap freshness gate first (`ReadArtifactRevision` = one-row `SELECT revision FROM meta`, no resident snapshot) so an unchanged refresh never rebuilds a 565k-symbol artifact; on missing/stale/unreadable it reads symbols (`SqliteSymbolReader.Read`) + writes via `SearchIndexWriter`. Returns whether it (re)built; `false` when disabled/fresh. MAY throw on genuine build failure (unlike the read gate `TryOpen`).
- **`CrossWorkspaceRefreshService`** — builds the sidecar **inside the lease (lock) scope, after `MarkScanned`**, via best-effort `TryBuildSidecar` (swallows build exceptions → a sidecar failure never turns a successful scan into `Failed`). Runs on BOTH Refreshed and Unchanged (flag-flip on an already-scanned repo still builds a missing artifact); freshness gate makes the already-fresh case a cheap no-op. Lock-busy/missing/failed paths never build.
- **Flag-gated + cross-process consistent**: env `MILLER_SEARCH_SIDECAR` read in the server composition root AND in `DashboardData.RefreshWorkspace` (a dashboard refresh is also a lock-holding safe writer). Public ctor now 3-arg; all call sites + DI updated. Default OFF → no build, byte-identical to pre-Phase-4.

### Adversarial review (3-lens workflow)
- **Fixed (HIGH):** `ReadArtifactRevision` let `Convert.ToInt64` throw `FormatException`/`OverflowException`/`InvalidCastException` out of the lock-holding writer on a corrupt `meta.revision`. RED test (corrupt revision threw) → broadened catch (treat as unreadable → rebuild) → GREEN.
- **Refuted by execution:** the review's other HIGH (GetInt32/GetBoolean throw `InvalidCastException` on a malformed column → escape `TryBuildSidecar`) — a reproduction test PASSED: Microsoft.Data.Sqlite *coerces* blob/text numeric reads (no throw). The path isn't reachable; `TryBuildSidecar`'s existing filter is sufficient. Dropped that test as misleading. (Lesson: verify adversarial findings against real runtime behavior, not generic ADO.NET semantics.)
- **Closed gap:** added a test that an Unchanged-status refresh with the flag on still builds a missing artifact.
