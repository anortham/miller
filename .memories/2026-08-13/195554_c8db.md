## Windows lease-loss defect found in julie-extract, plus three Miller fixes

### julie-extract: the writer lease expires under its own operation

The red Windows CI gate was NOT test slowness. My first guess (a 10s
`wait_for_path` deadline too short for a 4-core runner) was wrong.

Improving the test diagnostics revealed the truth:
`resolution_failed: resolution publication fence was lost for "writer-lease"`.

- `with_writer_lease` (resolve.rs) acquires a lease, renews it ONCE, then
  runs the whole operation with NO heartbeat.
- `DEFAULT_LEASE_DURATION_MS` is 5_000.
- So any resolve step longer than 5 seconds expires its OWN lease and
  fails. Certain on a large repo; reproducible under 2 test threads.

**Experiment (decisive):** raising the TTL to 60s turned a nearly-always-red
constrained suite green. Reverted, then fixed properly.

**Fix:** `WriterLeaseHeartbeat` renews every 1s in a background thread with
its own coordinator (the pattern `ResolveHeartbeat` already uses), stopped
explicitly before release so a renewal cannot race it. `layout` threaded
through all 10 `with_writer_lease` call sites. Dead-holder takeover is
unchanged, so fencing still holds.

**Test-harness fixes that made this visible:** `wait_for_pause` detects a
child that exits before the injection point and prints its stdout/stderr;
24 bare `assert!(...success())` calls became `assert_ran`, which prints the
failing command's output.

### Miller (3 commits on main, all verified)

- `f2e415fa` store-mode freshness was two hardcoded literals
  (`index_fresh: true`, `current`). Now derives `scan_failing` / `resolving`
  / `sidecar_stale` / `unknown` (null, never fabricated) / `current`.
- `f9a0f6ac` pin julie-extract 2.33.1; hashes computed from the downloaded
  archives; restored binary self-reports 2.33.1.
- `a2292599` `refresh --json` reported the store's real sidecars (173 MB
  search, 118 MB content) as `missing` at `.miller/` paths that hold no
  such file. `workspace status` was already correct, so two documented Eros
  surfaces disagreed. Contract now says to read the `path` field.

### Verified

- Miller fast suite: 6,490 passed, 0 failed, 25 skipped.
- Live `refresh --json`: `missing` at fake paths became `stale` at real
  store paths.
- `workspace status` now reports `index_fresh: false` with an honest
  converging warning (the resident leader still runs 2.33.0).
