## WHAT

Fixed `SharedBrokerHostTestSupport.Locate` so it recognizes the generated sibling `Miller.SharedBrokerTestHost` apphost and its companion DLL under CT's project-specific output tree. Added a regression using the real dotted extensionless basename.

## WHY

`Path.ChangeExtension(candidate, ".dll")` treated `.SharedBrokerTestHost` as a file extension and looked for `Miller.dll`. Live CT therefore reported 13 false fixture failures even though `Miller.SharedBrokerTestHost.dll` existed beside the executable.

## HOW

Extensionless candidates now append `.dll`; `.exe` candidates retain `Path.ChangeExtension` for Windows. Focused tests cover the dotted Unix apphost, the existing Windows shape, and generated sibling output.

## IMPACT

The live daemon reran the previous red set and returned green in 39 seconds. `tests failures --json` is empty and worktree status reports zero stale cases across 8,191 selected tests.
