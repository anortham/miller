## Unix detached-launch PID lifecycle correction

### WHAT

The Linux scale acceptance test now runs on Unix, asserts publication readiness and PID identity, and verifies post-launcher log growth. The Unix launch script was changed from backgrounding `nohup` with `&` to `exec nohup` without an inner background process.

### WHY

The shell wrapper PID returned by `Process.Start` exited before the daemon published its lease. Readiness therefore reported `daemon_exited_before_publish`, and the daemon child was not safely tied to the launcher/session lifecycle. The reported PID also differed from the live daemon PID.

### HOW

TDD first removed the Windows-only skip and added assertions for `publication.readiness == ready` and the live lease PID. The unchanged script failed with `Actual: daemon_exited_before_publish`. The minimal Unix-only fix preserves existing redirection and argument handling while replacing the shell process in place with `nohup` and the daemon. Windows code was untouched.

### IMPACT

The real Linux launcher now keeps one stable PID from `Process.Start` through lease publication, allowing readiness to observe the actual daemon. The scale test passes and confirms the daemon survives launcher exit long enough to emit shutdown log growth.
