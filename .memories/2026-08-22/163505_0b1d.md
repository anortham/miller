## Task 5B1A renderer milestone

### WHAT
Added optional publication-readiness rendering for `tests serve` and typed wait rendering for `tests run` in `src/Miller.Server/Tools/TestsCore.cs`. Added direct contract tests and updated the start/run/wait portions of `docs/contracts/tests-cli-v1.md`.

### WHY
The CT surface had typed start and wait facts but discarded them at the JSON/compact boundary, so publication lag and non-final activity outcomes were not visible to CLI consumers.

### HOW
Publication facts render only when present with lower-snake readiness and elapsed seconds. Wait facts render only when present with completion, exact state, elapsed/timeout, command id, and run id. Compact output explicitly marks incomplete waits. Existing absent-fact bytes remain asserted exactly; no CLI/MCP parsing or status/activity renderer paths were changed.

### IMPACT
Unblocks the next CT rendering/contract work with schema-1 additive output and honest non-final wait visibility. Focused renderer coverage passes for all three publication states and all six wait states.
