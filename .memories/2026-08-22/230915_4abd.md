## WHAT

Completed generated-ignore Task 3 real-extractor/CLI acceptance and added suite-wide Miller-home isolation after the first branch gate exposed live-state pollution.

## WHY

Task 1 made every real scan materialize generated policy under Miller home. Existing tests isolated workspace roots but many did not isolate `MILLER_HOME`, so a green full suite wrote 84 files into the user's live policy directory.

## HOW

- Added real pinned-extractor Scale coverage for global policy scan/update/watcher parity, clean Git checkout status, user-root takeover, linked-worktree compatibility, and removal cleanup.
- Extended the literal built CLI `workspace open/status/search/full/remove` Scale path to verify no root `.julieignore`, exact isolated global policy, `?? .miller/` status, and policy cleanup.
- Added a test-assembly module initializer that preserves an explicit caller `MILLER_HOME`; otherwise it creates one unique `/tmp/miller-tests-home-<pid>-<guid>` before the runner starts.
- Process-exit cleanup restores the environment and removes only the exact validated owned temp home after a bounded tree walk rejects reparse points, unreadable entries, escapes, cycles, and oversized trees.
- Serialized the two tests that intentionally change `MILLER_HOME`.
- Added both affected Scale classes to the Windows smoke allowlist.
- Recovered 4 focused-run and 84 full-suite leaked policy files to Trash after validating their exact parent, regular-file shape, and Miller-generated content.

## IMPACT

Real onboarding and extractor acceptance is green, ordinary repos remain free of generated root policy, and the test suite no longer mutates live Miller state. The corrected final gate left live policy inventory byte-identical empty and no temp test homes/processes behind.
