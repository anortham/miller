## WHAT

Captured a wall-closing real-store profile of the remaining Linux `producer.resolve.full` failure using a temporary default-off aggregate profiler in the Julie producer worktree.

- External attempt: 149,046 ms wall, 148,474 ms CPU, 26,874,880 bytes peak PSS, exit 0, no timeout, full/exact state with matching exact-at identity.
- Internal profile: 148,998 ms wall, 148,983 ms accounted, 15 ms residual (0.0101%).
- Resolution owns 140,060 ms. Within it, identifiers own 111,369 ms for 402,195 items and pending relationships own 28,334 ms for 97,868 items. Relationships take 348 ms.
- `finish_exact` is 4,921 ms; setup 1,509 ms; base/exact reader opens 723/718 ms; scope 8 ms; diff 503 ms; rebase decision 4 ms; publication 7 ms; terminal append 2 ms.

## WHY

The full resolver still missed its 60-second gate after startup, one-file resolution, context, inspect, trace, and impact were recovered. Static evidence showed CPU ownership but could not separate resolver phases or query amplification.

## HOW

The profiler preserved durable telemetry and emitted one out-of-band JSONL record per claimed resolve. It measured exclusive full phases, exact finalization, top-level closure, reader opens, query executions/rows, and written rows. The same distribution reproduced in baseline and measured records.

Identifier resolution executed 715,409 child-name queries, 224,645 symbol-ID queries, 121,519 filtered-name queries, 116,734 type-fact queries, and 111,341 top-level-name queries. Pending work executed 11,981 locator queries. This proves query amplification inside identifier resolution is the primary remaining mechanism; database lifecycle/finalization is secondary.

## IMPACT

The project is not slow because SQLite files are simply large or because exact publication/finalization dominates. The remaining anchor is per-item candidate relationship work in the full resolver. The next diagnostic should time candidate-query families on the same real shape, then batch or reuse only the measured dominant family while preserving the full resolver digest.
