## Fixed Windows CI temp cleanup failure during v1.1.0 release

- **WHAT:** Fixed a Windows-only CI failure in `CliDispatchTests.Metrics_Churn_Json_MapsCommitRangeToCurrentSymbols` during `JulieDbFixture.Dispose` cleanup.
- **WHY:** Windows raised `UnauthorizedAccessException` while recursively deleting a temporary git repository object directory after the git-churn test. The fixture already treated temp cleanup `IOException` as best-effort, but Windows can surface held-handle cleanup as unauthorized access instead.
- **HOW:** Extended `JulieDbFixture.Dispose` to also catch `UnauthorizedAccessException` around the best-effort recursive temp directory deletion.
- **IMPACT:** The actual test assertions are unchanged; only best-effort temp cleanup is made robust to the Windows exception type seen in CI.
