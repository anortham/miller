## Completed leader diagnostics and handoff slice

- **WHAT:** Added `workspace leader` diagnostics and explicit graceful handoff for MCP/CLI. Added a new leader-handoff request kind in `LeaderScanRequestQueue`, coordinator/service handling, shared render output, and CLI support via `miller workspace leader --json --handoff`.
- **WHY:** The approved plan called for replacing manual stale-leader remediation with a local, auditable protocol that asks the leader to abdicate without killing processes.
- **HOW:** Implemented a separate `leader_handoff` queue operation rather than overloading version-aware `yield`. The leader drains handoff requests on the normal debounce tick, verifies requester liveness, then reuses the existing teardown/cooldown path. MCP/CLI reports include leader identity, liveness, recommendation, and handoff request status.
- **IMPACT:** Focused queue, coordinator, service, MCP workspace, and CLI tests are green. Docs/contracts still need the cross-cutting update.
