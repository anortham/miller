## Codex pre-release review of 0.4.1 — all material findings fixed

**WHAT:** Ran an external Codex review of the three unpushed 0.4.1 commits before release. Four findings; validated each and fixed the three material ones:

1. **External same-revision rebuild staleness (real, fixed):** the Bug-1 cache eviction only fired when *this process's* refresh returned `Refreshed` — but the Eros fleet shape is a CLI `workspace full` in another process beside a live server, whose own next scan legitimately reports `no_change`. If the rebuilt artifact's restarted revision counter lands on a cached number, the server kept serving the pre-rebuild in-memory parse. **Fix:** `WorkspaceIndexProvider.CacheKey` now includes the symbols.db file identity (`LastWriteTimeUtc.Ticks` + `Length`), computed by a `KeyFor` helper at all 8 key construction sites — an externally rewritten file can never collide with a cached parse, regardless of revision numbers. One cheap stat per resolve; `EvictOtherEntriesForWorkspaceUnderLock` keeps memory bounded.
2. **Scale test pinned `0.4.0` (real, fixed):** `CliBinarySubprocessTests` asserted `StartsWith("0.4.0")` — the scale suite had been run *before* the version bump, so the landmine was live. Now asserts `Assert.Equal(MillerVersion.Current, ...)` (the spawned binary comes from the same build), ending the per-release literal chore for that file.
3. **Read-command valueless selector masking (real, worse than reported, fixed):** `TryResolveReadContext` overwrote `selectorFlagPresent` in the fallback branch, so a valueless `--workspace-id` was masked by `--workspace` AND silently fell back to the current workspace when alone. Rewritten: valueless selector flag → exit 2 in every combination, matching the lifecycle verbs.
4. **Stale release-notes test count (low, fixed):** verification block regenerated (2150).

**Verification:** TDD red→green for findings 1+3 (`Resolve_RegisteredWorkspace_ReloadsAfterAnExternalRebuildAtTheSameRevision`, two `ReadCommand_*` selector tests); fast suite 2150 green; scale suite 27 green (now genuinely validating the 0.4.1 version output); full Release build 0 warnings. Docs updated: release notes, cli-eros-v1 selector rules, findings-doc resolution addendum.
