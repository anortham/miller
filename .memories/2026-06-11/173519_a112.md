## Fixed all three Eros fleet-verification cross-workspace bugs (2026-06-11 findings)

**WHAT:** Fixed the three bugs from `docs/findings/2026-06-11-eros-fleet-verification-bugs.md` that broke Miller's cross-workspace operations for fleet orchestrators.

**WHY:** Eros (or any caller in another cwd) could not heal a schema-mismatched workspace: `workspace full` looped reporting "unchanged", CLI `workspace status|full` silently retargeted the cwd workspace, and schema-mismatch errors exited 1 instead of the contracted 3.

**HOW — root causes (julie-extract 2.4.0 was NOT at fault; it heals correctly):**
- **Stale pooled SQLite handles:** `SqliteReadOnlyAccess.Open` (the shared symbols.db opener used by all 16 readers) left pooling ON — the only reader that did. julie's force rebuild unlinks+recreates symbols.db, so a live server's pooled connections pinned the old inode and kept seeing the schema-2 DB forever. Fix: `Pooling=false` (+ same gap in `ContentCorpusContextReader`).
- **Revision-comparison status:** `CrossWorkspaceRefreshService` reported refreshed-vs-unchanged via `revision > LastRevision`; a from-scratch rebuild restarts the counter (1==1) → success misreported as "unchanged". Fix: judge by julie report `status=="no_change"` (new `ExtractReport.IsNoChange`).
- **Cache-key collision:** `WorkspaceIndexProvider` caches keyed `(ws, db, revision)` served stale indexes after a rebuild landing on the same revision. Fix: evict workspace entries when a Refreshed result does not advance the revision.
- **CLI selector drop:** `CliDispatch.Workspace` only parsed `--id`/`--path`. Fix: `--workspace-id`/`--workspace` aliases (path normalized vs cwd), valueless selector → exit 2, help + cli-eros-v1 updated.
- **Exit code:** `IncompatibleExtractException : Exception` fell through to the generic exit-1 catch. Fix: `CliDispatch.Run` maps it to exit 3 for all verbs.

**IMPACT:** Cross-workspace heal loop broken end-to-end (verified: schema-2 artifact → patterns exit 3 → cross-cwd `workspace full --workspace` → schema 3 + "refreshed" → patterns exit 0). 9 new fast tests; fast suite 2142 green, scale suite 27 green, Release build 0/0. Goldfish workspace itself was already healed by the original repro (the rebuild HAD worked; only reporting + pooled reads lied).
