## WHAT

Created `docs/plans/2026-08-30-stateless-workspace-targeting-design.md` for BRE-57 and saved an active Goldfish brief. The design requires `workspace_id` on all workspace-bound MCP tools, keeps list/open and registry-wide operations as bootstrap exceptions, and rejects `current`/`primary` only at the MCP boundary.

## WHY

User-level GUI registrations cannot trust process cwd or per-project environment variables. MCP 2026-07-28 makes requests stateless and deprecates Roots, so implicit primary binding cannot remain the tool-target contract.

## HOW

Used Miller to trace startup binding, request filters, provider routing, tool schemas, open priming, content, CT, telemetry, and edit locking/convergence. Ran a one-call cross-model doubt pass with Claude. Folded the surviving corrections into the spec: all tools must construct unbound; explicit IDs always take registered routing; machine-global paths share `MillerHome`; edit locks and file-converge requests target the selected workspace; startup binding remains only for background services; CLI `current` behavior stays intact. Rejected the review suggestion that a machine-global host path should replace the bound workspace's protected `.miller` path because those paths have different safety jobs.

## IMPACT

The design now covers the real architectural cause instead of adding another cwd fallback. It is ready for user review before worktree creation and implementation planning.
