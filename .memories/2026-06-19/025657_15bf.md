## Fixed v0.5.5 dependency and Actions release blockers

- **WHAT:** Updated NuGet package pins and GitHub Actions action versions after the first package-only run failed.
- **WHY:** GitHub Actions run `27802249667` failed in `build aarch64-apple-darwin` during `dotnet restore` with `NU1903` for `SQLitePCLRaw.lib.e_sqlite3 2.1.11` (`GHSA-2m69-gcr7-jv3q`). The run also showed Node 20 deprecation warnings for workflow actions.
- **HOW:** Bumped `Microsoft.Data.Sqlite` to `10.0.9`, `Microsoft.Extensions.Hosting` to `10.0.9`, `ModelContextProtocol` to `1.4.0`, and added explicit `SQLitePCLRaw.bundle_e_sqlite3 3.0.3` overrides so SQLitePCLRaw resolves to 3.x. Updated workflow actions to official latest Node 24-based versions verified from GitHub action metadata: checkout `v7.0.0`, setup-dotnet `v5.3.0`, setup-node `v6.4.0`, upload-artifact `v7.0.1`, download-artifact `v8.0.1`, configure-pages `v6.0.0`, upload-pages-artifact `v5.0.0`, deploy-pages `v5.0.0`. Updated third-party notices and v0.5.5 notes.
- **IMPACT:** Local restore/audit/build/test gates are clean, and the release package workflow can be rerun from a new commit.
