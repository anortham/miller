## WHAT
Completed and verified the full native Windows semantic broker soak after fixing fresh-machine model preparation. The 1,800-second run completed 26/26 normal probes, zero hangs/failures, 2/2 expected kills, no orphan broker, distinct model endpoints, one same-model broker, and effectively constant GPU allocation.

## WHY
The first isolated Windows run failed because the hardcoded Qwen fallback model was not yet present in the shared model cache. Linux had masked this precondition through an existing cache.

## HOW
Updated both `semantic-broker-soak.ps1` and `.sh` to synchronously run the pinned sidecar's verified `prepare --model` for BGE and Qwen before GPU baselining or probes, capture logs, and fail closed. Strengthened the platform convention test to enforce default prepare -> fallback prepare -> GPU baseline -> warm probe. The full Windows result reported broker recovery 1.249s, owner recovery 1.54s, GPU delta 87 MiB for one and many sessions, and every applicable acceptance flag true.

## IMPACT
The native Windows semantic gate is closed. Remaining work is the strict three-run replay from a helper-validated copied family, followed by evidence/worktree reconciliation. The Release launcher was temporarily suppressed to block MCP-supervisor restarts and restored automatically after success.
