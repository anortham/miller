## WHAT

Completed the approved design and implementation plan for nonblocking MCP `workspace open` in `docs/plans/2026-08-16-workspace-open-background-prime-*.md`.

## WHY

A live open of the clean Julie worktree produced no MCP response after more than 180 seconds because `WorkspaceTool.Open` ran extraction inline. The five-second limit covered only scan-governor admission.

## HOW

- Keep validation and durable registration synchronous.
- Add atomic insert-if-new registration that preserves existing state/error/revision.
- Use a fixed-capacity deduplicated hosted queue.
- Wait for bootstrap binding before lazily resolving refresh dependencies.
- Reuse `CrossWorkspaceRefreshService` for all scan policy.
- Preserve synchronous one-shot CLI open.
- Pin deterministic gated tests and a 20-sample warm-connection p95 gate.

## IMPACT

The work is decomposed into registry/status, hosted queue, MCP refactor, and integration verification tasks. It avoids the known hosted-service constructor crash and registry-state race before implementation starts.
