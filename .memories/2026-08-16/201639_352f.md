## WHAT

Completed the Miller consumer fixes for immediate MCP workspace opening and stale seed recovery.

- `WorkspaceTool.Open` now atomically registers/refreshes and queues bounded background priming without constructing or running the extractor on the request path.
- `WorkspaceOpenPrimeService` processes queued work, deduplicates active workspaces, resolves heavy dependencies lazily, and conditionally records errors so late failures cannot overwrite Ready.
- `WorkspaceRegistry` gained atomic register-refreshing and conditional error transitions.
- `StoreWorkspaceCoordinator` retries exactly once without `FromArtifact` only when seeded import validation returns `store_incompatible`.

## WHY

MCP `workspace open` was blocking on full index work, and stale released seed artifacts could permanently deadlock bootstrap after upgrades.

## HOW

Used a bounded channel, lazy refresh-service factory, state compare-and-set updates, and a narrow typed fallback. Kept CLI open synchronous. Added focused race, capacity, host-construction, live Scale, and seed-fallback tests.
