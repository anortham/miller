## Closed the final measured Miller recovery defects

### WHAT

- Corrected recording-proxy teardown so an intentional closed controller stream does not turn a successful downstream exit into code 70.
- Corrected Linux strict-Clippy failures in the Windows producer hardening.
- Replaced CLI bridge trace's full `MillerRepositoryIndex` hydration with the existing lean symbol-index plus `SessionBridgeGraphLoader` path.
- Reconciled the live PERF ledger and Windows evidence wording; final PERF-009 closure metrics still need to be written after the code commit.

### WHY

Windows acceptance passed, but exact-current Linux review exposed a proxy teardown regression, two Rust lint failures, stale ledger claims, and the still-open PERF-009 bridge budget. Profiling proved the CLI was loading identifiers, relationships, dependency graph, and search structures that bridge traversal never uses.

### HOW

- TDD trap: a family-store bridge fixture carries an invalid unused relationship projection; the old full loader fails while the lean bridge projection succeeds.
- The CLI now shares the same lean bridge path already used by MCP.
- No bridge sidecar or new public contract was added.

### IMPACT

- CLI bridge trace improved from 6.62–6.65 s and ~408–410 MiB RSS to 1.44–1.47 s and ~180 MiB RSS with identical SHA-256 output.
- Isolated MCP bridge calls pass at 1.76–1.79 s and ~187 MiB PSS.
- Exact-current Release build, 6,567/4 fast tests, and 138/10 Scale tests passed against the corrected producer before the bridge-only change; focused bridge parity tests pass after it.
