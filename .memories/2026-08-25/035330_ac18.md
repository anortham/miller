## Fixed QML visibility JSON serialization for Native AOT

### WHAT
Replaced the four reflection-based JSON array serializations in `QmlVisibilityCatalog` with source-generated metadata from a new `QmlVisibilityJsonContext` covering `long[]` and `string[]`.

### WHY
The Linux Native AOT publish failed with IL2026/IL3050 at the QML visibility catalog, preventing production from being generated. The arrays are passed to SQLite `json_each`, so their JSON shape must remain unchanged.

### HOW
Added `QmlVisibilityJsonContext` beside the existing indexing contexts and serialized materialized `long[]`/`string[]` values through `Int64Array`/`StringArray` metadata. No reflection suppression or runtime fallback was added.

### IMPACT
The Miller.Indexing Release build succeeds with zero warnings/errors; 54 focused QML/store/artifact/bounded tests pass; and a Linux Native AOT publish succeeds with no IL2026/IL3050 diagnostics. The generated binary runs `miller version` successfully as `1.22.0+a1bbf071610b`.
