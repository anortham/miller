## Pruned redundant telemetry indexes

- **WHAT:** Removed creation of the old single-column telemetry indexes and added open-time `DROP INDEX IF EXISTS` cleanup for `idx_tool_telemetry_ts`, `idx_tool_telemetry_tool`, and `idx_tool_telemetry_ws`.
- **WHY:** The new dashboard/summary composite indexes cover the known telemetry read paths, while the old indexes amplified every `tool_telemetry` insert without a distinct query benefit.
- **HOW:** Kept the composite indexes, made existing DBs shed superseded indexes on `TelemetryLedger.Open`, and added a migration-style test that recreates the old indexes then verifies open removes them.
- **IMPACT:** Reduces telemetry write amplification from the SQLite performance fix while preserving the improved dashboard query plans.
