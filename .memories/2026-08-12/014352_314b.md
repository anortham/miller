## WHAT

Narrowed missing-family-store classification so an inaccessible existing store cannot use legacy version fallback or claim leadership.

## WHY

`Directory.Exists` returns false both when a directory is absent and for some access/error states. The first RootRebind fix therefore overstated its safety invariant.

## HOW

- Added a Unix regression with a real existing store root behind a non-traversable parent.
- Observed RED: `ReadForLeadership` returned normally instead of throwing `StoreArtifactVersionReadException`.
- Replaced `Directory.Exists` with a bounded directory enumeration that treats only `FileNotFoundException` and `DirectoryNotFoundException` as absent.
- Left unauthorized access, generic I/O, not-a-directory, corruption, and post-probe races on the refusal path.

## IMPACT

The dangling-pointer recovery remains available only for actual absence, while an inaccessible or invalid existing store cannot bypass extractor leadership safety.
