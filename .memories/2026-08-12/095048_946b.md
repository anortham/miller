## WHAT

Added bounded, request-local Search-shape telemetry to the existing context lookup phase measurements.

- Fixed families: first query, mode variant, window variant, exact repeat, AND, and OR.
- Each family records calls, elapsed time, and returned rows; overflow records an honest dropped count.
- `ContextTool` emits the fixed search delta and cumulative snapshot at the existing correlated phase boundary.

## WHY

The rebuilt candidate proved that 21 `Search` calls consume 1,452 ms, but aggregate counters could not distinguish distinct queries from SearchTool mode/window retries. A behavior fix without this split would be another guess.

## HOW

A context-local `AsyncLocal` collector is activated only for the context request. It classifies process-local HMAC identities without logging query text or digests, caps identity state at 64, and restores a nested prior collector on disposal. The generation-cached lookup wrapper retains no per-request state, preventing concurrent contexts from mixing evidence.

Lead review found and corrected two pre-commit defects: cursor-based shared state cross-correlated concurrent requests, and telemetry hashing changed null-forgiven inner behavior.

## IMPACT

The next single candidate run can select between eliminating repeated whole-index rankings and optimizing the underlying FTS word arm. No search behavior, public API, MCP surface, or persisted schema changed.
