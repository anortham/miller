## Honored the explicit extractor-downgrade recovery override

A failed Julie family import can leave an existing store root with no published readable view. `CrossWorkspaceRefreshService` caught that version-read failure before `LeadershipEligibility` could observe the explicit override.

- **What:** Added a real-producer Scale regression covering default refusal followed by explicit-override recovery to an exact view
- **Why:** `workspace open` returned `IneligibleExtractor` even with `MILLER_ALLOW_EXTRACTOR_DOWNGRADE=1`
- **How:** Only when the override is active, route `StoreArtifactVersionReadException` through the existing eligibility policy with an unknown artifact version; preserve the normal refusal path otherwise
- **Impact:** Operators can deliberately recover an unreadable unpublished family store without weakening the safe default
