## WHAT

Added fixed, request-correlated stage measurements inside disk-backed symbol Search.

Seven completion-only families measure connection open, AND probe, word candidates, word scoring, trigram candidates, trigram scoring, and final ordering. Existing correlated context phase events now carry fixed FTS delta and cumulative snapshots.

## WHY

After duplicate caching and the empty-AND probe, context is 2.532 s and the remaining 11 OR searches consume 805 ms. Caller-level Search timing cannot identify whether SQLite candidate hydration, C# scoring, connection setup, or trigram work is load-bearing.

## HOW

A context-local `AsyncLocal` collector in Miller.Indexing receives immutable fixed observations from the generation-cached FTS reader. It uses fixed arrays, aggregates calls/elapsed/rows, and is activated alongside the existing Search request collector. Shared FTS objects remain immutable; concurrent contexts cannot mix.

Self-review found and corrected a TimeSpan/Stopwatch unit conversion defect and a dishonest connection row count before commit.

## IMPACT

One diagnosis run can now select a behavior fix from actual FTS stage cost without query content, per-row logging, a public surface, or persisted-schema change.
