## Default encoder pin flipped: bge-small-en-v1.5-f32 (qwen3 → fallback)

**WHAT:** `MillerSemanticContract.DefaultEncoder` is now bge-small (384-dim int8, cls pooling); qwen3 is `FallbackEncoder`. TDD: contract/selection tests re-pinned first (red 8), swap (green), then fixed dim-coupled collateral in SemanticQueryDiagnosticsTests, SemanticSearchArmTests, VectorConvergeServiceTests, VectorStoreTests (variant-value collisions where "different lane" test values now equaled the new default). Scale-suite sessions now use `ForServe(default)` + strict handshake — the live sidecar test proves the full pin+forwarding stack.

**WHY:** Pre-registered pin rule outcome (fused nDCG within 1.2% relative) + Task 6 cost table (7.7× faster build, 27× smaller sidecar RSS, 5× faster warm query, 9× smaller download) + user's explicit UX judgment that qwen3 was too slow for an MCP server.

**Migration semantics:** swap classifies as ShadowRebuild (new contract test `ExistingQwen3Artifact_UnderTheBgeDefault_ClassifiesAsAShadowRebuild`) — existing qwen3 artifacts converge in shadow with the old generation retained for rollback. `MILLER_SEMANTIC_MODEL=qwen3-0.6b-f16` remains a one-env-var opt-back.

**Docs:** README encoder line, vectors-v1 §Pinned initial values (columns swapped + dated pin-flip note; format freeze untouched — role labels only), sidecar-protocol note (binary manifest tiers unchanged; Miller always passes serve --model), conformance README labels.

**Depends on bf58afd** (sidecar --model forwarding) — without it the bge default would wedge every build.

**IMPACT:** fresh Miller installs get the 134 MB encoder by default. Remaining: Task 8 freeze record (bge identity), branch gate re-run at final HEAD, codex pre-merge review.
