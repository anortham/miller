## Dashboard panels vanished after first poll

- **WHAT:** `#workspace-detail-stack` published `hx-target="this"` for the refresh-finished refetch. Child polls (tests every 5s) inherited that target and replaced the whole stack with the tests fragment.
- **WHY:** First paint showed all ten panels; after the tests poll only Tests remained.
- **HOW:** Removed `hx-target` from `WorkspaceDetailStack.RefreshFinishedAttributes`. The stack request still targets itself by default.
- **IMPACT:** Nested polls keep their own element as the swap target.

Evidence: browser repro (tests fragment request then stack gone); after fix, 10 panels still present at 7s. Test `WorkspaceDetailStack_OmitsHxTargetSoChildPollsDoNotReplaceTheStack`.
