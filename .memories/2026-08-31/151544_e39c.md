## BRE-57 release decisions applied + julie-extract 2.38.0 pin

### WHAT
Closed the three open product decisions from the pre-release review and pinned julie-extract 2.38.0, all on `codex/bre-57-stateless-workspace`.

- **Dashboard, no primary bound:** now returns the registry list URL (`/`). `DashboardLaunchRequest` gained `OpenWorkspaceView` (default true, so CLI behavior is unchanged); `DashboardCliLauncher.LaunchUrl` returns the base URI when false; the MCP `workspace` tool passes `CurrentWorkspaceOrNull is not null`. Before: the synthetic fallback context derived a workspace id from `~/.miller` itself and opened a detail view of an unregistered fake workspace (a 404 on this branch).
- **Refresh fast path kept:** `RenderTargetAction` treats an explicit `workspace_id` that resolves to the bound primary as current (`IsCurrentWorkspace(row)`) and scans in-process. Scoped to refresh/full only — `ResolveTarget` line for other operations untouched, per the decision's scope. The branch's `Refresh_ExplicitCurrentWorkspaceId_UsesRegisteredRouting` test asserted the always-queue behavior and was flipped to `RefreshAndFull_ExplicitCurrentWorkspaceId_KeepTheInProcessFastPath`.
- **MILLER_AGENT_INSTRUCTIONS.md:** accepted as-is at 1,890 chars.
