## WHAT

Completed and lead-reviewed BRE-57 host integration. Production no longer registers the MCP Roots binding service or Roots notification service. `WorkspaceTool`, `ContentTool`, and `TestsTool` are activated from machine-global paths and registry state, and ModelContextProtocol tool targets use per-request DI factories so ambient constructors are never selected.

## WHY

GUI clients launch user-level MCP servers from unreliable or sensitive working directories, and the stateless protocol cannot preserve session workspace binding. Each workspace-bound call must therefore be independently routable by explicit `workspace_id`.

## HOW

Removed Roots services from the production graph, deleted the notification handler, retained the old binding class only as an unregistered legacy test seam, registered the three stateless wrappers explicitly, and added actual MCP stream integration coverage. Review found the first test only proved an unstarted bootstrap; the correction now runs bootstrap from the user-profile cwd, asserts the real deferred state, then serves two registered IDs through one MCP process without binding or state bleed. Matching and different primary bindings produce the same explicit result.

## IMPACT

Task 6 is complete. The production server sends no `roots/list`, deferred startup no longer blocks explicit calls, and runtime integration is ready for final guidance/docs.
