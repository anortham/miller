## WHAT
Implemented the approved family-store dogfood repairs. Linux workspace lineage now uses statx birth time instead of mutable ctime; incompatible/corrupt legacy symbols.db files are skipped as store seeds without deletion; existing status/health/dashboard surfaces now show store root and bounded member display labels. Live dogfood also exposed and fixed a semantic freshness bug: the vector writer stamped family_id:view_id while SemanticSearchArm compared against legacy .miller/symbols.db artifact_id. WorkspaceReadSnapshot now centralizes VectorArtifactId/VectorRevision, and the semantic arm resolves live freshness through the active family pointer.

## WHY
Linux ctime churn created false checkout replacement identities and new UUID store families. Legacy schema incompatibility blocked default startup. Raw UUID store directories were impossible to map back to workspaces from diagnostics. Finally, explicit semantic search failed even while health claimed vectors ready because reader and writer used different artifact identities.

## HOW
Added a statx ABI seam shared by WorkspaceRootIdentity and StoreWorkspaceCoordinator, a compatibility gate around LegacyArtifactReadSession.Validate, an authoritative views-table member summary, additive bounded rendering, and family-aware semantic freshness. Kept workspace_id as the user-facing canonical-root hash and family_id as internal shared-lineage identity; added no MCP tool and preserved existing stores/legacy artifacts. TDD captured Linux metadata churn, incompatible/missing/corrupt seeds, bounded diagnostics, and family vector identity.

## IMPACT
Default family-store startup recovers from stale legacy artifacts, ordinary Git metadata writes no longer rotate lineage on Linux, store UUIDs are diagnosable through existing surfaces, and explicit semantic retrieval works against family-store vectors. Live store ended exact with search/content/vectors current and semantic search served in 129 ms.
