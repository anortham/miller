## Made the existing family store default-on

- **WHAT:** Changed `WorkspaceReadSessionFactory.StoreEnabledFromEnvironment` so unset/blank enables the existing family-store path, added a serialized 12-case environment contract test, and updated README, release notes, known limits, and synchronized agent guidance.
- **WHY:** v1.18.0 is intended to ship one producer-owned store per repository family with checkout views by default; marketplace manifests already advertise 1.18.0 while the live release is still 1.17.0.
- **HOW:** Changed only the centralized policy seam. Existing true aliases, false aliases, invalid-value failure, rollback export, store/view model, per-view sidecars, and producer ownership remain unchanged. `MILLER_INDEX_STORE=off` is the explicit compatibility path.
- **IMPACT:** Every existing startup/read caller consistently selects the family store by default. Focused tests pass 12/12 and the Release build has zero warnings/errors; broad fast/Scale/Windows/package gates remain before publication.
