## Added agent-adoption guidance (README + snippet doc + site)

Users reported that harnesses with deferred MCP tool schemas (current Claude Code tool search) fall back to grep instead of Miller's tools — Miller's tool descriptions aren't in context when the model picks an exploration strategy, and ServerInstructions are truncated/late.

- **WHAT:** New README section "Making Agents Actually Use Miller" (after Common Agent Workflow) with an embedded copy-paste routing snippet for user-level CLAUDE.md / AGENTS.md / Cursor rules; canonical snippet at `docs/agent-setup-snippet.md`; registered in `docs/README.md` map; one-line pointer added to the site install list (`docs/site/index.html`).
- **WHY:** The only guidance channel that is *always* in the model's context is user/project instructions — Miller's three server-delivered channels (ADR-0001) can't reach a model before the schemas load.
- **HOW:** Snippet = "instead of X use Miller tool Y" table (search/inspect/trace/impact/context/edit) + 4 rules (search before grep, inspect before whole-file reads, trace/impact before changes, trust the index, applies to subagents). README embeds a copy; snippet doc notes to keep them in sync.
- **IMPACT:** Gives users a documented fix for the "Claude just uses grep" adoption complaint.
