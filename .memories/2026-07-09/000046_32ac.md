## Dashboard workspace remove + prune — design approved, worktree ready

**WHAT:** User approved adding mutation actions to the Miller dashboard: per-row workspace Remove (full parity with CLI `workspace remove`, inline confirm) on every entry, plus a one-click "Prune stale" button. Design doc committed at `docs/plans/2026-07-08-dashboard-workspace-remove-design.md`.

**WHY:** User wants to clean up dead workspace registrations directly from the dashboard instead of dropping to the CLI. This deliberately reverses the 2026-07-08 registry-hygiene plan Task 5 decision that kept the dashboard read-only.
