## Identified incompatible Codex SessionStart hook outputs

Codex has seven active SessionStart entries: four from `~/.codex/hooks.json` and three from enabled plugins.

- **WHAT:** The Goldfish user and plugin hooks emit raw Markdown. The Razorback user and plugin hooks emit JSON with only a top-level `additionalContext` field. All four fail Codex 0.153.2's SessionStart JSON contract.
- **WHY:** Codex now expects `{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":"..."}}` for non-empty SessionStart stdout.
- **HOW:** Enumerated active hooks through `/hooks`, ran each exact command with a synthetic SessionStart event, and validated its stdout shape with `jq`.
- **IMPACT:** Miller's two entries are valid. The Herdr user hook emits no stdout outside Herdr and its source never emits stdout inside Herdr, so it is a no-op for JSON parsing. Fix or disable the four Goldfish/Razorback entries to remove startup errors and duplicated hook delivery.
