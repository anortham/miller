## Published Miller v0.1.0-beta.1

### WHAT

Published the first Miller GitHub release: `v0.1.0-beta.1`.

- Release URL: `https://github.com/anortham/miller/releases/tag/v0.1.0-beta.1`
- Release workflow run: `https://github.com/anortham/miller/actions/runs/27076662572`
- Published from commit `09f3cbba9d1398f986673e0982785827c5b6839f`.
- Tag `refs/tags/v0.1.0-beta.1` points directly to the same commit.
- Release is a prerelease and not a draft.
- Release has eight assets: four platform archives plus four `.sha256` sidecars.

### WHY

The user requested the first GitHub release after plugin distribution and release packaging were committed. The release had to create the assets consumed by plugin install paths and direct archive installation.

### HOW

- Verified there were no existing releases or tags.
- Ran local release gates on the release candidate: `git diff --check`, `scripts/test-plugin.sh`, `dotnet build Miller.slnx -c Release`, and `scripts/test.sh all`.
- Dispatched `release.yml` for `version=0.1.0-beta.1`, `publish=true`, `prerelease=true`.
- First run exposed a Linux AOT MCP smoke timeout: the Linux binary passed `miller version`, but the six-second `tools/list` smoke window was too short. Cancelled the doomed run, patched `.github/workflows/release.yml` to keep stdin open for 20 seconds and preserve stderr on failure, committed `09f3cbb`, and reran.
- Second workflow run succeeded across all four matrix targets and the publish job.
- Edited the generated release body to use `docs/release-notes/v0.1.0-beta.1.md`.
- Downloaded the published `aarch64-apple-darwin` archive, verified its `.sha256`, confirmed it contains `miller`, `.tools/julie-extract`, `LICENSE`, `THIRD-PARTY-NOTICES.md`, and `dashboard/wwwroot/dashboard.css`, then ran `miller version`, `julie-extract --version`, and an MCP `tools/list` smoke against the published binary.

### IMPACT

Miller now has a real published prerelease and the plugin launcher can consume `v0.1.0-beta.1` from GitHub releases instead of requiring `MILLER_BINARY` for normal use.
