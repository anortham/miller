## Designed Miller public dashboard release slice

The approved direction moves Miller beyond the beta-minimum dashboard without crossing into Eros product territory.

- **WHAT:** Added a durable design for `docs/plans/2026-06-06-public-dashboard-design.md` covering workspace/index transparency, language and symbol stats, freshness, sidecar health, telemetry, and context savings.
- **WHY:** The current beta dashboard launches and shows workspaces/telemetry, but a public-ready Miller release needs a developer-facing view into what Miller indexed and how much context it saved.
- **HOW:** Kept the implementation boundary to aggregate read-only dashboard data plus small telemetry enrichment. Rejected full-index hydration, Julie theme copying, Eros recommendations, semantic/vector views, and invented context-savings numbers.
- **IMPACT:** Future implementation can proceed from a concrete acceptance checklist and preserve the Miller/Eros boundary.
