## Hardened Miller release workflow manual mode

- **WHAT:** Added a package-only manual validation mode to `.github/workflows/release.yml` while preserving tag-push publishing.
- **WHY:** Miller needs release automation across every pinned `julie-extractors` platform, but manual workflow runs should be able to validate packaging without accidentally publishing a GitHub release.
- **HOW:** Added a `publish` boolean input defaulting to `false`, gated the `github-release` job on tag push or explicit manual publish, and added a package-only summary job for non-publishing dispatches. Added a contract test for this behavior and synced `CLAUDE.md`/`AGENTS.md` release guidance.
- **IMPACT:** We can run the release workflow across all four Julie-supported targets for validation, then set `publish: true` only when explicitly releasing.
