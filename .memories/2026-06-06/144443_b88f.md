## Added dashboard snapshot read model tests and implementation

- **WHAT:** Added focused dashboard tests for workspace index facts, language and symbol-kind breakdowns, corrupt index handling, context savings, and stable snapshot JSON. Implemented a cheap dashboard facts reader over `files` and `symbols`, wired facts and context savings into `DashboardData.ReadSnapshot`, and added `/snapshot.json`.
- **WHY:** The public-ready dashboard needs transparent, inspectable repo state and defensible context savings without loading Miller's full repository index.
- **HOW:** Kept the model read-only and SQLite aggregate based, reused registry workspace rows for selection, read telemetry `source_bytes` only when positive, and marked missing/corrupt sidecars or index DBs as status fields instead of crashing.
- **IMPACT:** The first implementation slice is now test-backed and ready for the UI layer to consume richer dashboard data.
