## Release-readiness fixes complete — Miller v0.1.0-beta.1

Implemented and verified all fixes from the deep release review (`docs/findings/2026-06-06-release-readiness-review.md`), except the two the user explicitly skipped.

### Code fixes
- **edit BOM fidelity** — `EditApplier.AtomicTempMove`/rollback now preserve a UTF-8 BOM (sniff EF BB BF) via `WriteAtomicPreservingBom`.
- **edit dry_run removed** — the ignored second write-control flag is gone everywhere (tool/request/service/tests/docs); preview = `apply=false` default.
- **workspace_id case-fold** on Windows/macOS (`WorkspaceId.FromCanonicalRoot`).
- **workspace open symlink bypass** — canonicalize root BEFORE the sensitive-root check (`WorkspaceTool`).
- **DashboardData.SameRoot** case-insensitive on Win/macOS.
- **IndexBootstrap auto-rebuild** on corrupt DB (SQLITE_CORRUPT 11 / NOTADB 26) — rescans once then reloads; non-corruption SqliteErrors still surface.
- **Dashboard launch portability** — python3 → `/bin/sh` + `nohup` (POSIX; setsid absent on macOS). Smoke-verified it detaches + writes a numeric pid on macOS.
- **SearchIndexWriter** File.Move retry loop (Windows AV/lock races).
- **SqliteReadOnlyAccess** writable-dir probe now cached per process.
- **workspace --help** — was silently running `status`; now prints `WorkspaceHelpText` for `help`/`--help`/`-h`.

### CI / release workflow
- dSYM strip, `-p:Version` on both publishes, `allow_overwrite` guard, git-diff whitespace check, AGENTS.md sync guard.
- **AOT serve smoke bug found+fixed during verify:** `$(...)` strips trailing newline, so the final `tools/list` request reached the line-delimited MCP transport unterminated and never responded — the old `grep '"tools"'` false-positived on the initialize capabilities. Now `printf '%s\n'` + assert `"id":2` and all 7 tool names.
