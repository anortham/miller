## Added Native AOT release packaging for Miller

- **WHAT:** Updated the release workflow so the main `miller` binary publishes with Native AOT while the packaged dashboard remains a self-contained non-AOT executable.
- **WHY:** Normal development should keep using regular .NET binaries, but release artifacts should ship a native `miller` binary per platform.
- **HOW:** Replaced reflection-based JSON paths with source-generated contexts, registered MCP tools explicitly instead of assembly scanning, added an AOT-scoped Serilog package-warning suppression, and documented the dashboard/Razor Components AOT limitation.
- **IMPACT:** Local AOT publish now succeeds for `miller`; the release workflow can validate AOT server packages across the existing julie-extract target matrix without rewriting the dashboard.
