- **HOW:** Verified Graphify `v8` checkout at release `0.8.32`, MIT license, Python `graphifyy` package, many assistant install flows, `graphify-out/graph.json`, optional MCP server, hooks, global graph, PR impact, media/docs/LLM extras, and tree-sitter AST extraction.
