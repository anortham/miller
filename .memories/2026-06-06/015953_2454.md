## Added CLI read-verb workspace selectors

- **WHAT:** Added `--workspace-id <selector>` to Miller CLI read verbs (`search`, `inspect`, `context`, `impact`, `trace`) and `--workspace <path>` as a path alias, including relative path resolution from the CLI context.
- **WHY:** TODO #1 asked whether Miller should borrow Julie-style CLI coverage for easier testing and dogfood. The concrete beta gap was that MCP read tools supported workspace selectors but CLI read verbs were cwd-bound.
- **HOW:** Kept the change local to `CliDispatch`: resolve the selector through the central workspace registry, reuse the existing direct read paths, keep unknown selectors as exit 2, and leave freshness work explicit via `workspace refresh/full`.
- **IMPACT:** CI/dogfood can target registered repos without changing directories or restarting MCP. README and TODO now document the resolved CLI slice.
