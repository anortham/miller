## Added Miller plugin distribution surface

### WHAT

Implemented the first Miller plugin distribution slice in the main repo:

- Added Claude plugin metadata under `.claude-plugin/`.
- Added Codex plugin metadata under `.codex-plugin/` plus root `.mcp.json`.
- Added `bin/miller-plugin-launcher.cjs`, which maps supported platforms to release targets, downloads the matching GitHub release archive and `.sha256` sidecar, verifies the archive, caches it under `~/.miller/plugin-cache`, and runs `miller serve`.
- Added root `skills/` as a generated mirror of `.agents/skills/`, plus sync/test scripts.
- Added `docs/plans/2026-06-06-plugin-distribution-design.md` documenting the decision to keep plugin distribution in the main repo for now and defer Cursor until an npm launcher or reliable plugin-root location exists.
- Fixed release packaging to include `LICENSE` and `THIRD-PARTY-NOTICES.md` in Unix and Windows archives.

### WHY

The user wanted Miller made available as a plugin for Claude and Codex, using context-mode as a reference but without creating a separate `miller-plugin` repo prematurely. A main-repo plugin layer keeps distribution tied to Miller's tested release archives and avoids syncing a second repository before there is evidence that split is useful.

### HOW

Used TDD for the Node launcher and manifest surface:

- Added failing Node tests under `tests/plugin/` first.
- Implemented the launcher and plugin manifests to pass those tests.
- Used the Codex plugin validator in a temporary Python venv; adjusted Codex metadata to the stricter root `.mcp.json` companion and complete `interface` shape.
- Added CI coverage via `scripts/test-plugin.sh` in `.github/workflows/ci.yml`.
- Updated README and release docs to make the plugin path and archive license contents explicit.

### IMPACT

Miller now has a test-covered Claude/Codex plugin distribution surface that consumes the same release artifacts users download directly. Cursor support is explicitly deferred instead of shipping a brittle manifest. The previous release-archive licensing blocker is addressed by copying and verifying notices during packaging.
