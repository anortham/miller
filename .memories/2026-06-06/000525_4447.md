## Fixed beta CI and release dashboard packaging

Miller's pushed CI was failing only on the Windows hosted-runner elapsed-time guard, while all Windows tests passed. The release workflow also published only the server project, which meant beta release archives could pass extractor checks but omit the newly added dashboard app.

- **WHAT:** Raised the Windows CI fast-suite ceiling from 300s to 420s, published the dashboard app into `dashboard/`, taught the launcher to prefer `dashboard/Miller.Dashboard[.exe]`, and added a regression test for packaged dashboard discovery.
- **WHY:** Push CI needed to go green without weakening local/Ubuntu fast-suite discipline, and release archives need to ship the dashboard that `miller dashboard` launches.
- **HOW:** Kept the main `miller` server publish separate from a self-contained single-file dashboard publish, removed duplicate dashboard `.tools`, and verified package shape for Unix and Windows workflows.
- **IMPACT:** Beta release packages now contain the main CLI/MCP binary, the matched `julie-extract`, and the loopback dashboard app/static assets.
