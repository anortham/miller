## Added MCP workspace dashboard trigger

- **WHAT:** Added `workspace(operation="dashboard")` to start or reuse Miller's local loopback dashboard from an MCP session, with compact and JSON output returning the dashboard URL.
- **WHY:** The dashboard should be reachable during an active coding session without requiring a separate shell command.
- **HOW:** Reused the existing `DashboardCliLauncher` lifecycle path, added a dedicated workspace dashboard renderer, optional `port` parameter, focused `WorkspaceToolTests` coverage, and updated README plus embedded agent instructions.
- **IMPACT:** Agents can now surface a clickable loopback dashboard URL from the workspace tool while `miller serve` remains dashboard-free.
