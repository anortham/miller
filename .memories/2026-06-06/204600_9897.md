## Landed AOT release packaging for Miller

The AOT release-packaging slice is committed and pushed on `main`.

- **WHAT:** Release workflow now publishes the main `miller` executable with Native AOT while keeping normal development builds non-AOT.
- **WHY:** We want fast, ordinary local development but native release binaries for the product packages.
- **HOW:** Added source-generated JSON contexts, replaced MCP assembly scanning with explicit tool registration, scoped a known Serilog AOT package warning to `PublishAot=true`, and changed `release.yml` to AOT-publish `Miller.Server`.
- **Dashboard decision:** The packaged dashboard remains self-contained/non-AOT because ASP.NET Razor Components currently block trimming/Native AOT via `AddRazorComponents()`.
- **IMPACT:** The release workflow can now validate native `miller` packages across the same four `julie-extract` targets without publishing a GitHub release.
