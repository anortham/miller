## Fixed shared-broker release-gate races

- **WHAT:** Made broker ownership snapshots retire an exited owner before reporting state, added a deterministic regression assertion, and replaced a wall-clock cancellation race with method-observed synchronization in the fake sidecar test harness.
- **WHY:** Full-suite concurrency could report two owners or cancel the initial health handshake instead of the intended post-embed runtime-health refresh.
- **HOW:** `Snapshot` now runs existing exited-owner cleanup before returning. The cancellation test waits for initial health, embed, and post-embed health method events before canceling.
- **IMPACT:** Broker diagnostics no longer retain stale ownership, and the release gate tests exercise the intended phase without depending on a 50 ms scheduling window.
