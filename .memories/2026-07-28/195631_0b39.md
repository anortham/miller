## Recalibrated the hosted Ubuntu fast-suite tripwire from measured evidence

- **WHAT:** Moved the Ubuntu fast-suite ceiling into `FAST_BUDGET_SECONDS=45` at the build-test job and made the shell use that value. The local `scripts/test.sh` ceiling remains 30 seconds.
- **WHY:** Main grew from 3,619 tests at the last release to 5,258. The prior successful hosted run used 29 seconds wall for 3,616 passing tests; the v1.14.0 run used 35 seconds wall for 5,254 passing tests with 4 platform skips. The old 30-second hosted ceiling no longer had runner headroom and failed despite zero test failures.
- **HOW:** Compared historical and current hosted logs, reproduced cold/warm local timing, and kept a hard hosted tripwire 10 seconds above the measured 35-second run rather than weakening the local gate or reclassifying pure tests as Scale.
- **IMPACT:** Hosted Ubuntu retains a bounded runaway detector while accommodating the measured 5k-test suite and normal runner variance.
