## Hardened the Windows passive-observation test

- **WHAT:** Changed the CLI broker-observation test to retry each status/health command until it observes the already-running broker or a five-second test deadline expires.
- **WHY:** Each production CLI observation is intentionally capped at 500 ms and may return `not_started` under transient Windows runner contention; the test incorrectly required the first bounded attempt to succeed.
- **HOW:** Added a test-only `RunUntilSemanticBrokerReady` helper. Every individual production call retains the 500 ms product bound; the test now establishes eventual observation without changing runtime behavior or weakening the final assertions.
- **IMPACT:** Removes a Windows CI flake while preserving checks for ready state, non-owner role, CPU backend, no accelerator lease, zero spawn attempts, a single broker load, and continued owner usability.
