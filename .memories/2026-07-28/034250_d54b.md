## WHAT

Closed Grok's Batch A ownership finding in `SemanticEvaluationAdapter`.

## WHY

The injected factory overload always claimed ownership, so a caller could accidentally let an evaluation session dispose a borrowed shared factory.

## HOW

Added an explicit `ownsConnectionFactory` parameter with a default of true for current evaluation callers. Tests prove default-owned disposal and explicit borrowed-factory survival.

## IMPACT

Task 3's ownership contract is now complete: session disposal cannot tear down a borrowed shared factory, including through the evaluation adapter seam.
