## WHAT

Fixed standalone JSON diagnostics when a tool has no output to attach.

- `ToolDiagnosticRenderer.AttachJson` now sends empty or whitespace payloads through the existing standalone JSON renderer.
- Added direct empty/whitespace tests and JSON convergence guards for trace, context, inspect overview/full, and impact.
- Marked Task 1 complete in the bugfix plan; also recorded reviewed Task 3 completion from sidecar commit `35c8f13`.

## WHY

Converging resolution paths often have no normal tool payload. Parsing that empty string as JSON converted the intended `resolution_converging` diagnostic into `invalid_json_output`.

## HOW

The fix checks emptiness before parsing and reuses `RenderJson`, preserving the existing schema and leaving nonempty object/array, malformed/scalar JSON, compact output, and telemetry untouched.

## IMPACT

Agents now receive valid structured convergence refusals instead of a misleading renderer error. This closes the dogfood JSON bug and unblocks reliable verification of the context performance work.
