## Approved context cancellation design

- **WHAT:** Added `docs/plans/2026-08-11-context-cancellation-design.md` in an isolated continuation worktree.
- **WHY:** A client-canceled `context` request continued consuming one core; graceful host shutdown also hung waiting for it.
- **HOW:** The approved design injects the MCP cancellation token, threads it through expensive candidate/reference phases, and checks it inside large loops. Uncanceled output and the published MCP argument schema stay unchanged.
- **IMPACT:** Defines the TDD regression and minimal production boundary needed to prevent orphaned context CPU work.
