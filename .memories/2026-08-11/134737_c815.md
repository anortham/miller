## Rewrote the Testing section's run-cadence rules

**WHAT:** `CLAUDE.md` / `AGENTS.md` Testing section now defines four tiers: focused `--filter` runs in the inner loop, the fast suite once per task boundary, the Scale suite once at the branch gate, and a new rule — never rerun a green suite on an unchanged tree (fast-forward merges and metadata-only commits do not change the tree).

**WHY:** The old text said "Run this on every change" for the fast suite. Agents obeyed it literally: full suite before a merge, again after a clean fast-forward merge, again after. That line, not agent misbehavior, was the root cause of hours of redundant suite runs.

**HOW:** Replaced the "Run this on every change" directive with per-tier cadence bullets. Kept the fast/Scale split, the csproj filter enforcement note, and the Scale trait rules unchanged.

**IMPACT:** Agents in this repo now have explicit permission and instruction to stay focused in the inner loop and to cite prior green runs on an identical tree instead of rerunning.
