## Dashboard launch guidance and copyable error details

Completed a dashboard usability slice in `/Users/murphy/source/miller`.

- **WHAT:** Tightened agent-facing dashboard launch guidance so start/open/show dashboard requests route to the Miller `workspace` tool with `operation=dashboard`, not plugin-cache file searches. Added persisted telemetry error message/detail fields and rendered expandable error details in the dashboard activity feed.
- **WHY:** User reported agents frequently failed dashboard launch requests unless explicitly told to use the Miller workspace tool, and recent `ArgumentException` rows in the dashboard lacked stack trace/details useful for issue reports.
- **HOW:** Added tests in `AgentInstructionsTests`, `TelemetryLedgerTests`, `CallToolFilterTelemetryTests`, and `DashboardActivityFeedTests`; added `TelemetryScope.SetError(Exception)`; migrated telemetry DBs with `error_message` and `error_detail` columns; made `DashboardData.ReadRecentActivity` backward-compatible with old telemetry schemas; rendered details in `ActivityFeedPanel`; updated `CLAUDE.md` and regenerated `AGENTS.md`.
- **IMPACT:** Future tool failures should leave copyable dashboard diagnostics, and future agents should have explicit guidance to use `workspace operation=dashboard` for dashboard launch requests.
