## Fixed dashboard issue-detail refresh and copy UX

### WHAT
Fixed the recent-errors/activity issue-detail UX regression:

- `details` summaries now say `view issue details` instead of `copy issue details`.
- Issue details include a separate `Copy` button that copies the full issue bundle to the clipboard.
- Expanded issue-detail rows keep their open state across htmx panel refreshes.
- Added stable `data-issue-id`/`data-copy-target` attributes and a shared `IssueDetailsScript` component.

### WHY
Users expanding a recent error lost the open details on automatic dashboard refresh, making it hard to inspect or copy useful debugging information. The old label also conflated viewing with copying.

### HOW
- Added failing rendered-component tests for recent errors and activity feed issue details.
- Added a dashboard script that captures open `details[data-issue-details]` ids before `htmx:beforeSwap`, restores them after `htmx:afterSwap`, and implements clipboard copy with a fallback.
- Updated `TelemetryPanel`, `ActivityFeedPanel`, both dashboard shells, and CSS.

### IMPACT
The dashboard now supports stable inspection of recent errors during polling refreshes, while issue report copying is a direct button action instead of hidden behind the disclosure label.
