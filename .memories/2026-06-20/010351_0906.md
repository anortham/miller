## Fixed missing Razor component symbols in Miller reads

Miller could see Eros `.razor` source text through the content corpus, but `inspect ProjectTestsDashboard` failed because julie-extract emitted only Razor directive/property rows and no component symbol for the file stem.

- **Root cause:** `SqliteSymbolReader` projected only rows from `symbols`; Razor component files could exist in `files`/content without a high-signal symbol named after the component file.
- **Fix:** `SqliteSymbolReader` now adds deterministic virtual `component` symbols for indexed `.razor` files that lack a same-name symbol. It derives the component name from the filename and the signature from `@namespace` when available.
- **Sidecar:** Bumped `SearchIndexWriter.SchemaVersion` to force old `search.db` sidecars to rebuild with the virtual rows.
- **Tests:** Added reader coverage for full reads and `ReadForPaths` incremental sidecar reads.
- **Impact:** Fixed local CLI resolves `ProjectTestsDashboard` in `/Users/murphy/source/eros` as a component instead of returning not found.
