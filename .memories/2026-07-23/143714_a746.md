## Added model-facing typed action guidance

The first cleanly scored visible calibration was non-decisional because the runner asked for structured actions without telling the agent which target fields each action kind permits.

- **Evidence:** All 11 `invalid_answer` rows across both products failed only with `typed target does not match <kind>`; the final JSON was schema-valid and often contained correct evidence and exact product IDs.
- **Root cause:** Codex's supported structured-output subset cannot express the per-kind conditional target shapes enforced by `_validate_action_target`, while `_prompt` supplied no equivalent instructions.
- **Fix:** Generate a concise action-target contract directly from `_ACTION_TARGET_FIELDS` and `_EXACT_ACTION_TARGET_ALTERNATIVES`, and include it in every benchmark prompt.
- **Guidance:** Agents must use exact symbol IDs returned by product tools, never invent path/name IDs, meet each action kind's required shape, and leave all unlisted fields null.
- **TDD:** Strengthened the runner's captured-stdin test to require the identity rule, null-field rule, and every supported action kind; observed it fail before implementation and pass afterward.
- **Verification:** All 95 Python benchmark/controller tests pass and `git diff --check` is clean.
- **Interpretation:** The `85fb88d` aggregate is valid evidence that the evaluator fails closed, but its invalid-answer-heavy product comparison is superseded and cannot be used for the takeover decision.
