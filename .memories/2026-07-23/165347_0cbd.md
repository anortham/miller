## Documented every typed action kind

- **WHAT:** Added product-neutral purpose text for all 15 structured-answer action kinds and generated it into the bound agent prompt.
- **WHY:** Miller agents used `inspect_symbol` for config facts, selected tests, captured logs, and reference workflows because the schema exposed only enum names and target fields. The verifier expected `inspect_file`, `select_tests`, `read_log`, and trace/citation actions.
- **HOW:** `_ACTION_KIND_PURPOSES` is keyed by the existing closed catalog and `action_target_guidance()` emits each meaning immediately before its target-shape rule. Contract docs now state that kinds are semantic result categories rather than product tool names or transcripts.
- **IMPACT:** The next prompt-bound calibration can attribute remaining action failures to agent/product behavior instead of an undocumented output ontology.
