## Fixed visible-gate readiness timeout

The first committed Phase 0 visible preflight refused to run because Miller's cold readiness probe exceeded the controller's identity-command timeout.

- **Context:** The isolated goldfish snapshot probe completed successfully in about 10.4 seconds, but `_command_output` had a 10-second default.
- **Root cause:** The timeout budget was shorter than a valid cold .NET/MCP semantic readiness startup.
- **Fix:** Raised the default identity-command timeout to 30 seconds while preserving explicit short timeouts used by process-cleanup tests.
- **Coverage:** Added a test that proves the default passed to `communicate` is 30 seconds; the existing forced-timeout descendant cleanup test remains green.
- **Impact:** Unblocks the five-snapshot visible calibration preflight without weakening failure handling or readiness identity checks.
