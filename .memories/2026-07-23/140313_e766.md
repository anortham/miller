## Fixed budget-failure outcome normalization

The visible calibration executed all 30 first-pass arms without harness voids, but the C# decision scorer rejected two exported Julie rows as internally inconsistent.

- **Root cause:** `_raw_result` changed budget-exceeded runs to `observed_outcome=hard_error` and removed the answer, but retained the verifier's previous `wrong_action_count`.
- **Contract:** Wrong-action counts describe judged wrong answers; a superseding hard error must carry zero wrong actions.
- **Fix:** Clear `wrong_action_count` when budget enforcement supersedes answer judgment.
- **TDD:** Strengthened the existing budget/disallowed regression with an intentionally nonzero verifier count, observed the expected failure, then made it pass.
- **Verification:** Focused regression passes and all 95 Python benchmark/controller tests pass.
- **Evidence hygiene:** The completed `67d9b59` raw execution is retained as a superseded calibration attempt. It produced no verdict and must not be reinterpreted by manually editing exports.
