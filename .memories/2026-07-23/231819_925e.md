## WHAT

Completed Phase 3 of the Miller Julie-takeover plan: exact symbol-ID reference evidence now drives trace, inspect, context, CLI equivalents, and rename. Removed `trace auto` outright from active MCP/CLI/guidance/contracts. Added exact/fallback JSON contracts, stateless reference continuation, safe rename modes, and full qualified-member resolution.

## WHY

Name-based reference attribution could mix homonyms, mislabel callers/callees, and make workspace renames unsafe. The agent surface also retained a redundant `trace auto` mode after inspect became the authoritative caller/callee workflow.

## HOW

- Normalized direct identifiers, resolution overlays, relationships, and pending evidence through `ReferenceEvidenceReader`.
- Kept unresolved name matches in a separately labeled fallback tier.
- Added 16 KiB artifact-bound trace continuation and canonical cursor validation.
- Made rename exact-by-default; explicit fallback excludes sites already resolved to another homonym.
- Fixed definition-token selection, duplicate definition evidence, full ancestor qualification, deterministic ordering, import-kind mapping, orphan relationship preservation, and caller membership independent of display truncation.
- Updated active contracts, guidance, benchmarks, findings, and regression fixtures.

## IMPACT

Miller now has target-proven reference consumers and rename behavior suitable for replacing Julie's deterministic reference/edit workflows. Phase 4 can build shared search reranking without carrying Phase 3 identity ambiguity forward.
