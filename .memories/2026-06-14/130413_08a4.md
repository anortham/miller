### WHY
- The review found duplicated graph BFS/shortest-path algorithms and duplicated search route selection between MCP and CLI surfaces.

### HOW
- Kept caller-facing interfaces unchanged: `ISymbolGraphReachability`, MCP `search`, and CLI `miller search`.
- Used internal helpers plus friend assembly access instead of adding public API.
- Left provider/sidecar opening, telemetry, stdout, and exit-code behavior in the MCP/CLI adapters for now.

### IMPACT
- Graph traversal correctness now has one implementation.
- Search route selection has one owner for mode/region classification, reducing drift between MCP and CLI.
- Remaining search work is to decide whether a deeper shared command core should own provider/sidecar opening policy too, while preserving adapter-specific output/error handling.
