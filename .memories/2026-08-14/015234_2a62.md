## WHAT

Prepared Miller 1.19.1 on `main` as the coordinated consumer release for julie-extract 2.33.2.

- `StoreWorkspaceCoordinator.Submit` now skips the redundant post-import `store resolve` only when a full import reports `Exact` and `ExactAtMatches`; all non-exact or fence-mismatched results still resolve.
- `WorkspaceFactsAssembler.StoreFreshness` now validates the complete store resolution fence and real sidecar state instead of treating the string `exact` as sufficient or hardcoding freshness.
- `refresh --json` reports the family-store sidecars actually served, using their returned hashed paths.
- Release/plugin metadata is 1.19.1; the pinned extractor and live archive hashes are 2.33.2.
- Windows scale harnesses now clear pooled SQLite handles before fixture cleanup and emit `0` when PowerShell finds no broker processes.

## WHY

The live Miller 1.19.0 session was taking roughly three minutes after a small edit because Miller submitted a whole-store resolve even after the full import had already published an exact matching resolution fence. It also reported misleading freshness/sidecar facts. The upstream producer had separate transient SQLite protocol, lease-clock, heartbeat, scoped-resolution, and Windows path issues; those are fixed and published in julie-extract 2.33.2.

## HOW

- Reviewed all five unpushed Miller commits and the complete dirty release tree against the Claude handoff.
- Preserved the safe producer/consumer boundary: Julie owns store mutation and SQLite retries; Miller trusts only a proven exact fence and otherwise resolves.
- Added explicit coverage for exact-and-matching skip, exact-but-mismatched resolve, non-exact resolve, real freshness fences, and correct store-sidecar paths.
- Corrected two Windows-only scale-test bugs without weakening product assertions.

## IMPACT

Miller no longer turns an already completed one-file/full import into a multi-minute whole-store resolve, and status/refresh consumers receive truthful convergence and sidecar facts. Julie 2.33.2 is already live and verified; this checkpoint is the final local state before committing and publishing Miller 1.19.1.
