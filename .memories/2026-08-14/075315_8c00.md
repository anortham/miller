- **WHY:** The prior parser only understood structured bootstrap fields, so real MCP content text was incorrectly treated as ready before bootstrap completed.
- **HOW:** Added a focused fake MCP session using the real `result.content` text-block shape; the existing absolute deadline is passed unchanged through all probes and retries.
