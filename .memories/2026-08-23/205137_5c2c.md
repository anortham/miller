## Aligned semantic broker Scale startup with the 120-second contract

- **WHAT:** Replaced the broker Scale test's three independent 30-second startup/endpoint/exit budgets with one 120-second constant and updated its failure message.
- **WHY:** The semantic protocol, normal Miller session initialization, and broker soak all allow 120 seconds for first model load. The test alone imposed 30 seconds, causing a Windows cold-start false negative after the model cache was correctly prepared.
- **HOW:** Applied `BrokerStartupTimeoutSeconds` to the probe's `--timeout-seconds`, the named-pipe/socket endpoint wait, and the probe exit wait. No production code or protocol changed.
- **IMPACT:** The exact shared-broker test passes on Linux in 20 seconds; the owning class passes 2 tests with 2 expected recorded-soak skips. Windows Scale must be rerun on the committed SHA to prove the cold-start path.
