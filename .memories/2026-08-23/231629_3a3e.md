## Approved Windows Scale contract separation

- **WHAT:** Captured the approved design for a health-only eight-process broker-sharing probe and a hardened loaded-host .NET provider fixture.
- **WHY:** Windows CPU fallback showed that the existing broker-sharing test also imposed accelerator-throughput expectations, causing the sidecar's deliberate 30-second queue expiry to fail an otherwise healthy one-broker/one-owner lifecycle gate.
- **HOW:** Add a strict internal `--health-only` probe option that handshakes and holds the session without embedding traffic; keep batch-8 zero-failure throughput in the existing soak gate. Increase provider PID readiness to 30 seconds and always observe its cancellation task during cleanup.
- **IMPACT:** Production Miller, sidecar protocol/queue, public APIs, process count, owner/endpoint assertions, and soak requirements remain unchanged. Work proceeds in the isolated `fix/windows-scale-contract-separation` worktree.
