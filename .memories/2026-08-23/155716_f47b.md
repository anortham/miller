## WHAT

Zod was selected as the substantive JS/TS dogfood repository and indexed successfully. Its native Vitest baseline passed 7,472 tests, while Miller CT initially stayed partial/red. Two focused defects were repaired in `JavaScriptTestProvider` with regression-first tests.

## WHY

The detected pnpm package-script path inserted a standalone `--`; pnpm forwarded it into Vitest, so Miller's reporter arguments became file filters and no JSON artifact was written. After that was fixed, Vitest 4.1.5 rejected Miller's `--cache.dir` argument as deprecated.

## HOW

- Resolve the detected package manager once and insert the package-script separator only for npm; pnpm and yarn receive reporter arguments directly.
- Keep Vitest 1.x-3.x on `--cache.dir <generation>`, use `--cache=false` for Vitest 4+, and omit cache flags for 0.x or unknown versions.
- Added focused tests for the observed pnpm argv and Vitest 4 cache contract.
- Replayed the final Release binary against Zod's real pnpm/Vitest suite.

## IMPACT

Zod CT now reports green for 192 discovered file-level cases with 0 stale and 0 failures. Python more-itertools also finished green (2/2), and Rust julie-semantic-sidecar finished with 260 green, 25 skipped, 0 stale, 0 failures. All workspaces were restored to disabled/stopped CT state.
