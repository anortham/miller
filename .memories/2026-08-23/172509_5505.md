## Task 2 review found two bounded-read defects

- **WHAT:** Reviewed the incremental alias-aware sidecar implementation in commit `7360e005` after its 62-test worker ceiling passed.
- **WHY:** The plan requires affected-symbol-ID reads to stay bounded and adds no public API surface.
- **HOW:** The delta convergence algorithm is structurally sound, but `ReadForSymbolIds` places its ID filter outside a `ROW_NUMBER` CTE, causing SQLite to enumerate the entire visible symbol view for every chunk. The new helper is also public even though it is an implementation seam. The correction will move the ID predicate into the source query, return deterministic dense local ordinals after chunk merging, make the helper internal, and add a regression containing unrelated earlier rows.
- **IMPACT:** Task 2 is not accepted yet. The focused worker suite remains green, but the correction must land before integration and branch-gate verification.
