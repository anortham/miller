## Phase A landed: delta resolution soundness fixed, equivalence gate proven non-vacuous

### WHAT
In julie-extractors worktree `.worktrees/delta-resolution-soundness` (branch delta-resolution-soundness, off a8dc664). Three defects in the shipped incremental resolution path fixed, each reproduced against the pinned 2.25.0 binary first.

**Production changes (2 files, ~100 lines):**
- `resolution.rs`: two new `WorkspaceCandidateIndex` accessors — `files_declaring_type_named` (tier-3 keys on `type_facts.resolved_type`) and `files_importing_names` (tier-2 keys on `import.imported_name`/`local_name`). Both read maps `load_index` already holds, so zero extra SQL. Unioned into `delta_scope_files`, which now takes `&index`.
- `resolution.rs`: `resolve_delta` recheck sweeps now merge by-names with new by-files worklists via a `merge_by_key` helper (first-wins, re-sorted on primary key, matching `chunked_by` determinism). Pending fill and never-attempted identifier fill widened from `changed_file_ids` to `scope_files`.
- `resolution_store.rs`: added `worklist_resolved_pending_in_files` and `worklist_resolved_identifiers_in_files`. The latter deliberately OMITS the `target_symbol_id IS NOT NULL` filter the Full variant carries, so rows recorded ambiguous/missing/no_context get retried instead of frozen.

**Tests:** 3 named regression tests in operations_contract.rs + new `resolution_scope_equivalence.rs` (4 tests) — the acceptance gate the repo did not have.

### WHY THE GATE IS REAL
Ran the equivalence oracle against unmodified main (a8dc664) in a throwaway detached worktree: **3 of 4 FAIL**, each showing its defect — aliased import `missing` vs `resolved`; module shadowing stale `95311478` vs `2ae4ea84`; receiver ambiguity keeping a tier-3 target vs `missing`. Baseline worktree removed after.

### HOW
Strict TDD. Each defect reproduced with the pinned binary in scratchpad first (delta vs full artifacts compared column by column), then written as a failing test, then fixed. `var w = new Widget()` produces no usable type fact — explicit `Widget w = ...` was required for the tier-3 fixture.

### VERIFICATION
fmt clean; clippy --workspace --all-targets -D warnings exit 0; xtask test default exit 0 (28 binaries), contract exit 0 (12), capability exit 0 (2). Note: local `stable` is 1.94.0 but crates need 1.95+, so everything ran on `cargo +1.97.1` — the user's global default was NOT changed.

### IMPACT
Phase A is a shippable correctness fix independent of the perf work. Phase B (scoping whole-repo scans) is now unblocked because its safety precondition — a sound delta path plus an equivalence oracle — exists.
