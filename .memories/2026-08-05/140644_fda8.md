## Rebind P1: artifact is portable, but the program premise is refuted

### WHAT
Ran P1 ground truth (13-agent workflow + independent verification). Wrote docs/findings/2026-08-05-rebind-p1-cost-model.md plus a docs/README.md pointer. No code changes.

**Finding 1 - the rebind surface is ONE metadata row.** All twelve path-bearing tables store root-relative paths (zero absolute paths on the live 1,397-file / 121k-symbol artifact). IDs hash the root-relative path, never the root. Only artifact_metadata.root_path is root-derived. Retargeting is one UPDATE, cheaper than P1 assumed.

**Finding 2 - rebind attacks the wrong cost.** Full from-scratch build 16.40s (resolution 4.66s, extraction 4.32s). Delta with 1 changed file: 14.40s, of which resolution 13.97s and extraction 32ms. Curve: 25 files 13.93s, 100 files 13.66s, 170 files 19.54s, 294 files 21.52s, 654 files 45.47s. Crossover at ~120-150 changed files (9-11% of the repo); a real sibling-branch pair here diverges by 723 indexed files, past it.

### WHY
Both whole-repo write sites hard-code is_full_scan: true (writer.rs:1087, :1390); the hook then takes the whole-workspace branch (resolution.rs:1551). The update/delete paths pass false and get the scoped branch. changed_file_ids is ALREADY computed and passed at both whole-repo sites (writer.rs:1085, :1388) and simply ignored. Second cause: a populated artifact can never take the bulk path (writer.rs:1639-1646), so its resolution costs 3x the from-scratch build.

Per-file update is not a workaround: 25 sequential updates take 64.76s vs 13.93s for one whole-repo scan.

**base+overlay REFUTED, not deferred:** symbol IDs fold the full span (base/types.rs:408-421), so any edit re-IDs symbols below it; a reproduction showed the base-plus-overlay union returning zero references where base alone was correct.

### IMPACT
P1 should not freeze a rebind contract on today's julie-extract. The mechanism is settled and cheap; the payoff is gated on delta-scoping resolution for whole-repo scans - a julie-extractors change that pays for itself independently (it is on the path of every session-start reconcile, workspace refresh, and cross-workspace read on every workspace, not just worktrees). Awaiting the user's sequencing decision.
