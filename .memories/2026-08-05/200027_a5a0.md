## P1 rebind contract frozen — docs/plans/2026-08-05-rebind-contract-design.md

**WHAT:** Wrote and froze the P1 rebind contract design doc for the worktree delta-rebind program, after a two-round cross-model gate (Codex + Grok first round, Codex verification second round). Program plan P1 acceptance ticked; docs/README.md map entry added. Also pushed the two pending main commits (P1 cost-model rebind + 2.26.0 pin bump) with user approval at session start.

**WHY:** P1a (delta-scoped resolution, julie-extract 2.26.0) landed and was the last gate; the user approved starting P1 this session.

**HOW — the contract's load-bearing calls:**
- v1 = copy-and-rebind: page-stepped SQLite online backup (NOT `BackupDatabase` — uncancellable) into `symbols.db.rebuild` under ONE governor admission, new julie-extract `rebind` verb (pure atomic metadata retarget: new random `artifact_id`, provenance keys, fingerprint + committed-revision refusal gates), non-force scan at the snapshot's RECORDED level, `FullRebuildPromotion.Promote`.
- **No source lock, ever**: both reviewers independently killed the draft's brief-source-`SingleWriterLock` protocol — that lock is the lifetime leadership lease (`EditWriteLock.cs:7-10`), never briefly acquirable while a main leader lives. clonefile deferred to a leader-cooperative follow-up.
- Identity: `WorkspaceId` unchanged; registry lineage columns `git_common_dir` (canonicalized — `GitWorktreeLayout` doesn't resolve symlinks), `git_is_linked`, `git_dir` + `git_dir_created_at` (BOTH halves of `WorkspaceRootIdentity`) with a bootstrap replacement→`RootRebind` consumption rule.
- No new `ScanIntent` (new values default to repair semantics + old Millers drop the journal record); explicitly never `ScanIntent.RootRebind`. W8 suppression is conservative (any standing record skips rebind) because the record has no stage field.
- Eligibility validates the copied snapshot, not the registry row (check/use race); requires committed revision (crash shells pass `ServableFor`); level inherited (progressive bootstrap wiring would emit `--level symbols` and julie exit-2s on conflict); `MILLER_FULL_REBUILD_INPLACE=1` is ineligible.

**IMPACT:** P2 (julie-extractors rebind verb + release/pin-bump, needs user approval for the release window) and P3 (Miller wiring) can start from a frozen contract. Sequencing table's next row is P2.
