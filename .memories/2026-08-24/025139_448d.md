## WHAT

Corrected the CT performance hardening design and implementation plan after adversarial review. Whole-suite xUnit runs will use verbose console output for liveness plus JUnit for structured results. Artifact attribution now requires at least one selected test match when the selected set is non-empty, but does not require every artifact row to have existed in the prior selection.

## WHY

A strict all-rows-selected rule would reject valid whole-suite results whenever the current assembly contains a newly added test that the stale CT inventory has not discovered yet. Conversely, accepting any non-empty artifact risks importing an unrelated result file.

## HOW

The importer/coordinator will resolve artifact rows before mutation, fail when a non-empty selected set maps zero rows, import matched and genuinely new rows, leave unmatched selected residue stale, and emit bounded lifecycle counts. The provider will stop parsing massive xUnit JSON only for whole-suite non-coverage runs; selected, chunked, and coverage paths remain byte-compatible.

## IMPACT

This preserves test discovery while adding a practical attribution guard, and unblocks implementation of the xUnit output fix without weakening CT state integrity.
