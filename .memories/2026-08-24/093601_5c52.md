## Task 8 graph regression fixed and verified

### WHAT
Removed the regressing bounded multi-version slice prefetch/filter path, restored `RevisionFactCache.EnsureSlice` to the indexed `RevisionFactCacheLoader.LoadStoreSlice` point loader, and added `BoundedPointSliceLoads` with `BoundedLazySliceUsesThePointLoader` as a deterministic guard. The beneficial shared graph scratch handoff and identifier-detail `VALUES` batching remain. Updated the ignored Task 8 report with root-cause and final evidence.

### WHY
The first Task 8 implementation preserved output but failed the performance gate. Controlled variants showed prefetch and filtered per-version materialization were slower than indexed point reads on the fixed workload. Keeping them would retain speculative code and fail Context/Impact acceptance.

### HOW
The red guard failed with actual 0 point loads while the broken path used `LoadStoreSlices`; the direct point-loader fix passed. The rejected `PrefetchSlices`, `LoadStoreSlices`, `VersionFilter`, and filtered propagation helpers were removed. Focused tests and Miller impact/trace checks were rerun after cleanup. Final Release timing used one warm-up plus three sequential interleaved runs against the same workspace and pre-change binary workload.

### IMPACT
Final output hashes match the pre-change hashes. Final Context timings were 1.49/1.50/1.50s (p95 1.50s) versus pre-change p95 1.609s; Impact 2.57/2.61/2.57s (p95 2.61s) versus pre-change p95 3.603s. The Task 8 graph finding now has measured proof and a focused regression guard.
