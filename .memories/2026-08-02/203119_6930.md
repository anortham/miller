### WHY

One resolver fixes both W7 and W9.

### HOW / key discoveries
- julie's `--ignore-file` files are concatenated into ONE `GitignoreBuilder` in argv order → last-wins, so a Miller-owned invariant file passed last is decisive.

- `VendorScan.BaselinePatterns` is `[".miller/", "*.log"]`, so Miller-seeded roots already exclude `.miller/`; roots with a user-authored `.julieignore` do not.
