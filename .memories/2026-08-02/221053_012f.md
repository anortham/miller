## New primary dev machine wired for Miller dogfooding (Claude Code + Codex + Grok Build)

**WHAT:** This Linux machine (Fedora, user murphy) is now the primary Miller dev machine. Miller v1.15.0 is registered as an MCP server with session hooks in all three harnesses:

- **Claude Code:** `claude plugin marketplace add anortham/miller` + `claude plugin install miller@miller` (user scope). Plugin provides the MCP server, both hooks (SessionStart/SubagentStart), and all 14 skills. Wrote `.claude/settings.local.json` (gitignored) with `"disabledMcpjsonServers": ["miller"]` so the repo's `.mcp.json` server doesn't duplicate the plugin server inside the checkout.
- **Codex:** `codex plugin marketplace add anortham/miller` + `codex plugin add miller@miller` (MCP server enabled from plugin cache). Hooks via the documented openai/codex#16430 workaround: appended the Miller SessionStart entry to `~/.codex/hooks.json`, pointing at the **checkout's** `hooks/miller-session-hook.cjs`. Codex will prompt to re-trust hooks.json on next launch (trusted hash changed).
- **Grok Build:** Claude-compat scanning does NOT see Claude *plugin*-provided MCP servers (only `~/.claude.json` + project `.mcp.json`), so Miller got a native `[mcp_servers.miller]` entry in `~/.grok/config.toml` (node + checkout launcher path) and a hook file at `~/.grok/hooks/miller.json` (always-trusted global hooks dir; SessionStart + SubagentStart, unrecognized events are skipped safely).

**WHY:** User is moving most active Miller development to this machine and wants full dogfooding parity: MCP + routing-block hooks in every harness.

**HOW:** All three use the same plugin launcher → shared `~/.miller/plugin-cache`. Pre-warmed the cache via `ensureMillerPackage`; smoke test returned `1.15.0+dbec945ad9e7`. Verified `claude plugin details` (14 skills, 2 hooks, 1 MCP server), `codex plugin list`/`codex mcp list`, and TOML/JSON validity.

**IMPACT:** New sessions in any repo on this machine get Miller tools + routing guidance in Claude Code, Codex, and Grok. Testing an unreleased local build: `export MILLER_BINARY=$PWD/src/Miller.Server/bin/Release/net10.0/miller` before launching (the launcher honors it in every harness). Claude/Codex hook+skill copies come from the marketplace-installed 1.15.0 snapshots (update via plugin update); Codex/Grok hook *scripts* run live from the checkout.
