## Scale baseline root-caused: identity conflict blocks indexing; artifact write is 90% of small-repo cold start

**WHAT:** Attempts 3–4 on dotnet/runtime plus a miller-repo phase profile completed the
investigation started this session. Findings doc + delta-rebind plan P0 updated with the full
attribution.

**Key results (all from julie-extract 2.21.0 structured `--json` reports):**
- **The blocker:** `db_write_failed: SQLite artifact write failed: reference_site identity
  conflict` (non-recoverable) — content-derived "spanless" reference-site IDs collide on
  dotnet/runtime's near-identical generated JIT test files; the whole import aborts with zero rows.
  Bigger stacks clear the crash (extraction completes) but the repo cannot be indexed at any stack
  size. Deterministic: attempts 2/3/4 retired ~identical instruction counts.
- **Phase profile at scale (58,500 files, jobs=4):** discovery 4.2 s, extraction 226 s, artifact
  write reached 82 s before abort → healthy run projects ~6–8 min. Per-file failures (1 cs, 2 ps1,
  5 xml) tolerated correctly — not a threshold abort.
- **Small-repo attribution (miller repo, 1,518 files):** discovery 21 ms, extraction 4.5 s,
  **artifact write 39.6 s of 44.2 s total = ~90% of cold start**. The top first-impression fix for
  typical repos is extractor write throughput, ahead of any progressive-levels design.
- **Bug list for julie-extractors (one-command repros, scratchpad artifacts):** (a) stack-overflow
  at default stacks, (b) ~68× spool amplification, (c) reference_site identity conflict [BLOCKER],
  (d) bare-"failed" non-JSON error path, plus (e) artifact-write throughput target.

**WHY:** User asked for a real reporter-scale repo to test against; first-ever real-repo run found
what the synthetic W10 fixture never could.

**IMPACT:** Cold-start narrative corrected: not 25–40 min — ~6–8 min at scale once fixed, and
small repos are write-bound, not parse-bound. Recommend one julie-extractors release bundling
these fixes with the fleet-safety W4–W6 flags. dotnet/runtime @ a2f953fe266 is the standing scale
target; P0 gated on the identity fix.
