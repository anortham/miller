## Prepared Miller v0.3.3 Cursor MCP compatibility release

- **WHAT:** Added Cursor workspace-root propagation through `.cursor-plugin/plugin.json`, taught `bin/miller-plugin-launcher.cjs` to choose a project cwd from `MILLER_WORKSPACE_ROOT`/Claude/Cursor env vars before falling back to cwd, bumped release metadata to `0.3.3`, and added `docs/release-notes/v0.3.3.md`.
- **WHY:** Cursor can launch imported/global MCP plugin processes without a useful project cwd, while Miller safely treats cwd as the workspace root. The launcher now uses the project folder Cursor exposes when available, reducing false imported/errored states without weakening Miller's sensitive-root guard.
- **HOW:** Added launcher cwd resolution tests for explicit Miller workspace env, unresolved `${workspaceFolder}` fallback, and Claude/Cursor workspace env fallbacks; updated version assertions and plugin manifest tests.
- **IMPACT:** Local release gates are green and the commit is ready for package-only validation, promotion, and live Cursor testing.
