## Added first Eros-facing CLI contract slice

Miller now exposes a discoverable CLI contract surface for Eros/local integrations and a telemetry JSONL feed.

- **WHAT:** Added `miller capabilities --json` with Miller version, pinned `julie-extract` contract versions, artifact schema versions, optional feature flags, supported JSON commands, and export feeds. Added `miller telemetry export --jsonl [--workspace-id ID|all]` over the machine-global telemetry ledger.
- **WHY:** Eros should consume stable Miller CLI/export contracts instead of private Miller .NET internals or scraping logs.
- **HOW:** Added `MillerContractFacts`, `CliCapabilities`, and `TelemetryExportReader`; wired `capabilities` and `telemetry export` through `CliDispatch`; documented the contract in `docs/contracts/cli-eros-v1.md`; updated README and `TODO.md` progress.
- **IMPACT:** `capabilities --json`, existing workspace/content/impact JSON surfaces, content JSONL export, and telemetry JSONL export are now documented as the first Eros integration contract set.
