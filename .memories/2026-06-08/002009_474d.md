## Added Eros-friendly top-level refresh CLI

Miller now exposes `miller refresh --json --wait` as a top-level convergence command for Eros/local integrations.

- **WHAT:** Added top-level `refresh` dispatch with `--json`, `--wait`, `--workspace-id`, `--workspace`, `--id`, `--path`, and `--full` support. The command routes through the existing registered-workspace refresh path.
- **WHY:** Eros should not need to know Miller's workspace subcommand shape just to converge a dependency workspace before ingestion.
- **HOW:** Reused `WorkspaceRefresh`, accepted `--wait` as a contract flag because the CLI refresh path is already synchronous, mapped selector aliases into the existing registry resolver, and enriched refresh action JSON with `index_fresh`, `search_sidecar`, and `content_corpus` facts. Missing packaged `julie-extract` now returns operational exit `3` instead of bubbling as unexpected exit `1`.
- **IMPACT:** The Eros CLI contract now covers discovery, workspace/content/impact JSON, content JSONL export, telemetry JSONL export, and top-level refresh convergence.
