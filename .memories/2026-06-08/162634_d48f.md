## Added Cursor plugin manifest for Miller

- **WHAT:** Added a first-class `.cursor-plugin/plugin.json` for Miller and pinned it in `tests/plugin/plugin-manifest.test.cjs`.
- **WHY:** Cursor auto-discovered Miller from the Claude plugin install as `plugin-miller-miller`, but the Claude manifest uses `${CLAUDE_PLUGIN_ROOT}`. Cursor left that placeholder unexpanded, so Node attempted to load a literal non-existent launcher path and the MCP server errored before Miller started.
- **HOW:** Kept the Claude manifest unchanged for Claude Code, added a Cursor-specific manifest using `node ./bin/miller-plugin-launcher.cjs` with `cwd: "."`, updated plugin distribution docs, release-process guardrails, and `TODO.md` status.
- **IMPACT:** Cursor can use Miller through a plugin-native manifest instead of relying on Claude-specific environment variables; plugin tests now enforce Claude/Cursor/Codex launcher surfaces together.
