## Fixed Windows verbatim path normalization gaps

Implemented the follow-up fixes from the cross-platform path review.

- **WHAT:** Canonical root output now strips safe Windows verbatim drive/UNC prefixes; workspace IDs also strip those prefixes before hashing; bootstrap root equality now uses the same Windows/macOS case-insensitive policy as workspace identity and safety.
- **WHY:** `\\?\C:\repo` and `C:\repo` could still produce different workspace IDs, and macOS default case-insensitive roots could force unnecessary rescans on case-only spelling drift.
- **HOW:** Added targeted regressions in `PathCanonicalizerTests`, `WorkspaceIdTests`, and `IndexBootstrapServiceTests`; tightened `StripWindowsVerbatimPrefix` so it does not corrupt unsupported device forms like `\\?\Volume{...}` or drive-relative `\\?\C:`.
- **IMPACT:** Stable workspace identity and bootstrap DB reuse for Windows verbatim paths; root comparison policy aligned across Windows/macOS/Linux.
