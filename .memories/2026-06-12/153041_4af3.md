## Updated Cursor README guidance

- **WHAT:** Corrected README Cursor instructions to use the proven global `~/.cursor/mcp.json` server entry with `MILLER_WORKSPACE_ROOT="${workspaceFolder}"`, and changed the public quickstart to download the v0.4.3 launcher/manifest from GitHub instead of requiring a local checkout.
- **WHY:** Cursor local plugin copies can launch from empty/global windows or collide with imported Claude plugin copies, causing Miller to start from home/plugin roots or show stale errored rows.
- **HOW:** Documented the standalone launcher root under `~/.miller/plugin-cache/cursor-global-miller`, made `.cursor-plugin/plugin.json` explicitly package/testing metadata, and updated troubleshooting to point users at the global MCP config.
- **IMPACT:** README now matches the working configuration confirmed in Cursor and should apply across user projects without per-repo setup.
