## Fixed the 50-min `workspace full` pathology (Eros field report #2) — build-to-temp + atomic promote

**WHAT:** Force scans no longer merge in-place into the live served `symbols.db`. `JulieExtractRunner.Scan(force:true)` extracts into `symbols.db.rebuild` and `FullRebuildPromotion.Promote` atomically replaces the live artifact (folds temp WAL, removes stale live `-wal`/`-shm`, overwrite-move with bounded Windows retry). Escape hatch `MILLER_FULL_REBUILD_INPLACE=1`.

**WHY:** The openclaw `workspace full` ran 50+ min at ~7KB/s and could never finish: julie's merge did random indexed reads against the existing 2GB artifact while serve readers kept the WAL from checkpointing (380MB WAL, per-page `walFindFrame`). A fresh-DB scan bulk-inserts in ~90s. Root-cause profile preserved at `docs/investigation-jx-openclaw-sample.txt`.

**HOW (the part the field report couldn't see):** the promote restarts julie's revision counter, which the serve freshness pipeline couldn't detect:
- `FreshnessService` now opens a **transient reader per poll** — a long-lived connection would freeze on the replaced file's old unlinked inode (same trap as the Pooling=false fleet finding).
- `IndexHolder`/`FreshnessPoller` track `artifact_metadata.artifact_id`; swap when the identity changes even when revision tied or went backwards. Bootstrap seeds the id.
- `CrossWorkspaceRefreshService.WaitForExternalRevision` (lock-busy full routed to a live leader) confirms via the same artifact-id arm; registered caches were already rebuild-safe (file-stamp keys, b54510e).
- Sidecar `EnsureBuilt` exact-equality checks are restart-safe; residual accepted: exact-revision-tie skip (same source ⟹ same content-derived symbols).

**IMPACT (verified live):** rerunning the real failing case — `miller workspace full --path ~/source/openclaw --json` with the fixed binary — completed in **50.2s total (43.8s scan)**, exit 0, refreshed, sidecars current (660,851 symbols / 13,308 files), 382MB stale WAL gone, single-file artifact. Fast suite 2178 green (11s), scale 28 green, Release build 0 warnings. New tests: `FullRebuildPromotionTests`, `FullRebuildScanScaleTests`, artifact-id cases in poller/PollNow/cross-workspace suites. CLAUDE.md gained the "Full rebuilds promote, never merge" rule (AGENTS.md synced); TODO.md field-report entry closed.
