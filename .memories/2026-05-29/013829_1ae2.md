## Tycho probe: residual analysis — lexical+structural recovers 21/21 cross-language bridges, embeddings not justified

**Goal:** Determine if cross-language entity bridges (TS DTO ↔ C# DTO ↔ C# entity ↔ DB table) in Tycho (.NET + Vue/TS) are recoverable WITHOUT embeddings, using lexical (name/affix) + structural (ToDto extension methods, EF DbSet pluralization, useApi route literals + [FromBody] DTOs, field-sets) signals only. Generalization test vs a prior repo (MyraNext) that used AutoMapper/typed-axios — Tycho deliberately uses none of those.

**Union recall = 21/21 (100%).** Combined lexical+structural precision = 1.000 (S3 FULL: 77/77 in-scope edges, 0 cross-concept FPs; 6 entity↔table "unknown" edges are correct out-of-scope infra, not FPs).

**By difficulty:** exact 2/2, affix 10/10, semantic 9/9. The "semantic" tier label means name-ORTHOGONAL, not embeddings-needed — all 9 recovered by deterministic structural rules.

**Two fragile spots (both fixable by rule, neither needs semantics):**
- *Dev-mode impersonation command*: covered by S3 ALONE. Rests entirely on route `POST /dev/impersonate` + a degenerate 1-field set `{userName}↔{UserName}`. Verified real (route + field match), but the field-set alone is worthless (proven by S4 FP: 1-field `{username}` shape-matches the unrelated CurrentImpersonationResponse at Jaccard 1.0). Only the exact route literal disambiguates.
- *Page navigation tree*: S4 misses it (TS `PageTreeDto extends PageDto` → shape-matches C# PageDto at 0.95, not slim C# PageTreeDto at 0.53). Trivially fixed by identical-name affix (S1/S2/S3) and by `ToTreeDto` structural edge (S3).

**Adversarial verification done:** 5 covered concepts confirmed genuine via source (UserMappingExtensions ToDto(this AppUser)→UserDto, ToDto(this AppRole)→RoleDto; ContentMappingExtensions ToVersionDto(this ContentBlockVersion)→ContentVersionDto; CalendarMappingExtensions ToOccurrenceDto(this CalendarEvent)→CalendarOccurrenceDto). Re-checked 3 S4 FPs (lowest precision 0.91): DocumentRevisionDto↔RevisionEntry (J=0.60, real generic-audit-shape collision), PageTreeDto↔PageDto (J=0.95 wrong-routing via extends), CurrentImpersonationResponse↔ImpersonateRequestDto (J=1.0 single-field) — all confirmed genuine FPs.

**Verdict:** No meaningful semantic residual. A ~GB f32 vector index + Python MPS sidecar buys nothing the cheap deterministic stack misses on Tycho. Generalizes the MyraNext result despite signals being spelled differently (ToDto extension methods vs AutoMapper; EF pluralization vs Dapper FROM-literals; useApi get<T>/post route literals vs typed axios).
