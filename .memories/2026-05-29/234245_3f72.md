## M5 complete — `context` + `impact` tools (kept fast)

The last two read tools, both built to the "fast or vestigial" mandate (julie's slowest tools were its least-used). Built TDD-by-layer (Core pure -> Indexing infra -> Server surface) via workflow, then 5-lens adversarial review + verify + fix.

- **`context`** — task-anchored, token-budgeted bundle: BM25 search seeds ∪ entry_symbols ∪ symbol tokens parsed from failing_test/stack_trace, expand both-directions to max_hops, ContextPacker greedily selects within token_budget. All in-memory (sub-100ms target).
- **`impact`** — blast radius via REVERSE-dependency BFS (Direction.Reverse = who depends on the target) over an in-memory graph. Seeds from target | changed_paths | diff (exactly one). Partitions results into impacted symbols vs likely-tests (IsTest). julie's blast_radius was 5s p95 (per-hop DB); Miller precomputes the graph once, traverses in memory.

- **Graph engine (pure Core):** SymbolGraph (forward Dependencies + reverse Dependents adjacency + bounded BFS with hop distance), ContextPacker (token-budget selection), DiffTargets (unified-diff -> path + new-side line ranges parser). Zero I/O, heavily unit-tested.
- **Edge model:** julie's resolved `relationships` ∪ name-resolved `identifiers` (containing_symbol_id -> resolve(name) to all same-name ids). Over-approximate on homonyms = the safe direction for a blast radius. Built once at index build, swapped atomically with the index.
- **Infra:** SymbolGraphReader (edge load + name resolution), RepositoryIndexLoader (symbols + edges -> index+graph, the single production build path used by both bootstrap and freshness rebuild), MillerRepositoryIndex.Build(symbols, edges) overload + Graph accessor + hydrating Dependents/Dependencies. Added IndexedSymbol.EndLine for line-precise diff mapping.

- **Review:** 7 raw findings, 4 confirmed, all fixed with 15 new red-checked tests. Top one (HIGH): the diff parser misread in-hunk body lines starting with --/++ as file headers -> impact would SILENTLY miss real changes. Fixed by tracking inHunk state with per-side line budgets from the @@ counts. Lows: usage-guard JSON used 'error' key at Empty outcome (now 'note'); dead WorkspaceContext field dropped from both DB-free tools; D10 bytes_examined now set (reverse-closure size / candidate set).
