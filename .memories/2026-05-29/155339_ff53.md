**Verified ground truth (julie v7.12.2, schema v26, extract_contract_version 1):**
- **Schema**: `files / symbols / identifiers / types / relationships` (+ symbol_annotations, external_extract_metadata) all real. Full DDL captured. Symbol id = MD5 of 8-field span string. `identifiers.target_symbol_id` ALWAYS NULL (consumer resolves); `containing_symbol_id` populated. No FTS5 (dropped in migration 007). Paths relative-unix to root_path. files.hash=BLAKE3. `types` carries resolved_type/generic_params/constraints. semantic_group always empty; reference_score needs --analyze.
- **CLI**: `julie-server extract --db <abs> --root <abs> --json scan|update|delete|analyze|info`. --db always required; parent dir must pre-exist; default output TEXT (must pass --json); exit 0/1/2 distinct; 30s flock = single-writer; first call must be scan; discovery skips >1MiB/minified/blacklisted.
- **Distribution**: anortham/julie GitHub Releases have prebuilt assets (v7.12.2: mac arm64+x64, linux-x64, win-x64). URL `releases/download/v{VER}/julie-v{VER}-{triple}.{tar.gz|zip}`. No linux-arm64, no checksums. → restore script downloads, no source build.
- **.NET**: Microsoft.Data.Sqlite 10.0.8 (bundled, auto-init) on Miller.Indexing; FrozenDictionary in-box net10.0. **WAL trap**: Mode=ReadOnly still needs write access to -shm/-wal (immutable=1 only true read-only but unsafe under live writer).
- **Spike port spec**: CodeTokenizer rules + FrozenDictionary<string,int[]> + BM25 k1=1.2/b=0.75/IDF=ln(1+(N-df+.5)/(df+.5)). Measured 565k symbols → 0.91s build / ~35MB / 25.2µs.
