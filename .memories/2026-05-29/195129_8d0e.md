## Miller M2 complete — MCP host + search + inspect + telemetry (first dogfood milestone)

M2 is built, cross-language-correct, and fully green on the converged tree (my edits + parallel collaborator edits merged cleanly).

### What shipped
- **MCP STDIO host** (`Program.cs`): IndexBootstrapService → DI singletons → AddMcpServer + WithStdioServerTransport + WithToolsFromAssembly + central `CallToolFilter` (decision-1) via WithRequestFilters. Serilog Console→stderr only (STDIO purity).
- **search tool**: lexical over `MillerRepositoryIndex`, preserves index order (never re-sorts), compact + json renderers, `… N more` overflow note, `exclude_tests` tri-state + NL-phrase detection.
- **inspect tool**: SmartTargetResolver → File/Symbol/Candidates/NotFound; symbol detail + children/refs/callers/callees/body via ExtractReader, graceful NULL-body degradation.
- **telemetry**: central TelemetryCallToolFilter, SHA256 target hashing, est_tokens, ledger rows.

### Cross-language corrections (the heart of M2, decision-4)
The original M2 workflow's 5-lens review found 5 real defects — all now fixed:
1. **is_test consumed from julie metadata across all 34 langs.** `SqliteSymbolReader.ParseIsTest` reads `symbols.metadata.is_test` (compact serde, only-when-true) → `IndexedSymbol.IsTest`. Predicate is `IsTestPath.IsTest(sym) = sym.IsTest || IsTestPath.Check(sym.FilePath)` — search uses it, so an AST-flagged [Fact] in a production-named file is hidden.
2. **Index-derived file detection** — removed the hardcoded ~22-extension whitelist. SmartTargetResolver uses `index.KnownExtensions` / `ResolveIndexedFilePath` (basename canonicalization) derived from indexed paths. A .vue/.ex/.zig file resolves as a file purely because it's indexed.
3. IsTestPath is the **language-agnostic fallback** (segments/infixes/PascalCase boundary regex), not a per-language switch.
