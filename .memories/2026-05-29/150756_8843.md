## M0 complete — repo rebranded from Codesearch to Miller, builds green, deps modernized

**WHAT:** Finished M0 (Restructure & rebrand) of the Miller MVP. Codesearch is now Miller: a .NET 10 local code-intelligence MCP server. Clean 4-project solution that builds zero-warning and tests green, with CI from day one.

**Structure created** (logic↔infra seam is the load-bearing rule):
- `Miller.Core` — pure logic, ZERO I/O deps (contract types, in-memory index + BM25, the cross-language resolver). Empty now; real types land M1/M4.
- `Miller.Indexing` — infra (julie-server extract subprocess, SQLite WAL read, watcher). Refs Core.
- `Miller.Server` — MCP stdio host. Assembly name = `miller`. Serilog → `.miller/logs/miller-.log`. AddMcpServer(Name="miller") + WithStdioServerTransport + WithToolsFromAssembly, no tools yet.
- `Miller.Tests` — xunit v3, refs all three.
- `Miller.slnx` (.NET 10 default solution format, not classic .sln).

**Removed** (FFI-coupled / out of default path): Codesearch.Interop (UniFFI), Codesearch.Embeddings, all old Tools/Services/Memory/Registry, all 10 old test files, scripts/generate-bindings.sh.

**HOW (dep modernization, all verified against NuGet):**
- ModelContextProtocol 0.6.0-preview.1 → **1.3.0** (GA, published 2026-05-08). Host API unchanged; verified at runtime via MCP `initialize` smoke test (handler completed 4.6ms, clean shutdown, exit 0).
- Microsoft.Extensions.Hosting 9.0.0 → 10.0.8 (align net10.0).
- Migrated xunit v2 (2.9.3) → **xunit.v3 3.2.2** (greenfield + zero tests = cheapest time). Required `<OutputType>Exe</OutputType>` on test project; kept Microsoft.NET.Test.Sdk (18.6.0) + xunit.runner.visualstudio (3.1.5) so `dotnet test` still works in VSTest mode.
- coverlet.collector 6.0.4 → 10.0.1. Serilog stack already at latest stable (unchanged).

**CI:** `.github/workflows/ci.yml` — restore/build (warnings=errors)/test on push+PR. Test step is time-budgeted: local target <10s, CI ceiling 30s (catches julie's runaway-suite death spiral per audit §4) without flaking on runner variance. Scale tests excluded via `--filter "Category!=Scale"`.

**IMPACT:** Repo is now "Miller," dead FFI/embeddings code gone, deps current, CI gating from M0. Unblocks M1 (extract subprocess + SQLite read + in-memory index).

**Verification:** `dotnet build Miller.slnx -c Release` → 0 warnings / 0 errors. `dotnet test` → exit 0. MCP host boots and handles initialize at runtime.
