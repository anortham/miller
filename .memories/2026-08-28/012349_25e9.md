## Approved CT correction and expansion design written

### WHAT

Created `docs/plans/2026-08-27-ct-provider-correction-expansion-design.md` for the approved JavaScript, QML/qmake, VB.NET/MTP, Go, and shared CT fact work.

### WHY

The four requested areas share language, completeness, role, and provider-identity dependencies. A written contract prevents provider slices from inventing incompatible fixes.

### HOW

- JavaScript uses a bounded typed literal-config reader and honest runner defaults.
- QML keeps framework `qt-quick-test` and delegates internally to CTest or qmake backends.
- .NET keeps framework identity separate from VSTest, xUnit v3, and MTP execution backends.
- Go v1 covers modules, in-root workspaces, top-level tests/examples, and complete JSON verdicts.
- Shared file completeness fails closed instead of returning false `KnownEmpty`.
- Spec self-review found no placeholders or contract contradictions.

### IMPACT

The design is ready for user review. Implementation and the detailed task plan remain gated on that approval.
