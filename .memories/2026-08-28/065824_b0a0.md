## WHAT

Updated five CT test fixtures to provide explicit current `CtFileFact` evidence and aligned two fake graph-hit identities with their stored test cases. No production code changed.

## WHY

The branch gate's 30 failures were caused by the new fail-closed file-evidence contract seeing symbols without current file facts. Queues returned `Unknown`, so runner and daemon status tests never reached their intended execution paths. After facts were added, one local fake still returned an unconditional graph hit for both an impacted App file and the intentionally unreachable Persistence file; that hit was removed from the local KnownEmpty scenario.

## HOW

`EngineTestSupport.Selector` now seeds indexed/current `src/App.cs` evidence and names its graph hit `test:app`, matching the stored case. Revision, reopening-generation, Debounced, and Forbidden fixtures seed only the exact changed paths they model. The Debounced KnownEmpty advance fixture relies on path-stem evidence for App and has no unconditional impact hit. Selector gates and the fake source's unavailable fallback were left unchanged.

## IMPACT

The six formerly red representative tests now pass, and the combined requested filter across all ten affected CT classes passes 151/151. The lead can run the bare suite at the branch gate; no bare suite was rerun in this packet.
