## Task 6 correction ready for commit

### WHAT

The reviewed Task 6 gaps are corrected in the working tree.

- Fileless .NET cases no longer receive a guessed C# language; same-stem C# and VB changes fail closed unless unique compatible impacted evidence maps the case.
- Dotnet discovery and run now execute the bounded property-only MSBuild evidence preflight when static global/xUnit v3 evidence is not decisive.
- Evaluated backend properties and resolved backend metadata reach discovered provider cases.
- Microsoft Testing Platform evidence refuses before VSTest execution; existing VSTest and xUnit v3 lanes remain unchanged.

### WHY

The review found that path-stem selection could silently treat fileless cases as C# and that production never used the bounded backend-evidence helpers. Both gaps could produce false selection or route an MTP project through the VSTest lane.

### HOW

The provider reads bounded static project/global evidence, probes the five runner properties through the shared process runner, requires complete stdout, resolves the typed backend, and merges metadata. Selector reconciliation keeps the existing uniquely mapped impacted-name path while requiring compatible current file language.
