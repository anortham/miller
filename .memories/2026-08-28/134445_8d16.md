## Fixed all 10 Minor findings from the pre-merge review

Second fix pass on `feature/ct-provider-correction-expansion`: every Minor finding from the standalone review is now closed.

### WHAT

1. **DotnetTestProvider** — `MissingProjectEvidence` renamed to `LegacyMissingProjectEvidence` with a doc comment naming the legacy lane; the fabricated `xunit.v3` package id is dropped (the explicit `Backend: XunitV3` already decides resolution; `IsComplete: true` stays — `Resolve` refuses incomplete evidence).
2. **QmakeQuickTestTooling quoting** — `QuoteMakeValue` now escapes `` ` `` and `$` (as `\$$`: `$$` survives make, `\$` survives the recipe shell) and quotes any escaped value.
3. **Qmake `*=` operator** — `QmakeVariableValues` accepts `*=` as append-unique, so `CONFIG *= qmltestcase` enables instead of refusing silently.
4. **Qmake include order** — `TryReadProjectModel` now splices each literal `include()` at its call site (new `TryExpandIncludes`, comment-stripped `EffectiveText`), matching qmake inline evaluation instead of appending whole `.pri` files.
5. **GoTestTooling** — `Environment(...)` no longer creates directories; new `EnsureEnvironmentDirectories` is called on the execution paths in `GoTestProvider`, so render-only command construction writes nothing.
6. **QmakeQtQuickTestBackend** — `AggregateStatus` throws on an empty result set instead of mapping it to "passed".
7. **ContinuousTestProjectInventory** — CTest registration check accepts wrapper calls (`qt_add_test`, `ecm_add_test`, `*_discover_tests`) via `CMakeTestRegistrationCall` regex.
8. **MtpTestListParser** — the zero-cases message distinguishes header-found from summary-only; `NormalizeSourcePath` catches `ArgumentException` from hostile paths (embedded NUL) and returns null.
9. **GoTestListParser** — removed the dead inner `Contains('/')` branch. **JsTestGlob** — doc comment now says callers refuse, not fall back.
10. **JS string escapes** — the config tokenizer decodes `\' \" \` \\ \/` and refuses other escapes (`DecodeStringEscapes`), instead of keeping raw backslashes in patterns.
11. **vbnet family rule** — moved from the selector's private `PathLanguagesAreCompatible` into the public `ContinuousTestLanguageFamily.AreCompatible` (vbnet matches only vbnet even inside the dotnet family); the selector helper was deleted.
