## Fixed the 4 Important findings from the pre-merge review

Standalone code review of `feature/ct-provider-correction-expansion` (range 53bba8c1..7e730239) reported 4 Important findings. All 4 are now fixed and verified.

### WHAT

1. **Go run guard** — `GoTestProvider.cs` nonzero-exit guard now throws when no result is `failed` (was: only when ALL results were `passed`). A nonzero exit with a passed+skipped mix (e.g. a `TestMain` failure) can no longer commit green. New test: `Run_refuses_nonzero_exit_with_only_passed_and_skipped_results`.
2. **Vitest default excludes** — `JsTestConfigResult` gained `HasExcludeProperty`. A vitest config that sets only `include` now keeps vitest's real default excludes (`node_modules`, `dist`, `cypress`, dot-dirs, tool config files) via `JsFrameworkTestFileDiscovery.VitestDefaultExcludes`; an explicit `exclude` replaces them. Revised `Discover_explicit_vitest_include_keeps_the_runner_default_excludes` (was asserting dist/cypress selection — wrong: Miller runs whole-suite `vitest run`, so vitest's own excludes decide what executes; discovered dist/cypress cases could never report). Added `Discover_explicit_vitest_exclude_replaces_the_runner_default_excludes`.
3. **Unknown currency** — added the missing graph-path selection test (`Select_reads_unknown_when_a_graph_impacted_test_has_unknown_evidence_currency`). DECISION: kept the hint-path behavior (an impacted-test hint with unknown currency still selects its existing provider case) and updated the design table to record both rows — scheduling an existing case produces a fresh verdict and can never carry green; refusing would degrade to Unknown and verify less.
4. **Unindexed project manifests** — qmake `.pro`/`.pri` joined `IsQmlProjectChange` (scoped QML project_scope evidence); new `AddGoProjectScopeEvidence` selects `ct-provider:go` cases whose module dir sits under the changed `go.mod`/`go.sum`/`go.work`/`go.work.sum` dir. `HasInvalidFileEvidence` exempts these manifests (extractor never indexes them) but path accounting does NOT — a manifest that selects no family cases still reads Unknown, never KnownEmpty. 7 new selector tests.

### WHY

Finding 1 was the merge blocker (failed process → green verdict). 2–4 were safe-direction gaps: phantom stale JS cases, an untested fail-closed rule plus a design-doc mismatch, and whole-project Unknown degradation on manifest edits.

### HOW

Each finding was re-verified against the code before fixing (receiving-code-review discipline). Docs updated: design-doc evidence table (two currency rows), design-doc manifest paragraph, continuous-testing.md vitest exclude sentence.

### IMPACT

Branch is merge-ready: Release build 0 warnings, fast suite 9152 passed / 0 failed, Scale suite 203 passed / 0 failed (18 toolchain skips). Minor review findings remain unfixed by decision (reported to user as non-blocking).
