## Fixed GitHub Actions workflow YAML parse failure

- **WHAT:** Identified and fixed the CI failure that happened before any jobs were created.
- **WHY:** Miller 1.0 release readiness requires green GitHub CI; the current `main` Actions runs failed with no logs/jobs because the workflow file itself was invalid YAML.
- **HOW:** Reproduced locally with Ruby YAML parsing, which reported `.github/workflows/ci.yml:128` as `mapping values are not allowed in this context`. The new Windows scale-smoke step name contained an unquoted `: `, so YAML treated it as a mapping separator. Quoted the step name and added `GitHubWorkflowConventionTests.WorkflowStepNamesWithColonSpace_AreQuoted` so future workflow step names containing `: ` must be quoted.
- **IMPACT:** The workflow YAML parses locally again, the regression guard passes, and normal local build/fast-suite verification is green. Pushing this commit should let GitHub create CI jobs again instead of failing at workflow validation.
