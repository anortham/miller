## Clarified Miller README install paths

- **WHAT:** Updated `README.md` to make plugin/release archive installs explicitly self-contained, including the bundled pinned `.tools/julie-extract` binary.
- **WHY:** The previous troubleshooting/source-checkout wording could make normal users think they had to install or restore `julie-extract` separately.
- **HOW:** Added Codex plugin guidance, clarified manual archive layout, scoped restore-script instructions to source checkouts, and split troubleshooting for packaged installs vs source checkouts.
- **IMPACT:** First-time users should understand that plugin/archive installs require neither a separate extractor setup nor the .NET SDK; only source checkout development uses the restore script.
