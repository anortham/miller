## Decision: Miller absorbs semantic search — full program design written

### WHAT
Wrote `docs/plans/2026-07-19-miller-semantic-integration-design.md` — the complete multi-phase program design for integrating a semantic embedding layer into Miller. Not yet committed (worktree comes after user review).

### WHY
Fleet telemetry (June–July 2026) proved the lexical bet succeeded for symbols (0.7–2% empty) but failed for paraphrase queries (`search source` 42–60% empty, `content` 26–46%). Julie's felt quality edge was its symbol-level semantic search. Eros (the planned home for semantics) may never ship. User decided 2026-07-19: revise the Miller/Eros boundary, fully integrate semantics into Miller — no bolt-on.

### HOW (key decisions)
- New shared repo `julie-semantic-sidecar`: Rust shim vendoring llama.cpp (Metal/Vulkan/CPU; CUDA opt-in), speaking Julie's `julie.embedding.sidecar` v1 RPC verbatim — drop-in for Julie, pinned binary for Miller.
- Model: Qwen3-Embedding-0.6B GGUF (Apache 2.0) default; dims/quantization are benchmark outputs. Sidecar `prepare` subcommand owns model download (sha256-pinned).
- Miller: resident child process (NOT a daemon), `vectors.db` sidecar with dual desired-state cursors (symbol/chunk), shadow generations, five-field generation identity (encoder/storage/corpus/reader/fusion — split so revision bumps and fusion tweaks never force re-embeds).
- Default corpus: symbol cards (local-only text, no graph enrichment) + docs/config chunks — matches Julie's proven quality bar, minutes-scale builds. All-source chunks opt-in, eval-gated.
- Retrieval: separate semantic arm at SearchRouteExecutor (typed candidate seam refactor prerequisite), weighted RRF, SemanticQueryPolicy router, semantic rescue rung. Lexical path stays byte-identical.
- Per-tool: context seed fusion + tie-break, impact hop→cosine ordering, inspect related-block, clones via MinHash Type-2 (embeddings rejected for clone claims), dead-code display-only (suppression REJECTED — similarity transfers topic not liveness).
- Edit reliability lane: telemetry showed 21% instrumented error rate; auto ladder already default — it's a guidance problem (agents pass exact explicitly) + Unicode normalization + fuzzy policy + instrumentation.
- Measurement: randomized holdout canary (frozen telemetry contract in P0), identifier non-inferiority via shadow population; source-mode KPI moved to P6 opt-in cohort.
- Phases P0–P6: governance/gates → freeze/conformance → parallel lanes (fake sidecar) → integration (RC needs user approval) → shadow rollout → canary → default-on → eval-gated extensions.

### Process
Five parallel research agents (Miller search/indexing/tools maps, Julie embedding extraction, runtime grounding with citations) + four adversarial Codex section reviews + whole-document Codex doubt pass (9 surviving objections, all folded in). Architecture risk: HIGH.

### IMPACT
Resolves the "abandon Miller for Julie?" question: Miller stays the product, Julie stays maintenance-mode and adopts the same sidecar. Next: user reviews spec → worktree → razorback:writing-plans for P0.
