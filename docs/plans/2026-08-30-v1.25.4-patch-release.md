# Miller v1.25.4 Patch Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs.

**Goal:** Review and correct the unpublished fixes after v1.25.3, then publish them as the stable Miller v1.25.4 patch.

**Architecture:** This patch keeps the existing workspace-selection, dashboard-refresh, and store-maintenance designs. Review corrections land before release metadata. Package validation builds the platform matrix once, and promotion reuses that exact successful run.

**Tech Stack:** .NET 10, GitHub Actions, GitHub Releases, Claude/Cursor/Codex plugin manifests.

**Architecture Quality:** The dashboard correction has medium concurrency risk. `DashboardRefreshJobs` becomes the sole owner of atomic current-job and retained-outcome transitions, and htmx synchronization prevents an older detail refetch from replacing a newer refresh response. Store, selector, package, and public contracts stay unchanged.

- `julie-extract` stays `2.37.2`.
- `julie-semantic-sidecar` stays `0.1.0`.
- `sqlite-vec` stays `0.1.9`.

- Every plugin manifest and marketplace version stays aligned with `Directory.Build.props`.
- Use the two-step package-only validation then exact-run promotion path.
- Do not overwrite an existing release.
- The pushed release-prep commit and published release happen in the same working session.
- Write final release verification only from live GitHub and downloaded-package facts.
- The user's 2026-08-30 request authorizes the v1.25.4 release, including the required commits, push, package validation, and promotion.
- Reviewer choice: none beyond the lead and repository-required Luna review packets.

## Verification Strategy

**Project source of truth:** `AGENTS.md` and `docs/release-process.md`.

**Worker red/green scope:** The focused test class for each corrected behavior. Behavioral fixes require a failing regression test before implementation; comment-only cleanup and release metadata are configuration/documentation exceptions.

**Worker ceiling:** Focused test classes only. Workers do not run the fast suite, Scale suite, Windows gate, plugin gate, or security gates.

**Worker gate invariant:** Workspace selector operations state the correct intent; a newer dashboard refresh outranks retained state even when it finishes quickly; malformed store reports never escape parsing; producer failures cannot be mistaken for successful destructive maintenance.

**Lead affected-change scope:** Review the full `v1.25.3..HEAD` source diff, run focused classes after corrections, and inspect all release metadata and documentation changes.

**Branch gate:** `dotnet build Miller.slnx -c Release`; one bare `dotnet test`; `scripts/test.sh scale` because the store/extractor process path changed; `scripts/test-plugin.sh`; required launcher smokes; `git diff --check`; `cmp -s CLAUDE.md AGENTS.md`; and the local NTFS Windows fast suite through `win-test` on the release commit.

**Security scope:** `security-secrets`: `gitleaks detect --source . --no-banner --log-opts=HEAD`. `security-deps`: `dotnet list Miller.slnx package --vulnerable --include-transitive`. Any secret or high/critical dependency finding blocks publication.

**Replay/metric evidence:** Package validation, exact-run promotion, stable-release state, notes-body equality, eight assets, four checksum sidecars, archive checksums, and published binary version smoke are hard gates. No performance metric is claimed by this patch.

**Escalation triggers:** Any pin, workflow, package-composition, schema, or public-contract change requires its owning specialist gate and a plan update before publication.

**Assigned verification failure:** Workers stop and report when assigned verification fails unless their packet explicitly owns the correction.

**Verification ledger:** Record invariant, exact command, scope, commit SHA, result, timestamp, workflow run IDs, release URL, assets, checksums, and published version smoke.
