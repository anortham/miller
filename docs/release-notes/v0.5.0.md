# Miller v0.5.0 Release Notes

- **Audience:** Anyone using the Miller dashboard to watch agent activity, and Cursor users installing
  Miller as an MCP server.
- **Release shape:** Feature release — the dashboard gains a live tool-call activity feed and a
  machine-wide telemetry view, and the Cursor install path moves to a global MCP config.
- **Pinned extractor:** `julie-extract 2.4.0` (unchanged).

## What Is New

- **Live activity feed in the dashboard.** A new panel shows tool calls as they happen — tool, operation,
  outcome, duration, result count, and a relative timestamp — polling the telemetry ledger every 2 seconds.
  The landing page shows a machine-wide feed (each row tagged with its workspace), and the per-workspace
  page shows a scoped one. New surfaces: `GET /fragments/activity` and `GET /activity.json`.
- **Machine-wide telemetry.** `workspace_id=all` (the same sentinel convention as content search) aggregates
  the per-tool telemetry rollup across every workspace; the landing page now mounts an all-workspaces
  telemetry panel next to the feed.
- **Relative timestamps.** Telemetry and feed timestamps render as "12s ago"-style labels (absolute UTC on
  hover) and keep aging between refreshes.
- **Workspace refresh from the dashboard.** The per-workspace page's Refresh button now actually triggers
  the refresh path and renders the outcome inline — including a neutral `lock_busy` when a live `miller
  serve` leader owns the index (it converges on its own), and a visible failure message instead of a silent
  dead button.
- **Vendored dashboard fonts.** The dashboard no longer calls the Google Fonts CDN; Archivo and JetBrains
  Mono ship inside the release archives under `dashboard/wwwroot/fonts/` (~66KB, latin variable subsets),
  so the dashboard renders identically offline. The release workflow now fails if the fonts are missing
  from a package.
- **Cursor install is now a global MCP config.** The recommended Cursor path is a `~/.cursor/mcp.json`
  entry that runs the plugin launcher with `MILLER_WORKSPACE_ROOT=${workspaceFolder}` — not a Cursor local
  plugin copy (those can launch from empty/global windows and produce duplicate plugin rows). The README
  quickstart documents the one-shot install for macOS and Windows, and
  `scripts/install-cursor-local-dev.{sh,ps1}` set the same thing up against a source checkout.
