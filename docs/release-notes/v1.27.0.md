# Miller v1.27.0 Release Notes

- **Audience:** agents that use `trace`, `impact`, `inspect` callers/callees, and marker audits.
- **Release shape:** Feature release. No MCP tools were added and no public JSON contract changed.
  The query-time resolution policy gained two rules (below); the contract doc records both.
- **Pinned extractor:** `julie-extract 2.39.0` (was 2.38.2). The extraction identity epoch moves
  from 8 to 9, so the first leader that starts on this build re-extracts every file.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.
- **Pinned sqlite-vec:** `0.1.9`, unchanged.

## What changed

### Receiver-typed call resolution

`julie-extract 2.39.0` records three fact shapes in every general-purpose language: parameter
symbols, declared-type facts for locals, parameters, and fields, and a `receiver_type` value on
self-style call sites (`this`, `self`, `super`, `base`, `$this`, and Go/Zig/Lua receiver
parameters). Miller now reads all three:

- Tier 3 Receiver binds a call site that carries `receiver_type` straight to that type's direct
  member, at confidence 0.75. No scope walk is needed.
- Variable, parameter, and field receivers bind through the new declared-type facts with the
  existing Tier 3 rule (0.75 declared, 0.65 inferred).
- Cross-file static calls into `internal` types now resolve. Policy v6 refused every non-public
  type across files, which hid most in-repo static calls in C#, where top-level types default to
  `internal`. `public` and `internal` types are reachable; null and every other visibility still
  refuse.

On this repository's fresh extract, `trace path SymbolGraph.ShortestPathWithEvidence ->
GraphTraversal.ShortestPathWithEvidence` resolves in one hop (0.70, `pending_resolution`). It was
`no_path` on v1.26.3.

### `trace mode=path` finds more paths and explains misses

- A call into an overload set (same-name symbols under one declaring parent) now gets one
  low-confidence edge per member (`identifier_name`, site confidence × 0.4), so a path through an
  overloaded method no longer dead-ends. This covers unresolved pending relationships too.
- A forward miss performs only the requested caller -> callee search. The no-path diagnostic explains
  the directional search and offers an explicit swapped-endpoint retry for reverse discovery.
- An empty result states that the search walks caller -> callee only and that unresolved call
  sites can hide a real path. An unresolved or ambiguous `to` is reported as
  `unresolved_destination` with candidate symbol ids, and `to` retries resolution with the
  caller's scope.

### Continuous testing: local-variable facts no longer blank a selection

The new extractor records locals and parameters as `variable` symbols inside every test method,
so a save of a test file now carries identifier references from each test to its own locals. Two
selector rules turned those references into an `Unknown` outcome (every case stale, nothing
runs):

- A reference from a test method the store does not know (retired, not yet discovered) fell back
  to "the one stored case in this file" and reported the identity mismatch as unrunnable. The
  fallback now matches the referencing test by name and ignores a non-matching sibling.
- A case whose file path does not look like a test path (a root-level `UnitTests.vb`) had no
  backing-file role because discovery never writes one. A typed identity that resolves to an index
  symbol marked as a test now supplies that role.

### `RAZORBACK` marker audits

`search mode=markers`, the `todos` CLI alias, and the `marker_total` metric recognize
`RAZORBACK` debt comments alongside `TODO`, `FIXME`, `HACK`, and `XXX`. The metrics SQL now builds its IN list from one metrics marker
definition.

### Continuous-testing providers

Miller CT now discovers and runs Gradle, Maven, sbt, RSpec, PHPUnit, Pest, and GUT projects.
The v1 bounds are explicit:

- Gradle requires 8.3 or newer, reads `build.gradle` or `build.gradle.kts`, prefers the project
  or workspace wrapper before PATH, discovers with `test --test-dry-run`, and keeps per-method cases.
- Maven has no separate Maven-version floor, but requires a Surefire selection surface at 2.7.3
  or newer. It prefers the project or workspace wrapper before PATH, runs `test-compile` plus
  class scanning, and keeps per-class cases.
- sbt requires 1.x, discovers with `show Test/definedTestNames`, keeps per-class cases, and uses
  `testOnly` or `test` from a persistent CT shadow.
- RSpec requires 3.x and an `rspec` token in `Gemfile`. Discovery returns per-example JSON; runs
  use `bundle exec rspec` when `Gemfile.lock` exists and direct `rspec` otherwise.
- PHPUnit requires 10 or newer and Pest requires 2 or newer. Both use local `vendor/bin` runners;
  run `composer install` when the runner is absent.
- GUT requires Godot 4, GUT 9, `config_version=5`, and per-script `res://` cases. Miller uses an
  isolated project mirror and Godot home, a 2 GiB candidate budget, and a warm metadata fast path.

`minitest`, `gdUnit4`, and GUT evidence below those floors remain recognized-but-refused with
repair guidance in the project metadata. Swift, Dart, Elixir, Erlang, native C/C++/CTest, Zig,
Lua, R, and Bash still have no CT provider.

## Upgrade notes

- Restart resident Miller and dashboard processes to load the new binary and extractor.
- Expect one full re-extract per family store after upgrade (identity epoch 9). Serving continues
  from the prior artifact until the rebuild promotes.
- Existing lexical-only output stays compatible. `MILLER_SEMANTIC=off` remains a permanent
  zero-work guarantee.
