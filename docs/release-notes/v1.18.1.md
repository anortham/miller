# Miller v1.18.1 Release Notes

- **Audience:** Users of the default versioned family store, especially large repositories and repeated no-change startup convergence.
- **Release shape:** Performance and reliability patch. The MCP surface remains nine tools.
- **Pinned extractor:** `julie-extract 2.31.4`, up from 2.31.3.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.

## What changed

### No-change sidecar convergence is metadata-only

When the visible family-store manifest has no changed files and an existing search or content sidecar is structurally valid for the same family, view, generation, extraction level, and schema, Miller now advances only its freshness stamp. It does not rebuild unchanged FTS rows.

On the Miller repository this avoids rewriting about 488 MB of search and content sidecars during a zero-delta startup. Any changed file, stale schema, identity mismatch, corruption, or missing sidecar still takes the existing rebuild path.

### Exact family-store resolution is faster

The 2.31.4 producer pin reuses validated readers and prepared statements, filters candidate lookups in SQL, streams bounded caches, and batches relationship identifier hydration. The same Miller replay improved from 6m20.55s to 2m24.54s with unchanged exact output: 37,965 gaps across 98 files and 416,361 identifiers.

## Upgrade notes

- Plugin manifests advertise version `1.18.1`.
- Source checkouts must rerun `scripts/restore-julie-extract.sh`; the build guard rejects a stale 2.31.3 binary.
- The family-store schema, resolver epoch, migration contract, semantic model identity, public commands, and MCP tool count are unchanged.
- Non-empty search/content convergence still uses the existing incremental/rebuild paths. Cursor-level A8 convergence, family-shared vectors, and A7 durable reader pins remain follow-up work.

## Verification

- The zero-delta search/content fast-forward has focused tests for no-rewrite behavior and unsafe-fallback cases.
- The release candidate requires a zero-warning Release build, fast and Scale suites, plugin/site contracts, pin restore, dependency audit, whole-tree secrets scan, and diff checks.
- Producer publication and checksums are recorded in `docs/findings/2026-08-11-julie-extract-2.31.4-adoption.md`.
