# Miller v1.19.5 Release Notes

- **Audience:** All users, especially users who leave Miller running after the
  index is current, or who save docs and source files often.
- **Release shape:** Idle-quiet and incremental-save patch. The MCP surface
  remains nine tools.
- **Pinned extractor:** `julie-extract 2.33.6`, raised from `2.33.5`.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.

## What changed

### Idle stays quiet after the index is current

When status is `current` and the queue is empty, Miller no longer opens the
multi-GB family store every 500 ms. A small freshness stamp next to the store
answers the poll. After a store write, Miller checkpoints `store.db-wal` on an
empty debounce tick so the write-ahead log does not sit at several gigabytes.

### A docs save does not start a family-store resolve

A markdown or other file with no resolve keys used to publish a new manifest
and then run `store resolve`. That walk took tens of seconds and grew the WAL.
Miller now restores the exact fence from the empty journal batch and skips
resolve. A C# save still resolves. One-file scoped resolve from 2.33.5 stays.

### Store resolve is cheaper when it does run

The pinned `julie-extract 2.33.6` loads one source file's symbols into a
bounded in-memory index and caches whole-pass unique-type lookups. The
producer CLI, report, and schema contracts do not change.

## Upgrade notes

- Re-run `scripts/restore-julie-extract.sh` or `scripts/restore-julie-extract.ps1`
  after updating a source checkout. The build guard rejects a missing or stale
  2.33.6 binary.
- Existing workspaces may run one extractor-upgrade resolve after first launch
  on 2.33.6. After that, idle should stay quiet and docs saves should not start
  julie-extract.
- `MILLER_SEMANTIC=off` remains a zero-work guarantee.

## Verification

- Focused `StoreResolutionCarryTests` and `StoreWorkspaceCoordinatorTests`
  passed 55 tests in 511 ms.
- The fast suite passed 6,676 tests with 27 skips in 87 s (Debug, live Release
  miller held the Release output).
- Native Windows dogfood of the 2.33.6 pin and idle-quiet path: WAL truncated
  to 0 bytes after current; leader CPU near zero while idle.
- Package-only validation run `32079119053` passed all four platform builds
  and package smoke. Promotion run `32079623982` passed and published the
  stable release.
