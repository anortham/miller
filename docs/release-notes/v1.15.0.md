# Miller v1.15.0 Release Notes

- **Audience:** Existing Miller users, plus teams with Erlang or XML in their workspaces — both languages
  are now indexed instead of skipped.
- **Release shape:** Compatible dependency-adoption minor release. The MCP surface remains nine tools; no
  Miller artifact schema, JSON/JSONL output contract, or semantic wire protocol changes. No Miller code
  changes beyond the pin and language-count surfaces.
- **Pinned extractor:** `julie-extract 2.21.0`, with all four published archive hashes pinned. SQLite schema 5,
  extract contract 4, report schema 3, JSONL schema 4, and reference-resolution metadata version 6 are all
  unchanged from v1.14.1.
- **Pinned semantic sidecar:** stable `julie-semantic-sidecar 0.1.0`, unchanged from v1.14.1.

## What Changed

### Two new languages: 38 total

- **Erlang** (`.erl`, `.hrl`) ships at FULL support: symbols, references, and structural facts, with zero
  capability gaps reported by `miller languages --json`.
- **XML** (`.xml`, `.xsd`, `.wsdl`) ships at DATA_ONLY support: document-structure facts for the `patterns`
  surface.
- README, the public site, agent instructions, and the routing hook now list 38 supported languages.

### Oversized-file status transition

- `julie-extract 2.21.0` reports oversized files as `unsupported` (with row removal) instead of `no_change`
  during updates. This needed zero Miller code: update consumers never branch on `no_change`, the
  `unsupported_file` warning shape was already logged, and `FreshnessReader` already maps the unsupported
  revision-change kind. Oversized sources stay excluded by the extractor's 1MB cap by design; `content import`
  (25MB) remains the text-search escape hatch.

## Upgrade Notes

- Plugin manifests advertise version `1.15.0`.
- No manual `symbols.db` migration is required. When a 2.21.0-capable leader claims a workspace built by an
  older extractor, Miller's version-aware leadership performs the forced full rescan that indexes any Erlang
  and XML files already present in the workspace.
- The semantic wire protocol and encoder policy are unchanged. `MILLER_SEMANTIC=off` remains the permanent
  zero-work guarantee, and lexical-only output remains byte-identical.
- Published archives contain Miller, `julie-extract 2.21.0`, the stable semantic-sidecar runtime, sqlite-vec,
  the dashboard executable, and local dashboard assets for all four supported targets.
