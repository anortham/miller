# Miller v1.1.2 Release Notes

- **Audience:** Agents and teams using Miller through MCP plugins, the CLI, dashboard, and Eros-facing JSON contracts.
- **Release shape:** Patch release for deterministic search recovery and cross-workspace content-read routing.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Changed

- **Text search recall.** Disk-backed `content`, `source`, `web`, `external`, and `all-text` searches now widen
  candidate recall for longer natural-language queries before BM25 ranking. Short phrases and code-like literals
  keep strict phrase behavior.
- **No semantic fallback.** The no-results recovery stays lexical and deterministic. Miller still does not add
  embeddings, vector storage, or a new MCP tool for semantic search.
- **Cross-workspace content reads.** `content read` now honors the `workspace_id` returned by cross-workspace search
  hits, including external and web imports whose source IDs live in another registered workspace.
- **Better read follow-up.** Compact content-search output now includes the workspace-aware `content read` command
  for hits that need it, so agents can recover source text without guessing the owning workspace.

## Upgrade Notes

- Plugin manifests now advertise version `1.1.2`.
- No schema migration is required.
- Agents reading external or web hits from another registered workspace should pass the hit's `workspace_id` back to
  `content read`.
