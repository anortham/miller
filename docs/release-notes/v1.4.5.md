# Miller v1.4.5 Release Notes

- **Audience:** Agents dogfooding Miller search/content workflows, Eros CT consumers, and users installing
  Miller through Claude Code, Cursor, or Codex plugins.
- **Release shape:** Patch release to publish the current telemetry instrumentation and docs/evidence updates so
  fresh dogfood can collect search-miss data on a released build.
- **Pinned extractor:** `julie-extract 2.8.1` (unchanged).

## What Changed

### Search-miss telemetry

- Empty `search` and `content search` telemetry now keeps the existing `empty_reason` and adds privacy-safe
  `query_shape` plus `empty_diagnosis`.
- Compact empty-result guidance now gives more specific next actions, including handoffs to `mode=source`,
  `mode=content`, `mode=file`, or longer-query recovery when the query shape supports it.
- This release is intended to collect a comparable fresh dogfood window before changing ranking or widening
  default symbol search behavior.

### CT impact evidence

- The Rust CT impact live-gate evidence is recorded locally for the current Miller/Eros revision-delta workflow.
- No extractor pin change is required; Eros can continue consuming Miller's public refresh and impact JSON
  contracts.

### Public-site metrics evidence

- The public site token-savings metric was refreshed on current Miller sources.
- The measurement utility now supports linked worktrees and an explicit `MILLER_SITE_METRICS_SOURCE_ROOT`, making
  future evidence runs reproducible from normal development worktrees.

## Upgrade Notes

- Plugin manifests now advertise version `1.4.5`.
- No `julie-extract` restore change is required if a checkout already has the `2.8.1` pin restored.
- Existing workspaces do not need a forced rebuild for this release. Refresh normally so released builds emit the
  new empty-result telemetry fields.
