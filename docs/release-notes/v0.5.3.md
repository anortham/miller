# Miller v0.5.3 Release Notes

- **Audience:** Agents and users who rely on the dashboard for diagnostics, issue reports, and local workspace state; workspaces containing BOM-marked UTF-16 SQL files.
- **Release shape:** Patch release for dashboard quality-of-life fixes, richer telemetry diagnostics, local dashboard asset packaging, `julie-extract` 2.5.1, and Miller-side UTF-16 follow-up compatibility.
- **Pinned extractor:** `julie-extract 2.5.1`.

## What Is New

- **Dashboard launch opens the selected workspace detail page.** Dashboard CLI/workspace launch URLs now use `/workspace?workspace_id=...`, so agents and users land on the requested workspace instead of the global workspace list.
- **Recent errors are easier to report.** Dashboard recent-error and activity rows now say `view issue details`, keep expanded issue details open across refreshes, and expose a dedicated copy-to-clipboard action for issue bundles.
- **Telemetry stores local exception details.** Tool failures now persist bounded error message/detail fields so dashboard issue details have useful debugging context when exceptions are available locally.
- **Dashboard assets are fully local and release-verified.** Shared dashboard scripts, vendored Alpine CSP assets, CSS, and fonts are packaged with the dashboard and checked by the release workflow on Unix and Windows packages.
- **Updated pinned extractor to `julie-extract 2.5.1`.** The upstream release keeps SQLite schema version, artifact extract-contract version, JSONL schema version, and JSON report schema version at `3`, so Miller's runtime compatibility gates stay unchanged.
- **UTF-16 source follow-up.** Miller now decodes BOM-marked UTF-16LE/UTF-16BE source bytes in downstream body, content corpus, legacy projection, and source-region indexing paths while keeping freshness hashes and `source_bytes` based on original file bytes.
- **Compact ambiguity output.** `inspect`, `impact`, and `trace` compact output now caps ambiguity candidates and gives more precise next-step guidance without changing complete JSON contracts.
