# Miller v1.1.1 Release Notes

- **Audience:** Agents and teams using Miller through MCP plugins, the CLI, dashboard, and Eros-facing JSON contracts.
- **Release shape:** Patch release to keep the MCP tool surface stingy after the `v1.1.0` metrics work.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Changed

- **MCP tool count is back to nine.** Removed `metrics` from the MCP tool surface so agents see the focused set:
  `search`, `inspect`, `context`, `trace`, `impact`, `edit`, `content`, `patterns`, and `workspace`.
- **Metrics remain available where they fit better.** `miller metrics churn|clones|complexity` stays as a CLI-only
  deterministic report family with the same JSON contract documented in
  [`docs/contracts/metrics-json-v1.md`](../contracts/metrics-json-v1.md).
- **Dashboard local metrics.** The selected-workspace dashboard view now shows local complexity hotspots and
  body-hash clone groups from the workspace artifact. Git churn remains CLI-only because it reads an explicit git
  revision range.
- **Patterns recovery.** Compact `patterns search` output now prioritizes the filtered metadata key and suggests
  near-miss pattern IDs on empty results.
- **Agent skills.** Added `miller-metrics-audit` and `miller-patterns-audit`, and tightened edit guidance around
  exact `replace_text` matching.

## Upgrade Notes

- Plugin manifests now advertise version `1.1.1`.
- Agents should use the metrics skill or CLI for churn, clone, and complexity reports instead of expecting an MCP
  `metrics` tool.
- Existing `miller metrics --json` consumers keep the same schema version.
