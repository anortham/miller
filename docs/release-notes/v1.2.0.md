# Miller v1.2.0 Release Notes

- **Audience:** Agents and teams using Miller through MCP plugins, the CLI, dashboard, and Eros-facing JSON contracts.
- **Release shape:** Minor release for the Miller/Julie effectiveness work: better search/inspect recovery, stronger graph/text/pattern guidance, token-saving edits, and Miller-provided handoff skills.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Changed

- **Search and inspect effectiveness.** `search auto` now has bounded source/docs rescue output for weak symbol hits, and `inspect` ambiguity output gives clearer scoped rerun guidance instead of nudging agents toward the first plausible match.
- **Overview-first inspect workflow.** Server instructions, tool descriptions, skills, README, site copy, and onboarding hints now steer first symbol reads to `inspect depth=overview`, reserving `depth=full` for complete bodies or complete relation lists.
- **Trace, content, and patterns recovery.** Empty or unsupported graph/text/pattern results now carry concrete recovery guidance. JSON outputs expose additive `next_actions`, `patterns` supports free-text `query`, and content read/search failures report structured recovery details.
- **Token-saving edit previews.** `edit replace_text` can use indexed `query`, `anchor`, and `line` selectors with exact/normalized/fuzzy matching, match proof, stale-target checks, and preview diffs before `apply=true`.
- **Handoff skills.** The plugin now includes `handoff-out` and `handoff-in` skills that create and validate local markdown packets under `.miller/handoffs/` using existing Miller tools, git state, context, and impact analysis. This does not add a new MCP or CLI tool.
- **Foundation evidence.** The Miller/Julie matrix and focused dogfood evidence now cover search, inspect, trace, content, patterns, edit, Eros-facing CLI contracts, and handoff workflows.

## Upgrade Notes

- Plugin manifests now advertise version `1.2.0`.
- No schema migration is required.
- Metrics remain CLI-only through `miller metrics <churn|clones|complexity> --json`; there is no MCP `metrics` tool.
- Handoff packets are local, ignored markdown files and should not be committed.
- Agents that know the kind of structural fact but not the exact id can call `patterns operation=search query=<text>`.
