# Miller v1.21.1 Release Notes

- **Audience:** All users. This is a stable patch release with compatibility-preserving repairs and diagnostics after v1.21.0.
- **Release shape:** Patch release. Continuous testing remains opt-in and off by default; existing MCP, CLI, and index contracts remain compatible.
- **Pinned extractor:** `julie-extract 2.35.0`, unchanged.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.
- **Pinned sqlite-vec:** `0.1.9`, unchanged.

## What changed

### Continuous testing is more predictable on Linux

CT now keeps the Linux provider and daemon paths honest under real repository
dogfood. Project outputs for referenced .NET test helpers are resolved from the
active build, Linux fixtures use portable process and filesystem behavior, and
bounded selection/chunk facts and run activity make long or partial runs
diagnosable. Start and wait outcomes expose readiness, budget, and publication
states instead of turning an unavailable result into a false green.
Hook-injected routing guidance now exposes the `tests` tool and stays aligned
with the compact core content route.

### Derived sidecars converge and clean up reliably

Search, content, and vector sidecar convergence now reports actionable health
outcomes for unchanged refreshes and quiet workspaces. Workspace removal and
prune clean generated ignore policy and reclaim the workspace's derived store
sidecars without losing crash-durable cleanup work.

### JavaScript and TypeScript discovery keeps pace

Continuous testing recognizes pnpm layouts and current Vitest 4 behavior while
preserving the existing vitest, Jest, and Node test provider contracts.

### Search aliases stay deterministic

Search projections canonicalize aliased symbols by logical identity and bound
candidate attribution. Incremental sidecar updates converge by logical ID,
avoiding duplicate rows and unstable ranking after restarts or refreshes.

### Windows output and Scale fixtures are portable

Compact status, run, and failure renderers normalize line endings to LF so
cross-platform output remains byte-stable. Windows Scale fixtures now select
the current referenced-project apphosts, tolerate loaded-host cleanup timing,
and separate broker-sharing lifecycle checks from throughput soak checks.
Broker sharing and semantic throughput remain separate verification contracts;
this patch makes no claim about improved sidecar throughput.

## Upgrade notes

- No producer pin changed. Existing installations do not need a re-extract or
  forced rescan for this patch.
- Source checkouts should continue to restore the pinned `julie-extract 2.35.0`
  binary when the build guard requires it.
- Rebuild and restart a resident Miller server or CT daemon to load the new
  binary. `MILLER_SEMANTIC=off` remains a permanent zero-work guarantee, and
  lexical-only output remains byte-identical.

- Focused release metadata verification passed all four version assertions and
