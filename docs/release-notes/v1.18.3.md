# Miller v1.18.3 Release Notes

- **Audience:** All users of Miller's default-on local semantic retrieval, including first-time installers.
- **Release shape:** Semantic pause/recovery reliability and release-validation patch. The MCP surface remains nine tools.
- **Pinned extractor:** `julie-extract 2.32.1`, unchanged.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.
- **Publication:** Stable coordinated Miller release.

## What changed

### Semantic pause reporting matches the recovery path

Workspace health and onboarding now honor a matching recorded semantic pause before falling back to generic
freshness advice. Users see the actual reason a vector store is not serving, such as an unprepared model, an open
broker circuit, or a disk block, instead of being sent to an unrelated refresh path.

Preparation guidance is recommended only when the pause explicitly reports a model that is not prepared or a
genuinely absent vector artifact. Corrupt, unreadable, incompatible, or otherwise unavailable vector artifacts
retain their diagnostic state without suggesting model preparation.

### Semantic pauses are bound to the complete family-store snapshot

Recorded family-store pauses now match every field of `StoreSidecarStamp`. A stale or unscoped pause cannot mask a
newer family-store snapshot, so pause reporting stays attached to the snapshot it describes.

### Prepare and restart guidance is explicit

Setup guidance now distinguishes the one-time `miller semantic prepare` step from the state of a live broker. When
the command reports `activation=activated`, no restart is needed. Restart only when activation reports
`no_live_broker` or `still_not_ready`.

### Release probes are deterministic and fail early

The Scale probe launches the apphost from a deterministic clean-worktree location. The shell and PowerShell
semantic-soak scripts now fail immediately when a model-readiness event fails, before starting long traffic.

## Upgrade notes

- Default semantic retrieval remains enabled; `MILLER_SEMANTIC=off` remains the permanent opt-out.
- The extractor pin, semantic sidecar pin, family-store schema, semantic model identity, and public commands are
  unchanged.
- Plugin and marketplace manifests advertise version `1.18.3`.
- The MCP surface remains nine tools.
- No new public command or output shape was added.
