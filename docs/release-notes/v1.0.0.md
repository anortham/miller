# Miller v1.0.0 Release Notes

- **Audience:** Agents and teams using Miller as the deterministic local code-intelligence core for search, navigation, edits, workspace freshness, telemetry, and Eros-facing exports.
- **Release shape:** Stable 1.0 release with readiness hardening, public contract cleanup, and a smaller MCP tool surface.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Is New

- **Stable 1.0 tool surface.** MCP now exposes nine tools: `search`, `inspect`, `context`, `trace`, `impact`, `edit`, `content`, `patterns`, and `workspace`. TODO/FIXME/HACK/XXX audits moved into `search` as `mode=markers`; `todos --json` remains a CLI compatibility alias for Eros/scripts.
- **References export for Eros workflows.** Added the public `references export --jsonl` feed and contract so Eros can build dead-code and usage workflows from deterministic Miller facts without reading private SQLite internals.
- **Telemetry-derived onboarding.** Workspace status can now expose first-session onboarding facts derived from Miller telemetry, with a documented JSON contract for agents and downstream tools.
- **First-class Eros JSON contracts.** `workspace status --json`, `workspace health --json`, `refresh --json --wait`, trace JSON, content corpus, patterns JSON, and references export are documented as stable public contracts.
- **Readiness hardening.** Miller now logs POSIX lock-acquisition I/O failures instead of flattening them into silent contention, canonicalizes cwd-sensitive-root checks, makes leadership lease visibility explicit, supports configurable full-rebuild promotion retry timeout, and avoids per-term FTS document-frequency round trips.
- **Trace refs and edit hardening.** Name-based reference lookup stays under `trace mode=refs` with explicit confidence labels, and edit target resolution handles archive/path safety fixes from the 1.0 review pass.
- **Release and Windows checks.** CI and release validation now include stronger Windows package checks, exact workflow-step quoting, and restored extractor pin verification on Windows.

## Upgrade Notes

- The standalone MCP `todos` tool has been removed. Use `search --mode markers "TODO,FIXME,HACK,XXX"` for marker audits. Existing CLI automation may continue to use `todos --json`.
- Plugin manifests now advertise version `1.0.0`.
- Existing `.miller/search.db` files continue to rebuild automatically when the sidecar schema or source-region option no longer matches the running binary.
