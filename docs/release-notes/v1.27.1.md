# Miller v1.27.1 Release Notes

- **Audience:** agents using Miller continuous testing or its MCP tools.
- **Release shape:** Patch release. No MCP tools or public JSON contracts changed.
- **Pinned extractor:** `julie-extract 2.39.0`, unchanged.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.
- **Pinned sqlite-vec:** `0.1.9`, unchanged.

## What changed

### Continuous testing refreshes inventory before idle drain

The CT daemon now refreshes project inventory before an idle-drain run. This keeps parameterized
test case IDs synchronized with provider output and prevents a foreign-key failure when a provider
reports cases that were absent from stale method-level inventory.

The fix was replayed against the affected workspace: inventory grew from 9,368 to 9,631 cases, all
three projects finished green, no stale cases remained, and the prior foreign-key retry disappeared.

### Compact Miller output is the default guidance

Embedded agent instructions and plugin routing guidance now tell agents to use compact output for
interactive work and request JSON only when a structured result is needed for parsing or chaining.
Tool behavior and response contracts are unchanged.

## Upgrade notes

- Restart resident Miller, dashboard, and CT daemon processes to load the new binary.
- No index rebuild, pin refresh, or configuration change is required.
