# Miller v0.5.7 Release Notes

- **Audience:** Agents and users indexing large workspaces with frequent incremental rewrites or deletes.
- **Release shape:** Patch release that advances Miller's bundled extractor to upstream SQLite cleanup-path indexing fixes.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Is New

- **Large incremental updates avoid extractor-side cleanup table scans.** Miller now bundles `julie-extract 2.5.3`, which adds missing SQLite indexes used by writer delete paths and foreign-key cleanup paths for relationships, pending relationships, type facts, symbol annotations, type argument usages, type arguments, literals, and parse diagnostics.
- **Artifact contracts stay stable.** The pinned extractor keeps the durable SQLite schema version, extract contract version, JSONL schema version, and JSON report schema version at `3`.
- **Miller stays a consumer of extractor output.** No Miller-side parser or schema workaround was added; this release only repoints Miller to the upstream extractor package with the same contract.
