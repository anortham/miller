# Miller v1.11.0 Release Notes

- **Audience:** Teams using the Miller dashboard for workspace and telemetry visibility.
- **Release shape:** Dashboard UX release (10-task plan plus post-merge and review follow-ups). No MCP
  tool, artifact schema, or index migration was added.
- **Pinned extractor:** `julie-extract 2.14.0` (unchanged).

## What Changed

### Rendering and refresh

- Polled panels stop flickering: morph swaps with fragment ETag/304 responses, and static assets are
  cache-busted so upgrades never pair stale CSS with new markup.
- Workspace refresh runs as an async job with polled progress instead of blocking the request; Cancel no
  longer navigates away.

### Tables, navigation, and polish

- Telemetry tables use real table semantics with sortable columns, aligned recent errors, whole-row
  click targets, and a "Last used" column.
- Notice toasts replace silent outcomes; JSON links open in a new tab; a styled 404 page and version
  footer land; the recorded window shows under trend sparklines; the hero-metrics grid is responsive and
  panels no longer silently clip.
- Review follow-ups: popovers no longer steal clicks or clip at panel edges, an empty registry renders a
  404 instead of echoing the selector, plus pluralization, unresolved hot-target collapse, and pattern
  list noise fixes.

### Security and packaging

- Dashboard POST endpoints require a loopback Host allowlist match and a CSRF header on non-form POSTs.
- The release workflow verifies the vendored `htmx` and `idiomorph` dashboard assets in both packaging
  verification blocks, so a package missing them fails the build instead of silently breaking morph
  swaps.

## Upgrade Notes

- Plugin manifests advertise version `1.11.0`.
- No configuration, schema, or index migration is required. The dashboard remains local-first (no CDN
  fetches).

## Known Issue (fixed in v1.11.1)

- On Windows, workspaces containing Blazor components crash-loop server bootstrap with
  `Invalid URI: The hostname could not be parsed.` (introduced with v1.9.0's project-namespace
  inference). Upgrade to [v1.11.1](v1.11.1.md).
