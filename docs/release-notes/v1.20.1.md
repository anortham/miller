# Miller v1.20.1 Release Notes

- **Audience:** All users. This is a patch release: one output fix and
  smaller continuation tokens.
- **Release shape:** Patch release. The MCP surface remains nine tools.
- **Pinned extractor:** `julie-extract 2.34.1`, unchanged.
- **Pinned semantic sidecar:** `julie-semantic-sidecar 0.1.0`, unchanged.

## What changed

### The inspect banner prints once

The MCP `inspect` tool printed its `workspace:`/`freshness:` header twice
whenever the header applied — on every call with an explicit `workspace_id`,
and on any call while the index was not current. The entry method added the
header a second time after the render core had already added it. Compact
output now carries one header. JSON output was never affected. The other
read tools were audited for the same shape and print the header once.

### Continuation tokens are less than half as long

The opaque continuation tokens returned by `inspect` (file listings and
`depth=full` body pages), `trace mode=refs`, `patterns`, and `impact` output
pages used a JSON payload with hex-string fields. A file-listing token was
about 470 characters. The payload is now binary: hex identifiers pack to raw
bytes, integers are varints, and the checksum rides as raw bytes. The same
token is now about 200 characters. The token stays an opaque base64url
string, so the documented contracts and the CLI `--continuation` flags are
unchanged, as are all diagnostic codes.

## Upgrade notes

- A continuation token issued by an older build is rejected with the
  existing `continuation_invalid` refusal and its restart action. Tokens
  only live inside one pagination, so re-run the listing without a token.
- No index, store, or artifact change. No rescan runs on upgrade.
- `MILLER_SEMANTIC=off` remains a zero-work guarantee, and lexical-only
  output stays byte-identical.

## Verification

- Regression tests were added for both fixes: banner-once assertions for
  symbol and file targets, and continuation tests covering legacy-token
  rejection, cross-type rejection, a Unicode identity round trip, and a
  compact-size gate.
- The fast suite and the Scale suite passed on the release tree.
