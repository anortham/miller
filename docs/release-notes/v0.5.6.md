# Miller v0.5.6 Release Notes

- **Audience:** Agents and users indexing Razor, GDScript, or mixed-language workspaces through Miller.
- **Release shape:** Patch release that advances Miller's bundled extractor to the upstream Razor/GDScript fix.
- **Pinned extractor:** `julie-extract 2.5.2`.

## What Is New

- **Razor component symbols are restored at the extractor level.** Miller now bundles `julie-extract 2.5.2`, which emits the top-level Razor component symbol for `.razor` files instead of only the directive/import rows. This fixes symbol lookup for components such as `ProjectTestsDashboard`.
- **GDScript receives the same extractor-side hardening.** The new pin includes the related GDScript extraction fixes from the same upstream release.
- **No Miller-side synthetic Razor fallback was shipped.** The fix stays in `julie-extractors`, preserving Miller's boundary as a read-only consumer of extractor output.
