# Miller v1.9.0 Release Notes

- **Audience:** Teams using Miller for deterministic navigation across Blazor and extractor-backed structural facts.
- **Release shape:** Feature release for julie-extract 2.14.0 adoption and namespace-aware Blazor component edges.
  No MCP tool, artifact schema, or index migration was added.
- **Pinned extractor:** `julie-extract 2.14.0` (upgraded from 2.13.0).

## What Changed

### Blazor namespace resolution

- Simple component tags now resolve through inherited `_Imports.razor` `@using` and `@namespace` directives,
  fact-local namespace context, source/enclosing namespaces, and bounded SDK-project folder inference.
- Fully qualified tags still resolve exactly, while ambiguous or unsupported namespace evidence fails closed instead
  of creating a guessed `uses` edge.
- Conditional or imported MSBuild namespace evaluation, custom/additive SDKs, symlinked paths, oversized project
  files, and malformed extractor metadata do not contribute inferred namespaces.
- A divergent inherited `@namespace` no longer makes the unrelated project-root namespace implicitly visible.

### julie-extract 2.14.0

- Miller now bundles and pins julie-extract 2.14.0 on all four release targets.
- Pattern guidance reflects the 2.14 catalog: 175 pattern IDs across 36 languages, including the new T-SQL
  `MERGE` structural fact through Miller's existing generic `patterns` surface.
- Extractor schema 4, extract contract 3, and report schema 3 remain unchanged.

## Upgrade Notes

- Plugin manifests advertise version `1.9.0`.
- The newer bundled extractor triggers Miller's existing version-aware full rebuild when the instance becomes
  index leader. No manual schema migration or configuration change is required.
- Razor component symbols and facts remain available when the extractor reports a whole-file Razor diagnostic.
  `.cshtml` component-reference resolution remains deferred because 2.14 does not emit those reference facts.

## Verification

- An independent Claude review found two Blazor release gaps; both were reproduced, fixed, and regression-tested.
  Its separate SQLite flake report did not reproduce across eight sequential and four concurrent full-suite runs.
- Pre-release verification passed with a clean Release build, 3,270 fast tests, 52 Scale tests against the real
  julie-extract 2.14.0 binary, and 28 plugin contract tests.
- Cursor-style launcher smokes completed MCP `initialize` and `tools/list` from `/` and a non-Miller project
  directory, returning all nine tools. NuGet reported no known direct or transitive package vulnerabilities.
- Live package and release verification will be linked here after publication.
