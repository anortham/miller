# Miller v1.1.0 Release Notes

- **Audience:** Agents and teams using Miller for deterministic local code navigation, JSON contracts, workspace diagnostics, dashboard review, and Eros-facing raw feeds.
- **Release shape:** Minor release for new local metrics surfaces, empty-state recovery, leader handoff diagnostics, and dashboard panels.
- **Pinned extractor:** `julie-extract 2.5.3`.

## What Is New

- **Deterministic metrics.** Added `metrics churn`, `metrics clones`, and `metrics complexity` as MCP and CLI surfaces. Churn maps a commit range to current indexed symbols, clone groups report identical `body_hash` groups with bounded symbol lists, and complexity ranks rows from extractor `complexity_metrics`.
- **Commit-range impact.** `impact --base A..B` now accepts git commit ranges, so review workflows can map recent history to impacted symbols without shelling out separately.
- **Empty-state recovery.** `inspect` and symbol `search` misses now include near-match suggestions from indexed identifiers when Miller can identify useful candidates.
- **Workspace leader diagnostics and handoff.** Added `workspace leader` with a documented JSON contract, plus graceful handoff request wiring through the existing leader scan queue.
- **Dashboard health and onboarding panels.** The dashboard now renders workspace health and telemetry-derived onboarding facts from the existing JSON contracts.
- **Content read round-trip hardening.** `content read` can open workspace source ids returned by workspace content search, including registered cross-workspace ids.

## Upgrade Notes

- Plugin manifests now advertise version `1.1.0`.
- The new metrics JSON contract is documented in [`docs/contracts/metrics-json-v1.md`](../contracts/metrics-json-v1.md).
- The new workspace leader JSON contract is documented in [`docs/contracts/workspace-leader-json-v1.md`](../contracts/workspace-leader-json-v1.md).
- Clone metrics bound the number of listed symbols per group by default; use `--max-symbols-per-group` when a workflow needs a larger sample. The full group `count` is preserved.
- `workspace leader --handoff` requests graceful abdication through Miller's existing coordination path; it does not kill processes.
