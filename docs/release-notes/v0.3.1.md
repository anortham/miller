# Miller v0.3.1 Release Notes

- **Audience:** Windows and macOS users installing Miller through agent plugins or release archives.
- **Release shape:** Patch release for cross-platform workspace path correctness.
- **Pinned extractor:** `julie-extract 2.1.3`.

## What Is Fixed

- Windows workspaces whose `julie-extract` metadata records a Rust canonical path such as
  `\\?\C:\source\repo` now reuse the existing index instead of force-scanning on every startup.
- Miller canonical roots and workspace IDs now normalize safe Windows verbatim drive and UNC spellings, so
  `\\?\C:\repo` and `C:\repo` identify the same workspace.
- The verbatim-prefix stripper is intentionally narrow: it handles safe drive and UNC forms, and leaves device
  forms such as `\\?\Volume{...}` and drive-relative `\\?\C:` unchanged.
- Bootstrap root comparison now follows the same path identity policy as the workspace registry: case-insensitive
  on Windows and default macOS, case-sensitive on Linux/POSIX.
- Bare filesystem roots such as `C:\` keep their root form during canonicalization instead of collapsing to the
  drive-relative `C:` form.

## Verification

- Fast test suite passed on Windows: 1779 total, 1771 passed, 8 skipped.
- Targeted regression tests cover Windows verbatim roots, workspace ID stability, unsupported verbatim device
  forms, and macOS-compatible root comparison policy.
