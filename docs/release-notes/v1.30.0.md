# Miller v1.30.0 release notes

- Audience: agents using Miller through plugins, MCP, or the CLI.
- Release shape: Julie 3 integration and reliability fixes. No new MCP tools.
- Extractor pin: `julie-extract 3.7.2`, upgraded from 2.42.0; 42 supported languages.
- Semantic sidecar: `0.1.0`, unchanged.
- sqlite-vec: `0.1.9`, unchanged.

## What changed

- Miller uses standalone workspace indexes with Julie 3, which removed the family-store and export commands.
  Existing workspaces rebuild safely, preserve imported external/web content, and retire old pointers only after
  successful promotion. Original shared family data is retained.
- Watchers recognize basename-selected sources such as `go.mod` and `go.sum`, with exclusions matching Julie.
- Concurrent plugin launches preserve the winning installation. Windows runtime restoration works without an
  interactive console and preserves the caller's PowerShell settings.
- Windows drive-root canonicalization retains the root separator. Edit cleanup only removes temporary files
  belonging to the planned targets.
- Continuous testing adopts a completed rebuild's generation instead of repeatedly detecting the same rebuild.
  Dashboard and CT results explain when source rebuilding is required and avoid stale legacy reads.
- Semantic vector validation rejects small nonzero vectors that do not meet normalization requirements.
- Source setup documents restoration of both pinned runtimes.

## Upgrade notes

- Stop older Miller MCP servers, dashboards, and CT daemons before switching builds. Simultaneous old family-store
  writers are not supported during migration.
- Existing family-store workspaces require an explicit refresh with a full rebuild. Follow the
  [Julie 3 migration guide](../julie-3-migration.md); a failed migration retains its pointer for retry.
- `MILLER_INDEX_STORE=on` is refused because Julie 3 no longer implements that backend. Remove the override.
- The semantic model identity and MCP tool surface are unchanged. `MILLER_SEMANTIC=off` remains a zero-work switch.
