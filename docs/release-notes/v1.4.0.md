# Miller v1.4.0 Release Notes

- **Audience:** Agents and teams using Miller bridge traces across frontend/backend HTTP boundaries, and anyone
  relying on Miller's compact tool output and MCP guidance surfaces.
- **Release shape:** Minor release for the `julie-extract 2.7.0` pin, the new `backend-http` bridge provider,
  a tool-output compaction pass, and the ADR-0001 guidance-delivery channels.
- **Pinned extractor:** `julie-extract 2.7.0`.

## What Changed

### backend-http bridge provider

- **New `backend-http` provider.** `trace mode=bridge` now joins client HTTP requests
  (fetch/axios/`requests`/`httpx`/`net/http`/`Net::HTTP`/`HttpClient`) directly to backend route templates
  across 16 backend HTTP families: Express, Fastify, FastAPI, Flask, Django, Spring, Go `net/http`, gin, echo,
  Rails, and friends.
- **Cross-file mount-prefix composition.** Mounted routers (for example an Express router mounted under
  `/api`) compose their full route template across files before matching.
- **Rails resource expansion.** `resources`/`resource` declarations expand to their member/collection routes
  with `controller_action` binding.
- **C# structural HttpClient calls.** Structural `HttpClient` call facts are admitted as real client calls, so
  C# service-to-service requests participate in bridge evidence.
- **Diagnostics parity.** `backend-http` is wired into route diagnostics, evidence gates, and marker audits with
  the same vocabulary as the existing providers.

### Extractor pin

- **`julie-extract 2.7.0`** (from 2.5.10 via 2.6.1): backend HTTP boundary fact families plus the 2.6.1 bridge
  binding semantics, validated by the build pin guard.

### Tool output compaction

- **search:** identical (source, line) text-content hits dedupe; multi-marker lines collapse in markers mode;
  weak-result rescue output owns its closing affordance.
- **inspect:** refs group by file and callees dedupe with `×N` at full depth; doc-comment lines are stripped
  from the overview body preview.
- **trace:** `refs` output resolves `containing=` to the enclosing symbol name.
- **context:** neighbours rank by relevance instead of symbol id.
- **workspace:** `list` is recency-ordered, capped, and filterable; onboarding collapses unresolved hot targets
  to one line.
- **content:** empty-search recovery advice is stated once via the `Next:` block.

### Guidance delivery channels (ADR-0001)

- **ServerInstructions discovery core** rewritten to fit the real ~2KB Claude Code injection window: all nine
  tools in a most-important-first routing table, verified un-truncated in a live client.
- **Golden tool descriptions** now serve as post-discovery usage contracts with per-tool budgets, including
  `NOT for:` routing clauses.
- **NextStepHint nudges:** compact output gains one-line success-path hints (search → inspect, trace refs →
  impact, inspect high-dependent symbols → impact), suppressed where recovery guidance already owns the close.
- Long-form guidance relocated to [`docs/agent-guidance.md`](../agent-guidance.md) and the plugin `miller-*`
  skills; decision record in
  [`docs/adr/ADR-0001-guidance-delivery-channels.md`](../adr/ADR-0001-guidance-delivery-channels.md).

## Upgrade Notes

- Plugin manifests now advertise version `1.4.0`.
- No Miller schema migration is required; a leader running the new pin performs its normal
  extractor-upgrade full rescan on claim.
- Source checkouts should rerun `bash scripts/restore-julie-extract.sh` so `.tools/julie-extract` matches the
  `2.7.0` pin.
