# Miller v0.5.1 Release Notes

- **Audience:** Agents relying on Miller's live file watcher, especially in repositories with frequent
  directory moves/deletes or extensionless operational files.
- **Release shape:** Patch release fixing watcher freshness edges and agent guidance around missing indexed
  symbols.
- **Pinned extractor:** `julie-extract 2.4.0` (unchanged).

## What Is Fixed

- **Directory subtree changes now force scan reconciliation.** Recursive file watching already handled normal
  file creates, changes, deletes, and renames. Directory creates/deletes/renames are now routed through a
  dedicated directory watcher and force a delta scan instead of being misinterpreted as single-file events.
  This avoids stale rows after subtree moves or deletes.
- **Pending forced rescans are visible to freshness checks.** `index_fresh` now treats signaled rescans and
  overflow fallback work as pending indexer work, so status cannot report fresh while a scan fallback is still
  queued.
- **The watcher extension gate fails soft for extensionless paths.** When julie-extract's language catalog is
  available, Miller still drops files with explicitly unclaimed extensions, but it no longer drops paths such
  as `Dockerfile`, `Makefile`, `.env`, or trailing-dot names solely because they have no extension. The extractor
  can safely no-op if it does not recognize them.
- **Agent instructions now handle no-symbol file inspections better.** If `inspect <file>` reports no indexed
  symbols for an expected code file, agents are instructed to refresh and retry before falling back to raw file
  reads.
