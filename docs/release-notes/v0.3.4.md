# Miller v0.3.4 Release Notes

- **Audience:** Claude Code and Cursor users installing Miller through agent plugins, especially on Windows.
- **Release shape:** Patch release for Cursor startup compatibility through Claude-imported plugin installs.
- **Pinned extractor:** `julie-extract 2.1.3`.

## What Is Fixed

- Cursor now starts the Miller launcher through `${CURSOR_PLUGIN_ROOT}` instead of a relative `./bin/...` path.
  Cursor resolves relative MCP args against the open workspace or `/`, not reliably against the plugin root.
- The Cursor manifest no longer sets `MILLER_WORKSPACE_ROOT="${workspaceFolder}"`. Cursor resolves manifest env
  vars before process launch, so no-folder Settings windows can fail before the launcher runs.
- The plugin launcher now refuses sensitive startup cwd values such as `/`, the home directory, `/Users`, `/home`,
  `C:\Users`, and `C:\Windows`, then falls back to the plugin root instead of letting Miller index a broad system
  path.
- Cursor install instructions now call for a real directory copy under `~/.cursor/plugins/local/miller`; Cursor
  rejects local plugin symlinks that point outside that tree.
