# Miller v0.3.2 Release Notes

- **Audience:** Claude Code, Cursor, Codex, and Windows users installing Miller through agent plugins or release
  archives.
- **Release shape:** Patch release for Cursor plugin support and Windows follow-up fixes.
- **Pinned extractor:** `julie-extract 2.1.3`.

## What Is Fixed

- Cursor is now a first-class plugin target through `.cursor-plugin/plugin.json`. The manifest uses the
  plugin-root-relative launcher path Cursor expects instead of relying on Claude Code's `CLAUDE_PLUGIN_ROOT`
  placeholder.
- `content({})` over MCP now defaults to the list operation instead of failing argument binding before the tool
  handler runs.
- Qualified symbol targets such as `Class.Member` now resolve through the shared smart target resolver, including
  scoped inspect calls for private helper methods.
- Windows release packages now smoke-test `miller.exe serve` with JSON-RPC `initialize` and `tools/list`, matching
  the Unix package verification path.

## Verification

- Fast suite: `scripts/test.sh`
- Scale suite: `scripts/test.sh scale`
- Plugin suite: `scripts/test-plugin.sh`
- Cursor-style local manifest smoke: `.cursor-plugin/plugin.json` launcher with `MILLER_BINARY` set to the local
  release build.
