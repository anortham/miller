# Miller v0.3.5 Release Notes

- **Audience:** Windows users running Miller against Visual Studio workspaces, and any user with gitignored or `.julieignore`d generated trees.
- **Release shape:** Patch release for live watcher ignore-policy parity and cleanup of the next-release backlog.
- **Pinned extractor:** `julie-extract 2.1.3`.

## What Is Fixed

- Live workspace watchers now apply built-in ignored segments, `.gitignore`, and `.julieignore` before enqueueing per-file update/delete operations.
- Visual Studio `.vs` cache churn is skipped before it reaches `julie-extract`, avoiding repeated recoverable `file_outside_root` delete retries for ignored `.vsidx` files.
- Nested workspace roots inherit ancestor git-root `.gitignore` rules, including worktree/submodule `.git` file markers.
- Changes to `.gitignore` and `.julieignore` force a delta scan so newly ignored files are pruned and newly unignored files are discovered.
- Ancestor `.gitignore` files above nested workspace roots are watched explicitly, so ignore-policy edits are picked up without reopening the workspace.

## Verification

- Focused watcher/indexer tests covering `.vs`, `.gitignore`, `.julieignore`, nested roots, ignore negation, ignore-policy rescan, and ancestor ignore watchers.
- Fast suite: `scripts/test.sh`
- Scale suite: `scripts/test.sh scale`
- Plugin suite: `scripts/test-plugin.sh`
- Whitespace: `git diff --check`
