# Miller v0.3.3 Release Notes

- **Audience:** Cursor users installing Miller through the local/plugin package path.
- **Release shape:** Patch release for Cursor MCP startup compatibility.
- **Pinned extractor:** `julie-extract 2.1.3`.

## What Is Fixed

- The Cursor plugin manifest now passes Cursor's `${workspaceFolder}` to the launcher as
  `MILLER_WORKSPACE_ROOT`.
- The plugin launcher now starts `miller serve` from the best available project directory instead of only using
  its own process cwd. It prefers `MILLER_WORKSPACE_ROOT`, `CLAUDE_PROJECT_DIR`, common Cursor workspace env vars,
  then falls back to cwd.
- Unexpanded placeholders such as `${workspaceFolder}` are ignored by the launcher, so clients that do not expand
  the variable still fall back to cwd instead of trying to use a literal placeholder path.
