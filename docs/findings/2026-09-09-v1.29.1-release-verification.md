# Miller 1.29.1 release verification

## Scope

Miller 1.29.1 fixes repeated shared-store inspection while a leader is idle and preserves bounded retry timing
when a due inspection fails before opening a store session. It adds no MCP tools and keeps `julie-extract 2.42.0`,
semantic sidecar 0.1.0, sqlite-vec 0.1.9, and all store contracts unchanged.

All seven release version fields are aligned at 1.29.1: `Directory.Build.props`, `miller-plugin.json`, the
Claude, Cursor, and Codex plugin manifests, and both version fields in the Claude marketplace manifest.
