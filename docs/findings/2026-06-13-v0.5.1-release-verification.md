## What Shipped

- Directory create/delete/rename watcher events now force scan reconciliation instead of flowing through
  single-file update/delete handling.
- Forced rescans and overflow fallbacks now count as pending indexer work for freshness/status checks.
- The watcher extension gate now fails soft for extensionless paths such as `Dockerfile`, `Makefile`, `.env`,
  and trailing-dot names.
- Agent instructions now tell agents to refresh and retry when `inspect <file>` reports no indexed symbols for
  an expected code file.
