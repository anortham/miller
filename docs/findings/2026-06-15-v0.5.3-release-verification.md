## What Shipped

- Dashboard launch URLs now open `/workspace?workspace_id=...` for the requested workspace detail page.
- Recent dashboard errors expose `view issue details`, keep expanded rows open across refreshes, and include a
  dedicated copy-to-clipboard action.
- Telemetry persists bounded error message/detail fields for copyable local issue details.
- Dashboard scripts and vendored Alpine CSP assets are packaged and checked by the release workflow.
- Pinned extractor updated to `julie-extract 2.5.1`.
- Miller decodes BOM-marked UTF-16LE/UTF-16BE source bytes in downstream body/search/source-region paths while
  preserving original-byte hashes and `source_bytes`.
- Compact ambiguity output for `inspect`, `impact`, and `trace` caps candidate lists without changing full JSON
  contracts.
