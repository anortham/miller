## Patch scope

- Health and onboarding honor a matching recorded semantic pause before generic freshness advice. Model preparation
  is recommended only for an explicit model-not-prepared state or a genuinely absent vector artifact; corrupt,
  unreadable, and incompatible artifacts retain their diagnostic state without preparation guidance.
- Prepare/restart guidance now distinguishes one-time `miller semantic prepare` from the live-broker activation
  result: `activation=activated` needs no restart; restart only for `no_live_broker` or `still_not_ready`.
- Family-store pause matching is bound to every `StoreSidecarStamp` field, so a stale or unscoped pause cannot mask
  a newer snapshot.
- The Scale probe launches the apphost deterministically from a clean worktree.
- Shell and PowerShell semantic-soak scripts fail immediately on a failed model-readiness event, before long traffic.
