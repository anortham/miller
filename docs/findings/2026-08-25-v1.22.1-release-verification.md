## End-to-end plugin install of the published artifact

The release's whole subject is the plugin launcher, so the launcher was run against the published release
from an empty cache and an isolated `MILLER_HOME`. Whole install: **6 seconds**.

- Archive downloaded: 113,195,090 bytes in **2.2 s** (~49 MB/s), checksum matched the published sidecar
  (`sha256sum -c` → OK).
- Archive listed (85 entries), extracted in 0.9 s, promoted, and `miller` spawned.
- Installed binary reports `1.22.1+c920c7fdb167`, matching the release target commit.
- Bundled extractor reports `julie-extract 2.35.1`, matching `scripts/julie-pins.json` and the notes.

## Limits of this verification

- Linux only. No Windows or macOS run was performed for this patch; the macOS and Windows archives are
  verified by the workflow's own package smoke and checksums, not by a local install.
- The launcher's stall-retry path is covered by the plugin suite against a loopback server, not by a
  reproduction on a real degraded network.
