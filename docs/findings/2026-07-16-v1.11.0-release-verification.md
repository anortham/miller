## Downloaded Asset Verification

Downloaded all eight live `v1.11.0` assets and verified SHA-256 against the sidecars. The three tarball
sidecars pass `shasum -a 256 -c` directly. The Windows zip sidecar is CRLF-terminated (written by the
pwsh packaging step), so Unix `shasum -c` cannot parse its filename; the hash value itself
(`48839e3757cc033f649015631d3652abb338165bcecc24965d80b61fb5ba39d4`) matches the downloaded zip exactly.
This CRLF quirk predates this release; Windows users verify with `Get-FileHash`, which does not read the
sidecar.

Local smoke run of the extracted `aarch64-apple-darwin` binary: `miller version` →
`1.11.0+d1efbac593bd`, matching the release target commit.

## New Packaging Guards in This Release

`release.yml` now verifies `dashboard/wwwroot/lib/htmx/htmx.min.js` and
`dashboard/wwwroot/lib/idiomorph/idiomorph-ext.min.js` in both the bash and PowerShell verification
blocks (pinned by `ReleaseWorkflow_VerifiesVendoredDashboardScriptAssets`) — a package missing idiomorph
would previously have passed smoke and silently broken every `morph:` swap.
