## Refuted (verified against the code — do not re-file)

- Worktree daemon outliving the family daemon: documented spawn rule; the family scan detaches a
  worktree with its own daemon within one 5s pass; each root stops its own.
- "Unauthenticated" file command channel: no trust boundary — writing the channel grants strictly
  less than writing the tests CT already runs; the payload cannot introduce a command.
- Unix shadow-copy cleanup deleting a live daemon: ETXTBSY blocks the write-open probe on Linux
  (macOS unverified; the probe fails toward keeping the copy).
- Whole-suite fallback on invalid selections: no production trigger — selections are
  provider-generated, project-scoped ids (defense-in-depth guard deferred as a low).
- Cache-wipe-on-every-failure (F7's two-strike recovery): a red tree does not throw, so the premise
  fails; the narrow real gap (timeouts count toward the wipe streak) is deferred as a low.
- Environment inheritance as a high: the daemon spawns the user's own test processes with the same
  environment any test runner gives them; a doc note is the proportionate response.
- Truncated impact wedging watermarks: reconciliation works and the reviewer's proposed fix would
  have broken the everything-stays-stale fail-safe; the REAL defect found during verification is R3.
