## Defect found and fixed

`miller workspace health --json` (the documented Eros contract surface) always rendered
`history_db: null`: all three CLI branches of `CliDispatch.WorkspaceHealth` omitted the
`MetricHistoryStatus` argument to `WorkspaceHealthFacts.Create`, which the MCP path
(`WorkspaceTool`) passed. Fixed on main (`fix(cli): workspace health reports the metric-history
sidecar status`) with a red→green regression test
(`WorkspaceHealth_Json_ReportsHistorySidecarStatus`). Live output now shows
`history_db: present … schema v1` in compact and the full JSON block.

## Full-rebuild timing baseline

No prior full-rebuild wall-clock number was recorded anywhere (findings, memories, logs), so this
run is the baseline for future perf-regression checks:

- Command: `miller refresh --full --wait --json`
- Wall clock: **8.4 s** (`duration_ms: 8312`) end-to-end — extract into `symbols.db.rebuild`,
  atomic promote (revision counter reset to 1, new `artifact_id`), **and** search + content
  sidecar convergence inside the `--wait` window.
- Symbol count identical before/after (39,352). `history.db` kept all pre-rebuild rows and
  recorded a fresh converge snapshot under the new artifact — append-only across promotes, as
  designed.

## Observations (not bugs)

- The sole candidate, `IFS` at `scripts/release-promote.sh:167`, is the `while IFS= read -r`
  bash idiom: a special shell variable consumed implicitly by the shell, never referenced by
  name. A future suppression rule for well-known shell variables (`IFS`, `PATH`, `PS1`, …) would
  take this repo to zero candidates.
- Coverage labels use a `>=10% resolved` threshold, so csharp at 8.2% renders
  "name-evidence only" — as coded, but the threshold may deserve a second look since csharp has
  real `variable_ref` resolution.
- A pre-1.5.0 dashboard process left running across the release upgrade returned HTTP 500 on the
  workspace page until restarted. Expected (stale binary vs. new sidecar schemas), but a
  version-mismatch banner or self-check could make this failure friendlier.
