## Scope

Single-fix patch release for a Windows bootstrap crash-loop. julie-extract records
`artifact_metadata.root_path` in Windows extended-length form (`\\?\C:\...`);
`BlazorProjectNamespaceResolver.TryReadXml` passed paths derived from that root to
`XmlReader.Create(string)`, which URI-parses its argument — `new Uri("\\?\...")` throws
`UriFormatException: Invalid URI: The hostname could not be parsed.`, a `FormatException` outside the
method's catch set, so it escaped `RepositoryIndexLoader.Load` and crash-looped server bootstrap on
every Windows workspace containing Blazor components (v1.9.0–v1.11.0; the resolver shipped in v1.9.0).
Fixed in `e02f059` by opening
the project file as a `FileStream` so no URI parsing occurs, with a `\\?\`-root regression test.
